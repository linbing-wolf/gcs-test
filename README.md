### 🛠️ 核心技术路线（速览）
- **架构**：STM32(下位) + RDK X5/Jetson(上位视觉)，UART协议`0xFF+9字节ASCII+0xFE`
- **底盘**：麦轮+编码器闭环+陀螺仪（⚠️必须加悬挂）
- **机械臂**：塔吊式(步进+齿条)优于舵机臂（防断爪）
- **扫码**：广角2MP USB摄像头 + OpenCV QRCodeDetector，3帧一致才认
- **色环定位**：CLAHE抗光+霍夫圆，粗640×480→精1920×1080
- **详见**《技术方案参考手册.md》

### ⚠️ 高频失败点 TOP5
1. 扫码环节翻车（国赛重灾区）2. 夹爪断裂 3. 上位机烧毁 4. 麦轮走不直 5. 视觉联调太晚
