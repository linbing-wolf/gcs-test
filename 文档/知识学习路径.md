### ③ 视觉算法 👁️

#### 必学知识点
| 知识点 | 用途 | 优先级 |
|--------|------|--------|
| Python 基础（numpy/数组操作） | 视觉代码全用 Python | ⭐⭐⭐⭐⭐ |
| OpenCV 基本操作（读图/视频/阈值） | 图像处理基础 | ⭐⭐⭐⭐⭐ |
| 颜色识别（HSV 颜色空间） | 物料颜色判别（红黄蓝绿） | ⭐⭐⭐⭐⭐ |
| 二维码识别（pyzbar/QRCodeDetector） | 读取任务码（3帧确认） | ⭐⭐⭐⭐⭐ |
| 霍夫圆检测 (HoughCircles) | 圆环定位 | ⭐⭐⭐⭐ |
| CLAHE 抗光预处理 | 现场光线鲁棒（关键技巧） | ⭐⭐⭐⭐ |
| 坐标系换算（像素→实际距离） | 机械臂精准对位 | ⭐⭐⭐⭐ |
| 卡尔曼滤波（可选进阶） | 定位稳定 | ⭐⭐⭐ |
| USB摄像头采集（V4L2/OpenCV） | 视频输入 | ⭐⭐⭐⭐ |
| 串口发送识别结果（pyserial） | 与STM32通信 | ⭐⭐⭐⭐⭐ |

#### 学习路径（由浅入深）
```
第0步 看懂学长视觉代码结构 ≈ 0.5天
  ↓  MBH仓库 视觉程序/gongchuang_vision.py
第1步 Python + OpenCV 基础（读图/阈值/颜色分割） ≈ 3-4天
  ↓  OpenCV官方tutorial / B站"OpenCV零基础"
第2步 HSV颜色识别演练（红黄蓝绿四色） ≈ 2天
  ↓  注意红色需要两段色相(156-180 + 0-6)
第3步 二维码识别（pyzbar 连续3帧确认） ≈ 1-2天
第4步 色环定位（CLAHE + 霍夫圆 + 精定位） ≈ 3-4天
  ↓  西安理工视觉开源（CSDN），核心算法可参考
第5步 相机标定 + 像素转实际坐标 ≈ 2-3天
第6步 串口回传坐标/颜色给STM32 ≈ 1-2天
  ↓  0xFF+9字节ASCII+0xFE格式
第7步 完整识别流水线：读码→抓取识别→落位识别 持续
```
