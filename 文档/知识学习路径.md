## 三、技能掌握标准与验收清单（技能维度）

> 第二章回答"学什么"，本章回答"**学到什么程度才算会**"。每条技能给出**达标标准**与**验收方式**，可自测、可打勾，避免"看着会、一上手就废"。
> 注：达标阈值带 * 者为往届经验值（见《参赛完成路径图.md》阶段5测试数据）；其余为建议标准，随训练数据持续修正。

### 3.1 技能树与前置依赖（谁必须先学）

```
【基础层·全员】
  C 语言 ────┐
             ├──→ 电控线
  Python ─────→ 视觉线
             ─→ 集成线（串口协议 / 状态机 / 故障排查）

【电控线】C语言 → STM32基础(GPIO/TIM/UART/中断) → 电机驱动+PWM → 编码器+PID闭环
          → 麦轮运动学 → 陀螺仪航向修正 → 串口协议联调 → 全系统状态机
【视觉线】Python → NumPy/OpenCV基础 → HSV颜色识别 → 二维码识别(3帧确认)
          → CLAHE+霍夫圆色环定位 → 相机标定(像素→实际坐标) → pyserial回传
【结构线】CAD建模(SW/CATIA) → 3D打印件设计 → 底盘/折叠臂结构 → 装配+强度验证
【集成线】串口协议设计 → 状态机编程 → 三线联调 → 现场故障排查
```

**关键依赖（不能跳步）**

| 后置技能 | 必须先完成 | 原因 |
|----------|-----------|------|
| 串口协议联调 | 电控 UART + 视觉 pyserial | 两端任一侧没通，联调无从谈起 |
| 麦轮运动学 | 电机驱动 + 编码器读数 | 没有闭环反馈，解算再准也走不直 |
| 色环精定位 | HSV 颜色识别 + 相机标定 | 坐标不换算，识别到圆心也没用 |
| 全流程状态机 | 三线各自单模块跑通 | 单点没稳就串流程 = 故障无法定位 |
| 尺寸复测 | 整车总装完成 | 含软质线路复测才有效（红线项） |
