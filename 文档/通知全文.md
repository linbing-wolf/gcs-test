# 关于举办2026年第十三届中国大学生工程实践与创新能力大赛（校级选拔赛）的通知

- **发布单位**：浙江师范大学大学生学科竞赛组织委员会 / 浙江师范大学工学院
- **作者**：张克华 / 供稿单位：工学院
- **发布时间**：2026年9月11日
- **原文链接**：https://sjcx.zjnu.edu.cn/home/notice/detail?newsId=10420&typeName=通知公告

---

为深入贯彻党的教育方针，落实立德树人根本任务，深化我校工程实践与创新教育教学改革，全面提升大学生工程创新综合素质和能力水平，根据《关于举办2026年第十三届中国大学生工程实践与创新能力大赛的预通知》及浙江省大学生工程实践与创新能力大赛组委会有关安排，经研究，决定举办2026年浙江师范大学大学生工程实践与创新能力大赛（校级选拔赛）。现将有关事项通知如下：

## 一、竞赛主题

交叉融合工程创新育新质，立德树人强国建设勇担当。

## 二、参赛资格及日程

竞赛日程安排：

| 事项 | 时间 |
|------|------|
| 校赛报名 | 2026年10月10日 |
| 省赛报名 | 2026年10月16日截止 |
| 省赛初赛 | 2026年11月2日截止 |
| 省赛复赛 | 2026年11月27日-29日 |
| 全国决赛 | 待定 |

## 三、赛道与赛项

本次校赛对接省赛、国赛赛道赛项，共设 **4个赛道 12个赛项**。

### （一）工程实践赛道（2个赛项）
- 太阳能电动车
- 生物质能电动车

### （二）智能+工程创新赛道（3个赛项）
- 智能搬运
- 智能分拣
- 智能救援

### （三）虚拟仿真赛道（4个赛项）
- 企业运营仿真
- 工程场景数字化
- 飞行器设计仿真
- 智能网联汽车设计

### （四）工程创客专项赛道（3个赛项）
- 智能低空消防
- 智能制造产线设计与仿真
- AI+机械臂设计与增材制造

## 四、竞赛规则

（一）本次校赛对接省赛、国赛各赛道各赛项，按浙江省大学生工程实践与创新能力大赛组委会、第十届中国大学生工程实践与创新能力大赛组委会发布的命题与运行规则、评分与规则执行。

（二）各赛项命题细则、任务命题文档模板等由校赛组委会另行发布，并同步在竞赛咨询群内通知。

## 五、参赛对象与组队要求

（一）参赛对象为我校正式注册的全日制在校本科学生。

（二）以参赛队为基本单位报名，可跨学院（部）、跨专业组队；每队学生人数不超过 **4人**（具体人数按相应赛项规则要求），每队指导教师不超过 **2名**。

（三）每名学生限参加一个赛项、加入一支参赛队。

（四）后续将根据省赛、国赛组委会的具体通知要求，在指定的大赛报名平台完成参赛注册并提交报名及相关参赛材料（国赛官网：http://www.gcxl.edu.cn）。

（五）省赛、国赛：省赛为第十三届浙江省大学生工程实践与创新能力大赛，时间、地点、名额分配以省赛组委会通知为准（省赛官网：http://etc.zju.edu.cn/cy-zju-home/industrial_innovation）。

## 六、奖项设置与激励措施

（一）校级设特等奖（可空缺）、一等奖、二等奖、三等奖和成功参赛奖，具体获奖比例根据最终参赛队伍数，参照省赛口径确定。

（二）根据校赛结果，择优选拔队伍组建省赛集训队，并组织集训、模拟比赛及参赛工作。

（三）参赛并完成校赛、入选省赛（国赛）并取得成绩的，按《浙江师范大学本（专）科生创新创业成果奖励办法（修订）》及学校创新创业教育学分认定有关规定，予以成果奖励和学分（学时）认定。

## 七、工作要求

（一）各学院（部）要高度重视，广泛宣传动员，做好参赛选手组织推荐和报名材料报送工作。

（二）参赛学生须遵守竞赛纪律，按时参加竞赛及相关培训；竞赛期间需请假的，应征得任课教师同意并办理请假手续。

（三）本通知未尽事宜，由校赛组委会负责解释。
