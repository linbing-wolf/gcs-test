## 🎯 倒计时冲刺规划（建议）

### 第一阶段：组队与选题（现在 → 9月底）
- [ ] 确定参赛赛道与赛项（4赛道12赛项，每人限报1项）
- [ ] 组建参赛队：学生 ≤4人，指导教师 ≤2名
- [ ] 加入校赛咨询QQ群：**1071824687**，留意命题细则发布
- [ ] 研读对应赛项命题与运行规则（见附件1-4目录中的命题文件）

### 第二阶段：报名（10月1日 → 10月10日）
- [ ] 10月10日前完成校赛报名表填报（附件5）
- [ ] 打印报名表 → 队员、指导教师本人签名 → 学院盖章
- [ ] 按学院要求报送报名材料

### 第三阶段：校赛 → 省赛（10月中旬 → 11月）
- [ ] 等待校赛选拔结果，入选省赛集训队
- [ ] 省赛平台注册报名（10月16日前）——国赛官网 http://www.gcxl.edu.cn
- [ ] 准备初赛作品（11月2日前提交）
- [ ] 11月27-29日参加省赛复赛

## 📌 关键提示

1. **每人限报一个赛项、加入一支队伍**——不要多头报名
2. **跨学院可组队**——但报名材料需通过参赛队伍所在的学院申报
3. 竞赛期间请假需征得任课教师同意并办理请假手续
4. 命题细则、任务命题文档模板由校赛组委会另行发布，重点盯QQ群通知
