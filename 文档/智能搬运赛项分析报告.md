# 🤖 智能搬运赛项 — 深度分析报告

> 来源：《"华航唯实杯"第十三届浙江省大学生工程实践与创新能力大赛 智能+工程创新赛道竞赛命题与运行》（附件2）
> 赛道定位：人工智能 + 大数据 + 智能制造场景，聚焦十五五"制造业数字化、智能化、绿色化升级"

---

## 一、竞赛核心任务

参赛队需**自主设计并制作**一台按给定任务、在工业场景内**自主完成零件搬运 + 装配**的低能耗智能搬运机器人。

### 任务闭环
```
读取二维码任务 → 识别物料(颜色/形状/位置) → 依次抓取 → 载运 → 精准摆放/码垛 → 回启停区 → 统计核对
```

### 作品红线（违反即取消资格）
- 非标零件必须**自主设计和制造**，禁止购买成品或成品套件拼装
- 比赛全程（含调试）**不能更换任何零部件、不能更换电源**
- 尺寸超标直接取消参赛资格

---

## 二、作品硬性指标

### 1. 外形尺寸（硬性，不过关取消资格）
| 指标 | 要求 |
|------|------|
| 铅垂方向投影 | ≤ 300mm × 300mm 正方形 |
| 高度 | ≤ 400mm（含机械臂及所有软质线路） |
| 机械臂 | 允许折叠形式，**出发后才可展开**，展开后尺寸不受限 |

### 2. 电控要求
- 传感器、电机**种类和数量不限**
- **必须配备任务码显示装置**：装在机器人**上部醒目位置**、亮光显示、**不被任何物体遮挡**、字体高度 ≥ 12mm，显示所有任务码及完成情况
- 电源：只能**一个内置电源**，禁液体/腐蚀/污染类电源，全程不可更换
- 允许与笔记本通讯，但运行中**不能触碰笔记本、不能任何形式遥控**
- **不允许对场地遮挡，仅允许垂直向下补光**

### 3. 必须具备的功能清单
定位 · 移动 · 避障 · 读取(二维码/条码/图形/数字/文字/颜色) · 无线通信 · 物料位置/颜色/形状识别 · 物料抓取 · 载运及旋转定位 · 路径规划 · 任务完成情况统计

## 三、赛场环境（决赛第一阶段）

### 场地布局
- 场地：**2400 × 2400 mm** 正方形平面
- 行车道：**灰色**，十字车道宽 **400mm**
- 淡黄色区域：4 个，**450 × 450mm**（对称分布）
- 其余区域：亚光白色浅底
- 障碍物：黑色圆柱 **φ50 × 100mm**，数量和位置**随机抽签**

### 功能区域
| 区域 | 尺寸 | 说明 |
|------|------|------|
| 启停区（蓝色，2处） | 300 × 300mm | 机器人往返停放 |
| 原料区 | 顶面直径300mm圆盘，高80-100mm | **电动转盘**，一次放3个物料，120°均匀分布 |
| 粗加工区 | 580 × 150mm | 表面有5个评分圆环（+6环计数） |
| 暂存区 | 580 × 150mm | 同粗加工区，用于第二批码垛 |

### 转盘细节
- 转向随机，停止位置有误差（停在中间位置附近）
- 转速 **6-10 秒/圈**，每转停留次数和时间现场为准
- 所有区域尺寸和摆放位置**会有偏差**，机器人必须适应

### 评分圆环（放置精度）
- 圆环中心有数字（1、2、3），数字面向赛场中心
- 环外径：φ1=φ+3, φ2=φ1+5, φ3=φ2+7, φ4=φ3+10, φ5=φ4+10 (φ=物料最大直径)

| 环号 | 1环 | 2环 | 3环 | 4环 | 5环 | 6环 | 6环外/倾倒 |
|------|-----|-----|-----|-----|-----|-----|-----------|
| 分数 | **15** | 10 | 7 | 5 | 3 | 1 | **0** |

> 💡 越靠近圆心分越高，**精确落位是拿分关键**

### 物料规格
- 材料：3D打印 ABS，尺寸 ≤ 80mm，重量 ≤ 100g
- 决赛第一阶段：红、黄、蓝、绿**各2个**（共8个，实际用6个），同一种形状
- **颜色可能有一定色差**，系统需鲁棒应对
- 决赛：形状多样（圆柱/方形/三角/球/锥/组合体），现场公布

## 四、任务编码规则（核心赛制）

**任务码 = 四组三位数，用 `+` 连接**

| 组别 | 含义 |
|------|------|
| 第1组 | 第一批3个物料的**颜色和搬运顺序** |
| 第2组 | 第一批物料在粗加工区与暂存区的**放置位置**（按第1组颜色顺序对应1/2/3号环） |
| 第3组 | 第二批3个物料的**颜色和搬运顺序** |
| 第4组 | 第二批物料在**粗加工区**的放置位置 |

颜色编码：**红=1，黄=2，蓝=3，绿=4**

**示例**：`134+123+314+231`
- 第一批：红(1)→蓝(3)→绿(4)，依次放粗加工区/暂存区 1、2、3 号圆环
- 第二批：蓝(3)→红(1)→绿(4)，放粗加工区 2、3、1 号圆环

### 二维码板
- A4大小（横放），贴在**每个赛场内侧垂直**位置，位置随机
- 二维码 80×80mm（含边框），任务编码**随机产生**

## 五、赛程与评分结构

```
复赛 ──→ 决赛第一阶段 ──→ 决赛第二阶段
 |

┌──────────────────────────────────────────┐
│ 复赛        作品说明书 30 + 运行视频 70 = 100 │  → 决出决赛名单
├──────────────────────────────────────────┤
│ 决赛第一阶段  作品说明书 30 + 现场比赛 70 = 100 │  → 晋级第二阶段（成绩不带入）
├──────────────────────────────────────────┤
│ 决赛第二阶段  创新实践 30 + 现场比赛 70 = 100  │  → 最终排名
└──────────────────────────────────────────┘
```

### 各环节要点

#### 复赛
- **作品说明书**（30分）：按附件7模板1，PDF格式，**不得出现学校/队员/教师信息**
- **运行视频**（70分）：按决赛第一阶段要求实拍，**双视角合成1个视频**
  - 全景占1/3 + 跟随特写占2/3，**两画面必须同步**
  - MP4，≤3分钟，<500MB；视频打不开 = 0分
  - 外形/结构雷同 = 0分

#### 决赛第一阶段现场赛
- 每队**2轮**，取最好成绩；每轮**调试3分钟 + 运行3分钟**
- 调试剩1分钟：抽签定搬运任务；剩30s：停机放出发位，裁判摆好二维码板和转盘物料
- **一键式启动**（机器人上必须有明确标识），指令发出后 **5秒内未启动 = 本轮结束**

**运行流程**：
1. 读二维码 → 获得任务码 → 显示在显示装置
2. 到原料区按顺序抓取（**每次1个**，有抓取动作才算过）
3. 运至粗加工区，按任务码放对应圆环
4. 把粗加工区物料搬到暂存区，按任务码放对应圆环
5. 返回原料区，重复搬第二批
6. 第二批在暂存区后三个物料需**码垛**（第一批放置正确才有效，颜色须一致）
7. 回启停区，核对显示装置统计（抓取/放置正确次数）

**运行规则红线**：
- ❌ 禁止用手爪**夹持物料运送**（只能放在机器人上载运）
- ❌ 物料没放到机器人上，**不能去下一个区域**（本区域内不受限）
- ⏱️ 违规不计成绩，但**时间连续计算**

**评分维度**：读码正确性、抓取顺序正确数、放置顺序正确数、粗加工区平面放置精度（圆环）、暂存区放置精度及码垛成功、统计正确性、是否按时回启停区

#### 决赛第二阶段
- **创新实践**（30分）：现场发布任务命题，用现场提供的装备/材料/软件平台完成（如现场加工零件装到作品上）
  - 没完成零件制作 → 取消后续资格；做了**没装到作品上** → 该项0分 + **扣决赛总成绩50%**
  - 自带工具/笔记本/舵机/传感器备件；危险品禁入；离场打扫场地扣分机制
- **现场比赛**（70分）：参照第一阶段流程，任务现场发布，同样2轮取最好

## 六、技术难点分析 🔍

### 难度等级：🌟🌟🌟🌟（较高）

| 难点 | 分析 | 建议 |
|------|------|------|
| **尺寸严苛** | 300×300×400mm 受限空间要塞下底盘+机械臂+电控+显示装置 | 结构紧凑化设计，机械臂折叠方案几乎是必选 |
| **抓取精度** | 物料颜色识别 + 每次抓1个 + 精准对位圆环 | 视觉+机械臂精度联合标定，末端执行器适配物料形状 |
| **导航鲁棒** | 灰色车道识别 + 随机障碍物 + 转盘误差 + 区域位置偏差 | 建议颜色车道线视觉循迹 + 编码器融合；做好容错 |
| **任务码处理** | 二维码读取含边框80mm，现场光线多变 | 高动态范围摄像头 + 多角度补救策略 |
| **两批物料搬运** | 第二批要**码垛到第一批上**且颜色一致 | 需要精确的空间定位与Z轴高度控制 |
| **时间压力** | 3分钟完成两批6个物料搬运+码垛+回程 | 路径规划优化，减少空跑 |
| **转盘不确定性** | 转盘转速/停止位置随机 | 抓取时需视觉确认物料实际位置，不能依赖固定坐标 |
| **一键启动+不可触碰** | 启动后全程全自主 | 必须在调试阶段把稳定性调试到位，现场无修正机会 |

### 系统性风险
- 🔴 **零件尺寸超标** → 直接取消资格（最常见的硬伤）
- 🔴 视频双视角不同步/剪辑 → 不计分
- 🔴 拧螺丝松了都不能换 → 结构可靠性必须极端重视
- 🟡 颜色色差、环境光变化 → 视觉模型要留余量

## 七、备赛行动建议

### 阶段一：方案设计（2-3周）
- [ ] 确定机械结构：底盘（轮式建议全向轮/麦克纳姆轮）+ 可折叠机械臂
- [ ] 视觉方案：主摄像头（读码+识别）+ 辅助传感器（编码器/陀螺仪）
- [ ] 电源选型：单电源高强度放电能力，支撑3分钟连续运行
- [ ] 任务码显示装置设计：≥12mm字体，确保不遮挡

### 阶段二：样机制作（3-4周）
- [ ] 非标件自主设计制造（3D打印/机加工/激光切割）
- [ ] 结构可靠性工程：防抖动、防断线、快检快修设计
- [ ] 尺寸自检：含全部软质线路复测 ≤300×300×400mm

### 阶段三：算法调试（2-3周）
- [ ] 车道灰度识别 + 障碍物避障
- [ ] 二维码读取 + 任务码解析 + 显示
- [ ] 物料颜色识别（色差容错）+ 定位抓取
- [ ] 圆环落位精度控制（目标：1-2环）
- [ ] 码垛策略（高度补偿）

### 阶段四：赛前冲刺
- [ ] 模拟现场：随机障碍/随机转盘停位/随机任务码 全链路演练
- [ ] 录制复赛视频：双视角同步、3分钟完整任务
- [ ] 撰写作品说明书（模板1），检查匿名要求
- [ ] 准备第二阶段创新实践的工具箱与备用件清单

## 八、一句话总结

> **智能搬运 = 视觉识别 × 精准抓放 × 自主导航 × 码垛装配**，在300mm见方的小车上集成完整智能制造物流闭环。复赛视频+初赛现场拼"稳"，第二阶段拼"临场工程能力"。早立项、重可靠性、多演练，是拿奖的关键汪。
