## 一、系统架构总览（多队共识方案）

```
┌─────────────────────────────────────────────────┐
│  上位机（视觉）                                  │
│  Jetson Nano 或 地瓜派RDK X5 或 树莓派           │
│  Ubuntu/Linux (V4L2) + Python3                   │
│  opencv-python / numpy / pyserial / pyzbar       │
└──────────────┬──────────────────────────────────┘
               │ UART 串口通信
               │ 帧格式: 0xFF + 9字节ASCII + 0xFE
               │ (不足9字节补0x00, 波特率9600 8N1)
┌──────────────▼──────────────────────────────────┐
│  下位机（运动控制）                              │
│  STM32F407 / F103ZET6 + RTOS                    │
│  编码器闭环 + PID + 舵机PWM + CAN总线电机        │
│  陀螺仪(WHT101等)航向修正                        │
└──────────────┬──────────────────────────────────┘
               │
       麦轮底盘（麦克纳姆轮） + 塔吊/舵机机械臂
```

## 二、摄像头与识别模块设计

### 2.1 双摄像头分工（MBH 方案）

| 摄像头 | 设备节点 | 职责 |
|--------|----------|------|
| 下摄像头 | `/dev/video0` | 扫描任务二维码（80×80mm） |
| 上摄像头 | `/dev/video2` | 物块识别、色环定位、码垛、物料区/成品区条码 |

### 2.2 摄像头选型参考

- **扫码**：130°广角、200万像素 USB 摄像头（如"花雀"），配 OpenCV QRCodeDetector / pyzbar
- **识别**：MJPEG、30FPS、双缓冲协商分辨率；粗定位 640×480，色环精定位切 1920×1080
- ⚠️ OpenMV 扫码分辨率低/曝光差，多队现场翻车，谨慎选用

### 2.3 识别算法要点

| 任务 | 算法 | 关键细节 |
|------|------|----------|
| 二维码 | pyzbar / QRCodeDetector | 转灰度 → 解码 → **连续3帧相同才认定**（抗闪烁） |
| 物块颜色 | Hough圆 + HSV直方图 | 红用**两段色相**(H 156-180 + 0-6)；位置颜色均稳定才回传 |
| 色环定位 | CLAHE + 形态学梯度 + 霍夫圆 | 只放大"圆环与底色差"；粗检640×480→精修1920×1080局部；卡尔曼/滑动滤波 |
| 码垛 | 半分辨率粗检+全分辨率精修 | Z轴高度补偿，第二批叠第一批上且颜色一致 |
| 转盘取料 | 动态识别 | 转盘运动→静止切换时触发识别指令；停下后视觉确认再抓 |

## 三、通信协议（MBH 开源标准）

### 3.1 帧格式
```
0xFF + 9字节数据 + 0xFE
数据不足9字节 → 后补 0x00
```

### 3.2 常用回传内容

| 内容 | 格式 | 含义 |
|------|------|------|
| 任务码 | `132+3120` 一类7位码+补齐 | 二维码识别结果 |
| 物块/色环坐标 | `XXXXYYYYC` | X、Y各4位，C为颜色 |
| 夹取顺序 | `ABC456789` | 三个工位相对位置 |
| 就绪/确认 | `987654321` | 上电就绪或颜色/条码确认 |
| 超时/失败 | `000000004` | 本次识别失败 |

### 3.3 STM32 任务码指令表（初赛版，指令'1'-'g'）

| 指令 | 函数 | 作用 |
|------|------|------|
| `1` | `run_erweima()` | 下摄像头扫7位任务码，3帧一致后回传 |
| `2`/`a` | `run_wukuaiyuanxin_1()` | 转盘定第一个物块圆心+颜色 |
| `3` | `LOOP1()` | 第一圈转盘，算三个物块抓取顺序 |
| `4` | `LOOP2()` | 第二圈转盘，按任务码后三位重算顺序 |
| `5`/`6` | `run_wukuaiyuanxin_xuanzequyu()` | 确认下一个物块到位 |
| `7` | `run_sehuanyuanxin2()` | 色环粗定标（640×480） |
| `8` | `run_sehuanyuanxin2_centered()` | 色环精细定标（半分辨率粗检+全分辨率精修） |
| `9`/`0` | `run_maduoyuanxin2()` | 码垛圆环定标 |
| `d` | `yunxing_tiaoxingma_dingbiao()` | 决赛：成品区 Code128 定标 |
| `e` | `yunxing_tiaoxingma_zhuanpan()` | 决赛：等条码变化，判向回三次夹取位 |
| `f`/`g` | `yunxing_tiaoxingma_xuanzequyu()` | 决赛：确认条码2、3到位 |
| `h` | `run_maduoyuanxin2()` | 决赛：固定物料区定标 |
| `i` | `yunxing_sangeyuanxin_shibie_q123()` | 决赛：识别Q1/Q2/Q3，按任务码回夹取顺序 |
| `r` | `restart_program()` | 关串口，20秒后重启视觉程序 |
| `end` | 退出主循环 | 本轮任务结束 |

### 3.4 视觉程序启动约定
```bash
python3 gongchuang_vision.py          # 初赛
python3 gongchuang_vision_final.py    # 决赛
```
程序启动后先发 `987654321` 表示视觉端就绪，然后循环等待 STM32 指令。

## 七、调试工具与经验

### 7.1 仿真器
- CMSIS-DAP（X893版/官方原版），含电路原理图、WIN7驱动、DIY教程（MBH 仓库电控程序内收录）

### 7.2 高频踩坑提醒（多队血泪）
1. 扫码环节翻车 — 摄像头选型+光线，国赛初赛重灾区
2. 机械臂夹爪断裂 — 冗余夹爪备件
3. 上位机烧毁（Jetson供电）— 电源管理提前测
4. 死循环导致第二轮不运行（`jixie_reset()`）— 状态机复位自查
5. 麦轮走不直 — 加悬挂
6. 机械改太晚、视觉联调时间不够 — 机械/视觉并行推进
