## 阶段2：技术选型定案（9月底前）⚠️ Rule4 重大决策

**每个方向都列出主流方案，需与张老师确认后锁定**

### 决策1：底盘
| 方案 | 优点 | 缺点 |
|------|------|------|
| 麦克纳姆轮 | 全向移动，场地转弯方便 | 必须加悬挂否则走不直 |
| 四驱差速 | 结构简单、便宜 | 转向笨拙，调头占时间 |

### 决策2：机械臂
| 方案 | 优点 | 缺点 |
|------|------|------|
| 塔吊式（步进+齿条）| 定位准、刚度高 | 结构复杂、重量大 |
| 多舵机机械臂 | 轻便、灵活 | ⚠️ 多队现场断夹爪 |

### 决策3：视觉平台
| 方案 | 优点 | 缺点 |
|------|------|------|
| USB摄像头+OpenCV | 可调试、分辨率高、扫码强 | 需跑上位机（树莓派/电脑） |
| OpenMV/MaixCAM | 轻量、即插即用 | ⚠️ 扫码弱、分辨率低、国赛大量队伍栽这 |

### 决策4：主控
| 方案 | 说明 |
|------|------|
| STM32F407/F103 下位机 | 运动控制，UART+上位机通信 |
| Jetson Nano / RDK X5 上位机 | 跑 OpenCV 视觉 |
| 18650电池组 | 成本只有航模电池 1/5 |

### 选型检查表
- [ ] 尺寸预算：底盘+机械臂折叠后 ≤ 300×300×400mm
- [ ] 电源预算：单电源，3分钟连续高强度运行
- [ ] 显示装置：顶部亮光屏，字体 ≥12mm
- [ ] 非标件清单：哪些自己设计制造

## 阶段5：视觉算法 + 系统联调（10月下旬-11月初）

### 视觉三大模块
| 模块 | 方案（参考开源） |
|------|------------------|
| 二维码读取 | OpenCV QRCodeDetector，**连续3帧一致才认**，130°广角摄像头 |
| 颜色识别 | HSV两段色相（红=156-180+0-6），CLAHE抗光 |
| 圆环定位 | CLAHE+形态学梯度+霍夫圆，粗定位640×480→精定位1920×1080 |

### 联调重点
- [ ] 循迹：灰度传感器+陀螺仪修正走直线
- [ ] 避障：黑色障碍 φ50×100 随机位置，路径重规划测试
- [ ] 转盘抓取：转盘停位有误差，视觉确认后再抓（动态抓取是决赛隐藏考点）
- [ ] 码垛流程：第二批堆第一批上，Z轴高度补偿
- [ ] 全流程time：3分钟内跑完两批6个物料+回程

### 测试数据
- [ ] 读码成功率 ≥ 99%（100次测试）
- [ ] 颜色识别（含色差）正确率 ≥ 98%
- [ ] 圆环落位：1-2环占比 ≥ 60%
- [ ] 全流程完成率 ≥ 80%
