## 三、主流技术路线情报 🛠️

### 系统架构（多队共识）
```
上位机（视觉）：Jetson Nano/RDK X5/树莓派 + Python/OpenCV
      ↕ UART多线程串口通信（0xFF+9字节ASCII+0xFE协议）
下位机（运动）：STM32F407/F103 + RTOS，编码器闭环
```

### 各环节推荐方案
| 环节 | 主流方案 | 反例/坑 |
|------|----------|---------|
| 底盘 | 麦克纳姆轮+编码器+陀螺仪 | ⚠️ 不加悬挂走不直 |
| 机械臂 | 塔吊式（步进+齿条）定位准 | 舵机臂易断爪 |
| 扫码 | ⚠️ OpenCV QRCodeDetector连续3帧一致才认+广角2MP USB摄像头 | OpenMV扫码=送分，国赛大量队伍栽这 |
| 颜色识别 | HSV两段色相（红156-180+0-6） | 单一色相阈值扛不住色差 |
| 圆环定位 | CLAHE+形态学梯度+霍夫圆，粗精两级定位 | 直接依赖绝对颜色，光线一变就挂 |
| 创新实践 | 熟练3D打印/激光切割/PCB，工具系统提前备 | 现场现学来不及，未装新零件扣50% |

### ⚠️ 高频失败点 TOP8（多篇经验帖交叉验证）
1. **扫码环节翻车**（国赛初赛重灾区）
2. **机械臂夹爪断裂**（结构强度+无备件可换）
3. **上位机烧毁**（Jetson Nano供电问题，有位学长省赛前烧板）
4. **代码逻辑缺陷**（while死循环导致第二轮不运行）
5. **机械反复改导致视觉联调太晚**（校赛就出局）
6. **麦轮走不直**
7. **3分钟超时**（任务调度不紧凑）
8. **规则理解分歧**（尤其创新实践环节）
