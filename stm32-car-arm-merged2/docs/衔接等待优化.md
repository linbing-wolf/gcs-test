# 点位衔接等待优化

更新：2026-10-17。仅优化当前连续速度模式的两处重复等待，路线、运动速度和完成判据不变。

## 同向衔接复用稳定结果

上一平移段已通过距离、航向和四轮停稳判据后，只向下一次衔接传递一次有效完成结果。若下一段的地图航向相同，使用原目标继续更新最新IMU样本，并重新检查角差、角速度稳定和四轮反馈；满足条件即进入下一平移段，不再从头等待另一个300 ms稳定窗口。

目标航向改变、工位夹爪对位、未确认停稳、IMU或电机反馈失效、速度ACK未齐等情况均不走此路径。起步自检和必要的转向仍完整确认；最后归位若已在初始航向且停稳，可直接结束，保留原有完成条件。

不会把当前偏航重新设为零。新样本若显示误差或角速度超限，仍执行原来的正常对齐流程；没有自动重试或估时放行。

复用时打印：

```text
[heading reused; four wheels stopped]
```

## 编码器基线复用停稳窗口内采样

四轮已在零速反馈下持续稳定时，其间更新的四轮位置可作为下一段起点。基线仍要求四轮位置有效、未过期，而且采样时间不得早于本次四轮停稳区间的起点；不能混入旋转过程中的位置。

这样不必在转向确认完成后强制再轮询一轮位置。若没有满足条件的采样，仍等待有效反馈；急停、丢帧、CAN错误和超时继续按原规则处理。

## 保留的判据与行为

- IMU误差±0.8°、角速度不超过1°/s、至少3个新样本且稳定300 ms。
- 零速命令收到四轮ACK，四轮位置/速度/状态有效；速度反馈来自零速命令之后，达到原有稳定时间和不超过1 RPM的阈值。
- 横移编码器末端误差±1 mm，原有过冲保护、低速修正和超时不变。这些是软件判据，不能当作实车位置精度。
- 仍在几何段结束时减速并确认停稳；本轮没有改成穿越节点不停，也没有取消原料/粗加工/暂存的右侧夹爪朝向。
- 发车/返程60 mm横移、仅已走返回路后退、任务顺序、14480 mm路程、两段横移、一段后退和18次实际转向保持。没有增加F→D长横移，也没有合并工位两次90°。
- PC9按钮、XM1601扫码、串口/CAN驱动和原位置模式不变。

## 当前验证

使用同一仿真探针，分别编译修改前快照和当前源码；轮子惯性、扰动、IMU输出周期等条件相同。A的IMU周期100 ms，C为50 ms。

| 指标 | 修改前 | 修改后 |
|---|---:|---:|
| 每圈已有稳定结果的复用次数 | 0 | 6 |
| 确认完成到基线就绪 | 平均约59 ms | 平均1 ms |
| 确认完成到首批运动指令 | 平均约59 ms | 平均约23 ms，最大29 ms |
| A整圈仿真时间 | 151.80 s | 149.67 s |
| C整圈仿真时间 | 152.20 s | 149.67 s |

仍保留25 ms速度控制周期，因此“基线就绪”不等于同一毫秒就向电机发运动指令。以上每圈约2.1–2.5秒的差异是仿真结果，不包含实车串口、CAN、机械和场地误差，不能作为实车耗时承诺。

回归覆盖最新IMU仍稳定时保留原累计目标、误差合格但角速度过高时拒绝复用、4号轮未停稳、过期反馈、缺ACK、没有有效上一段完成结果、航向改变、工位对位、旧位置采样和计时回绕，以及两条整圈/故障/横移/返程回归。证据见 [衔接等待优化验证](../evidence/衔接等待优化验证.json)。

本轮未连接或烧录车辆。烧录后仍先确认实际转角和停车距离，再对比节点处的停顿与整圈耗时。
