# 开始按钮串口检测

更新：2026-10-15。操作者确认开始按钮接PC9、按下高电平。

当前初始化PC9为下拉输入，在主循环中进行30 ms非阻塞消抖。确认一次由松开到按下的变化后，从现有调试串口USART3（PB10 TX、PB11 RX、115200 8N1）发送：

```text
[button] START pressed
```

长按只发送一次；松开稳定30 ms后，再按可再次发送。松开不打印，上电时已经按住不当作新按下，需先松开再按。短于30 ms的脉冲会被过滤。

按钮只用于检测提示，不调用run/runimu或其他运动命令。主循环先处理串口急停，再更新按钮状态；消抖不调用delay，也不在GPIO中断中等待串口发送。旧vendor/USER/exti.c的PA0中断示例向USART1发送0x72，当前没有启用该示例。

引脚与消抖时间集中在src/car_config.h的CAR_START_BUTTON_*参数。串口观察使用已有USART3调试连接。

电脑验证覆盖按下抖动、松开抖动、长按不重复、连续两次按下、毫秒计数回绕、上电按住、平移测试模式及急停处理顺序，并确认没有新增运动命令。源码、ARM构建状态和固件哈希见 [开始按钮验证](../evidence/chassis-history/开始按钮串口检测验证.json)。未烧录或现场验证实际电平。
