# 粗加工环位作业合并

本次只接入粗加工区D的环位作业，来源为远程分支 `codex/merged2-station-rings` 的固定提交 [7fed0f62821a3c2680dbd1c3ce16e88f9009d5b5](https://github.com/linbing-wolf/gcs-test/tree/7fed0f62821a3c2680dbd1c3ce16e88f9009d5b5/stm32-car-arm-merged2)。没有导入该分支的原料区、暂存区叠放、任务码解析、机械臂默认使能/PWM或底盘控制实现。

## 动作顺序

车辆到D并完成原有工位转向、四轮停稳后，以2号环为基准。第一批读任务码G2，第二批读G4；每批环号必须是1、2、3的排列。车上第i杯的物块放到该批第i项指定的环。三块放完后，按相同物块顺序抓回原杯位，最后车辆回到2号环基准、机械臂收拢、载物台回1号位，继续原路线。

例如任务 `134+312+314+231`：第一批依次放到3、1、2号环，抓回也按3、1、2号环进行；第二批放下及抓回都按2、3、1号环进行。同一整轮两批共用任务码，返程经过B不重新扫码，整轮结束或急停/故障取消后任务码失效。

每相邻两环索引150mm，1与3之间强制经2分成两段。索引前必须已收臂、机构空闲，四轮具有新鲜的严格零速和健康状态；索引期间机构不能动作。使用当前底盘IMU、编码器和四轮反馈闭环，平移目标上限60RPM，保留r8起步编码器方向确认。每段结束重新取得四轮零速互锁后再抓放。路线节点、道路完成记录及路线里程保留，工位内索引不当作走完了新道路。

## 现场参数

远程原始粗加工姿态也是全零、READY=0。本次保留这个状态，**不会直接启用自动粗加工**。现有D停车点是否对应2号环、环间距及环号增大方向都需要现场确认。

在 `src/station_config.h` 标定以下参数：

| 参数 | 当前值 | 含义 |
|---|---:|---|
| `STN_ROUGH_PLACE_READY` | 0 | 姿态和索引实测通过后才设1 |
| `STN_PLATFORM_TAKE_READY` | 0 | 从车载杯位取料也须完成实测确认 |
| `STN_ROUGH_SLIDE_MM` | 0 | 工位抓放的平推位置，mm |
| `STN_ROUGH_LIFT_MM` | 0 | 工位抓放的升降位置，mm |
| `STN_ROUGH_YAW_DEG` | 0.0 | 工位抓放的云台角度，度 |
| `STN_ROUGH_INDEX_MM` | 150 | 相邻环心距离，mm |
| `STN_ROUGH_INDEX_SIGN` | 1 | 3号环在车头方向为1，反向为-1 |
| `STN_ROUGH_INDEX_RPM` | 60 | 工位索引的平移目标转速上限，RPM |

同一抓放姿态通过车辆索引对准三个环，不再使用五组粗加工姿态数组。只改READY而姿态仍全零会拒绝；平台取料未确认、姿态超出当前机械行程、环号重复或含4/5也会在动作前拒绝。没有修改全局任务码语法，手动调试解析仍保持原有兼容性。

粗加工从车上取料复用当前车载放置姿态 `ARM_PLACE_*`（35mm / 110mm / 256°），夹紧15°、张开45°，速度沿用当前300RPM和舵机插值设置。需要额外确认这一姿态能够从杯中可靠取出物块。暂存区仍使用原有独立取料表和READY限制；本次没有开启暂存区。

## 日志与停止

`[station index] ring=3 move_mm=150` 表示开始向相邻环移动；`[station index done] ... reacquiring ...` 表示距离、航向及底盘停稳条件已满足，正在重新获取机构使用的严格零速互锁。后者完成前不会进入下一机械臂动作。

索引中急停、`arm stop`、`obstacle`、IMU/CAN/反馈故障都取消当前整轮，保持停车并使任务码失效，不沿原道路自动退回，也不自动续夹。四轮严格非零速互锁保持原样，1RPM反馈仍可能停止作业。

验证以 `evidence/current-validation.json` 为准。电脑测试中的40mm / 90mm / 120°只用于模拟，不写入实际ARM固件配置，也不代表现场标定或动作验收。
