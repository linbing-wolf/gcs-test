整理日期：2026-10-17。

这里收的是开发过程中逐个功能验证用的独立程序，**不是比赛最终程序**。最终车辆程序在
`stm32-car-test/`；本目录只用于复现实验、重新标定参数和排查硬件。

### `main_armclaw.c` 当前实测参数

以下数值是 2026-10-18 在实车上量过的，只对这台车的机械安装有效；换车或拆装后要重新标定。

| 项目 | 数值 |
| --- | --- |
| 云台初始位 | 0°，1975 us |
| 云台抓取位 | 126°，1275 us |
| 云台放载物台 | 254°，564 us |
| 夹取姿势 | 平推 65 mm，升降 110 mm |
| 放料姿势 | 平推 30 mm，升降 110 mm |
| 升降最高 | 135 mm |
| 爪子张开 / 夹紧 | 45° / 0° |

常用按键：

- `!`：从默认位完成一次夹取并保持夹住。
- `@`：连续装三块——回默认位、载物台回 1 号位，然后“抓取 → 放到载物台”重复三次；
  每放完一块，载物台在机械臂摆回抓取位的同时转 120°，最后机械臂回默认位、载物台回 1 号位。
- `$`：只执行放料段，适合手里已经夹着物块时使用。
- `W`：回默认位（升降最高、齿条收到底、云台 0°、爪子 45°）。
- `p`：打印机械臂、爪子、云台的完整状态；`h` 重新打印按键表。

注意：`@` 和 `W` 会先回默认位并开爪，手里夹着物块时不要按。

## 电脑端脚本

| 文件 | 用途 |
| --- | --- |
| `switch-main.ps1` | 把指定的 `main_*.c` 换进 Keil 工程，可编译并下载 |
| `serial-capture.ps1` / `serial-capture-boot.ps1` | 串口抓日志（普通 / 开机阶段） |
| `serial-monitor.ps1` / `serial-listen.ps1` | 串口监视 |
| `serial-hexdump.ps1` | 串口十六进制查看 |
| `serial-gui.ps1` | 简易串口图形界面 |
| `tjc-send.ps1` / `tjc-text.ps1` / `tjc-from-file.ps1` | 向串口屏发指令 / 文字 / 文件内容 |
| `改屏上的字.bat` | 调用串口屏脚本的快捷入口 |
| `screen-text.txt` | 串口屏文字示例 |
| `像素取点.py` | 从截图取像素坐标，辅助视觉标定 |
| `eprj2-dump.py` | 导出/查看 Keil 工程配置 |

脚本里的串口默认是 `COM8 / 115200`；换电脑后按实际端口修改。
`switch-main.ps1` 包含本机 Keil 工程路径，换机器时要改路径。

## 接线要点

- 串口看板子右侧的 `USB UART` 口（板载 CH340 直连 USART1）。
- 舵机电源用电源模块的**绿色 5V 座**；蓝色 12V 座会烧舵机。
- 舵机信号线与核心板必须共地。
- 扫码模块接 USART1：模块 TX → PB7，模块 RX → PB6，并共地。
