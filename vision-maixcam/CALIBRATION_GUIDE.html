解决什么画面边缘弯曲像素 → 毫米
产出K + dist单应 H
对你项目的影响次要（目标多在画面中心）主要（决定抓取精度）

① 打板→ ② 拍图→ ③ 畸变标定→ ④ 手眼标定→ ⑤ 回填 config→ ⑥ 上板验证

核心纪律：标定与运行的相机分辨率必须一致；标定板必须平整；同机同镜。

1阶段一 · 准备标定板

打板

checkerboard.html

打开 maix_toolkit/pc/checkerboard.html 打印，选「实际大小 / 100%」。

校验比例

关键

打完后量页面上那条 100mm 校验尺，必须正好 100mm，否则重打。

贴平板

平整

贴/压在 硬平板 上，纸不能弯、不能起泡，否则标定必废。

规格对照（本板默认）：方格 20mm · 10×7 格 → 9×6 内角点 → 脚本填 --cols 9 --rows 6。

⚠️ 头号坑：OpenCV 的 patternSize 填的是内角点数，不是格子数。"9×6 方格"的板子是 8×5 内角点。本板已明确标注，不会踩。

2阶段二 · 畸变标定（视镜头，可选）

先判断要不要做

情况做法
镜头是 OS04D10（官方无畸变）直接跳过本阶段
SC850SL / OS04A10（畸变约 25%）先 lens_corr 看一眼，边缘明显弯再做
目标都在画面中心可跳过，只做手眼

快速体检（10 分钟）

from maix import camera, display, app
cam = camera.Camera(640, 480); disp = display.Display()
while not app.need_exit():
    img = cam.read()
    img = img.lens_corr(strength=1.5)   # 调 strength 到画面不弯
    disp.show(img)

只调径向、不精确、每帧约 10ms——用来判断"要不要认真标"，不作最终方案。

正式标定 · 拍图

  1. 相机设为运行时同分辨率（如 640×480）；标定期间不要再改分辨率。
  2. 拍 15~20 张，棋盘格要：整块可见、清晰、覆盖四角与中心、带不同倾角。
  3. 一定要有棋盘格出现在画面边缘的照片——边缘点才用来建模畸变。
  4. 别过曝/欠曝，别拍糊。图片放 maix_toolkit/pc/calib/。

跑标定

python maix_toolkit/pc/calib_distort.py --dir maix_toolkit/pc/calib --cols 9 --rows 6 --square 20

产出 maix_toolkit/pc/cam_K_dist.py：

UNDISTORT_ON = True
CAM_K    = [fx, 0, cx,  0, fy, cy,  0, 0, 1]
CAM_DIST = [k1, k2, p1, p2, k3]

验收：屏幕打印的 重投影误差 RMS < 0.5 px 才合格；偏大就重拍（更清晰、更覆盖边缘、更平整）。

⚠️ 畸变数字以你实测为准；官方不同页面写 5% / 25% / -25.6%，别照抄。

3阶段三 · 手眼标定（像素 → 毫米，必做）

原理：工作台面近似共面，用单应矩阵 H 即可：

        [Xmm]        [u]
        [Ymm] ~ H ·  [v]
        [ 1 ]        [1]

做法（用已知点）

  1. 台面上摆 ≥4（建议 9） 个标记点，坐标尽量铺开、别共线。
  2. 用尺子量出每个点的 毫米坐标（原点/轴向要和 STM32 约定一致）。
  3. 拍照，读出这些点的 像素坐标（可用棋盘格角点，或放标记后找色块）。
  4. 把两组坐标填进 calib_homography.py 的 PX / MM，运行：
python maix_toolkit/pc/calib_homography.py

产出 maix_toolkit/pc/homography.py：

HOMOGRAPHY_ON = True
HOMOGRAPHY    = [h11, h12, h13, h21, h22, h23, h31, h32, h33]

验收：脚打印的 最大反算误差 < 3 mm（理想 < 1mm）。

⚠️ 原点/轴向必须与 STM32 一致（不然方向反）；点要铺开、共面；每场比赛重标（机械装配会变）。

4阶段四 · 回填参数到 config.py

把两个脚本产出的内容，粘进 maixcam_app_v2/config.py：

# 精度：镜头畸变
UNDISTORT_ON = True
CAM_K    = [ ... ]     # ← cam_K_dist.py
CAM_DIST = [ ... ]     # ← cam_K_dist.py

# 精度：手眼标定（像素→毫米）
HOMOGRAPHY_ON = True
HOMOGRAPHY    = [ ... ] # ← homography.py

# 精度：坐标系 / 多帧
DET_W, DET_H = 640, 480     # 检测分辨率（提精度可调大）
CENTER_FILTER_N = 9         # 多帧平均

5阶段五 · 参数在应用里怎么生效

precision.py 组件config 开关作用
CoordScalerDET_W / DET_H高分辨率检测 → 缩回 640×480 口径（STM32 零改动）
DistortionModelUNDISTORT_ON / CAM_K / CAM_DIST坐标层反畸变（逐点，纯 Python 迭代）
HomographyHOMOGRAPHY_ON / HOMOGRAPHY像素 → 毫米
CenterFilterCENTER_FILTER_N多帧平均降抖动（σ/√N）
fit_circle（直接调用）圆的最小二乘亚像素拟合

典型链路：像素(cx,cy) → 去畸变 → 手眼 H → 毫米 → 多帧平均 → 发送。

6阶段六 · 验证

  1. 跑本地自检：python maixcam_app_v2/selftest.py → 应打印 [ALL PASS]。
  2. 把棋盘格/已知物块放在已知物理位置，看应用输出的毫米坐标。
  3. 做抖动测试：同一目标静置，连续 100 帧输出坐标标准差 < 1 像素（或 < 1mm）。
  4. 换个位置再来一遍，确认全场误差一致（不是某处准某处偏）。

7常见坑清单

坑后果对策
内角点当格子数找不到角点，标定失败填内角点数（10×7 格 = 9×6 角点）
打印被缩放方格不是标称尺寸，尺寸全错选"实际大小"，量 100mm 校验尺
板子弯/起泡RMS 偏大，畸变算歪贴硬平板
标定≠运行分辨率畸变参数对不上两者锁死同一分辨率
没拍画面边缘边缘畸变没建模务必有几张棋盘贴边的图
手眼原点/轴向搞反移动方向相反，抓飞与 STM32 约定一致，先验一个点
用了别的相机拍色彩/畸变不一致同机同镜
标完没重标装配变了精度掉每场比赛重标手眼

8总检查清单

  • 打印棋盘格，选 100%，量 100mm 校验尺合格
  • 棋盘格贴硬平板，平整无弯
  • 相机锁定 = 运行时分辨率
  • 拍 15~20 张：全可见 + 覆盖四角/中心 + 有贴边 + 不同倾角
  • calib_distort.py → RMS < 0.5px → 产出 cam_K_dist.py
  • 台面摆 ≥4（建议 9）个已知点，量准 mm 坐标
  • 读像素坐标，填 PX/MM → calib_homography.py → 误差 < 3mm
  • 参数回填 config.py（UNDISTORT_ON / HOMOGRAPHY_ON 置 True）
  • selftest.py 全绿；上板验证：毫米坐标准、抖动 < 1px

OS04D10 用户：跳过棋盘格畸变，只做手眼即可。OS04A10 / SC850SL：按全流程走。
