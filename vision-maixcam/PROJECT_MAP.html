0一句话概括

把开源工程 gcs-gold-medal 的树莓派 + OpenCV 视觉，迁移到 MaixCAM2 上， 并按新题目（智能搬运）的流程重构。目前已产出：旧流程版 maixcam_app、 新流程版 maixcam_app_v2、独立工具项目 maix_toolkit， 以及一套精度优化方案；AI 增强已落地：自采 870 张 / 6 类数据集 → 训练 yolo11n-cls（val top-1 99.4%）→ 经 Pulsar2 转成 MaixCAM2 的 .axmodel + cls11n.mud（量化后仿真 99.38%）→ 以「CV 定位 + AI 判色」接入 maixcam_app_v2（USE_AI 开关）。

6精度优化路线（与比赛无关的通用能力）

① 镜头畸变标定

收益 ★★★★★

官方大底镜头畸变约 25%（MaixCAM2 镜头页标 -25.6%，以实测为准）。棋盘格 + cv2.calibrateCamera，重投影误差 < 0.5px。

② 手眼标定

收益 ★★★★

像素→毫米单应 H，反算误差 < 1~3mm。原点/轴向须与 STM32 一致。

③ 高分辨率检测

收益 ★★★★

检测用高分辨率，发送前缩回 640×480 口径，STM32 零改动。

④ 亚像素圆拟合 + 多帧平均

收益 ★★★★

圆最小二乘拟合（0.1~0.3px）+ 多帧平均（σ/√N）。

⑤ AI 分类（抗色差）

收益 ★★★

4 色分类替代硬阈值；框内再用 CV 精修中心。

落点：maixcam_app_v2/precision.py（库）+ maix_toolkit/（标定工具）。

7标定实操（精度优化的地基）

两个标定：畸变标定（把弯曲的画面掰直）与 手眼标定（像素 → 毫米）。 它们跑在 maix_toolkit/pc/，产出的参数直接喂给应用。 这一步不做，后面 AI / CV 再强也白搭。

7.1 镜头畸变标定

要什么

棋盘格

9×6 内角点、方格 25mm，贴在硬平板上（别贴软纸，会弯）。

怎么做

calib_distort.py

固定分辨率拍 15~20 张，覆盖四角 + 中心 + 不同倾角。

看什么

验收

重投影误差 < 0.5 px 才算合格。

原理（OpenCV 口径：径向 k + 切向 p）：

正向： x_d = x(1 + k1 r^2 + k2 r^4 + k3 r^6) + 2 p1 x y + p2 (r^2 + 2 x^2)
       y_d = y(1 + k1 r^2 + k2 r^4 + k3 r^6) + p1 (r^2 + 2 y^2) + 2 p2 x y
反解： 应用层用不动点迭代（precision.DistortionModel）逐点还原
# 1) 拍好图放 pc/calib/
python maix_toolkit/pc/calib_distort.py --dir maix_toolkit/pc/calib --cols 9 --rows 6 --square 25

# 2) 产出 pc/cam_K_dist.py，粘进 maixcam_app_v2/config.py：
UNDISTORT_ON = True
CAM_K    = [fx, 0, cx,  0, fy, cy,  0, 0, 1]
CAM_DIST = [k1, k2, p1, p2, k3]

⚠️ 官方大底镜头（SC850SL / OS04A10）畸变约 25%（镜头页写 -25.6%，以实测为准），必做； OS04D10 官方标注无畸变，可跳过。标定与运行必须同分辨率；板子要非对称（行列角点数不等，避免 180° 二义性）、且要拍到画面边缘（边缘点才建模畸变）。

更省事的替代：MaixPy 自带 img.lens_corr(strength=...) 可免标定快速矫正（调到画面不弯即可）； 板上也能跑 OpenCV 全流程（image.image2cv → cv2.undistort → image.cv2image，见 MaixHub「畸变校正」经验帖）。

7.2 手眼标定（像素 → 毫米）

要什么

已知点

台面摆 ≥4（建议 9）个标记点，用尺子量出各点 mm 坐标。

怎么做

calib_homography.py

读出这些点的像素坐标，填进脚本，解单应矩阵 H。

看什么

验收

反算误差 < 1~3 mm。

# 1) 填好脚本里的 PX / MM 两个列表
python maix_toolkit/pc/calib_homography.py

# 2) 产出 pc/homography.py，粘进 config.py：
HOMOGRAPHY_ON = True
HOMOGRAPHY    = [h11, h12, h13, h21, h22, h23, h31, h32, h33]

⚠️ 坐标原点 / 轴向必须与 STM32 一致（否则方向反）； 标定面与工作台面共面；每场比赛重标（机械装配会变）。

8AI 调研结论（MaixCAM2）

项参数
SoCAxera AX630C：2×A53@1.2GHz + E907 RISC-V
NPU12.8 TOPS@INT4 / 3.2 TOPS@INT8，支持卷积 + Transformer
实测算力YOLO11n@640 约 113 FPS，YOLO11s 约 62 FPS
支持模型YOLOv5 / v8 / YOLO11 / YOLO26；检测 / 姿态 / 分割 / OBB / 分类
图像增强AI-ISP「智眸4.0」低照增强（需配 vNPU）
转换INT8 → .axmodel + .mud（Pulsar2 / AX620E，或在线转换）

结论：几何精度靠 经典 CV + 标定（AI 的边框中心反而糙）； 语义/色差鲁棒性靠 AI。最佳为混合架构：AI 粗定位 + CV 精修中心。
