## 2. 当前程序入口

MaixCAM App ID 为 `yyb_mover`，启动入口是 `maixcam_app_v2/main.py`。默认使用 UART4、115200 baud，与 STM32 UART5 以 `AA 55 + LEN + PAYLOAD + CRC8 + 0D` 格式通信。实验 I²C 位于调参工具目录，当前 App 包走 UART。

| 命令 | 分支与回包 |
| --- | --- |
| A / T / C | 启停区 `START`、任务码 `TASK`、指定颜色物料 `PICK` |
| D / E | 圆盘模板与霍夫/圆环后备。主动对齐以新画面复核，并通过原有 `DISC,x,y,dx,ok` 回状态 |
| F | 码垛底座，指定颜色默认依赖 AI，回 `STACK` |
| G | 障碍回 `OBST`，确认畅通回 `CLEAR`，检测超时回 `NONE,G` |
| H | 按配置进入旧盘缘模式或新物料模式，见下节 |
| R / Z | R 复位并回 `READY`，可中断任务。Z 回 `OK`，服务继续轮询 |

任务执行中收到其他命令会回 `BUSY`。串口日志、AI 置信度和 D/E、F、H 采图记录均开启。采图仍受间隔和单次张数限制，任务日志目录默认保留。

## 3. 新 H 处理流程与通信

1. 先看到工位内物料停稳时，记录首件颜色。中心 Y 超出容差时发送 `MOVE,步长`，继续等另一种颜色的物料停稳。
2. 首次确认停稳前若发现物料在动、全图可连续确认两种颜色，则按转盘向右运动的假设记录**右侧先到、左侧后到**，并等待判定为后到的颜色在工位范围内停稳。
3. 运动画面暂时凑不齐两色时，继续等待两次停稳。同一色持续出现在画面里只计一次，新 H 要求两种不同颜色。
4. 双色确认时发一次 `COLORS,c1,c2`。后到物料停稳后，回 `DISC,x,y,dx,c1,c2`。超时回 `NONE,H`，R 中断回 `READY`。

颜色码为红 1、黄 2、蓝 3、绿 4。例如先蓝后红、终点物料中心为 `(300,240)` 时，完整终包载荷为 `DISC,300,240,-20,3,1`。最后的 `3,1` 是顺序颜色，`dx` 仍表示中心 X 相对于画面中心的偏差。车距微调走独立的 `MOVE`，终包表示收齐双色且后到物料停稳。旧 H 和 D/E 继续使用末尾带 `ok` 的原终包。

STM32 实验固件可以直接从新终包获得两色。如果此前收到 `COLORS`，终包顺序须一致。`vision h` 发起请求，`vision status` 查看会话，`vision clear` 清除。该实验入口只显示 `MOVE` 像素指令，车辆运动由现有整车控制流程负责。整车固件的自动工位流程仍需按实际固件版本核对 UART 消费契约。

## 4. 配置和重装后复调

板端配置文件是 `/root/yyb_mover_data/h_material.json`。文件可写局部覆盖，省略字段取 `config.py` 默认值。默认模式是旧 H，每次收到 H 时读取一次并固定参数，文件在重启后仍保留。

```json
{
  "mode": true,
  "target_y": 240,
  "max_moves": 0
}
```

`mode: false` 切回旧 H。`max_moves: 0` 用于只观察和采样。差分档的默认目标 Y 为 240 px、容差 ±6 px、单次步长上限 12 px、超时 8000 ms，均为离线初值。停稳使用当前 `config.py` 中的 `PICK_STOP_HOLD_MS` 和 `PICK_STOP_SPEED_PX_S`，再以 H 的中心确认帧数判断。

- 调参台需要已有 Python 3 和可用 SSH。先读取当前板端配置，再改参数并点击保存回读。保存从下一条 H 生效。
- 把车摆到实际目标距离，先用只观察配置收集物料中心 Y。确认目标和运动方向后再逐步恢复步长。D/E/F/旧 H 的临时落点仍使用 `/tmp/plate_bias`。
- 串口日志在 `/root/yyb_mover_serial`，D/E、F、H 采图在 `/root/yyb_mover_data` 的相应目录，新 H 任务目录带 `H-material` 标记。联调时对照首件中心、`MOVE`、颜色顺序和终包的时间。
