## 2. 当前程序入口

MaixCAM App ID 为 `yyb_mover`，启动入口是 `maixcam_app_v2/main.py`。默认使用 UART4、115200 baud，与 STM32 UART5 以 `AA 55 + LEN + PAYLOAD + CRC8 + 0D` 格式通信。实验 I²C 位于调参工具目录，当前 App 包走 UART。

| 命令 | 分支与回包 |
| --- | --- |
| A / T / C | 启停区 `START`、任务码 `TASK`、指定颜色物料 `PICK` |
| D / E | 圆盘模板与霍夫/圆环后备。主动对齐以新画面复核，并通过原有 `DISC,x,y,dx,ok` 回状态 |
| F | 码垛底座，指定颜色默认依赖 AI，回 `STACK` |
| G | 障碍回 `OBST`，确认畅通回 `CLEAR`，检测超时回 `NONE,G` |
| H | 按配置进入旧盘缘模式或新物料模式，见下节 |
| R / Z | R 复位并回 `READY`，可中断任务。Z 回 `OK`，服务继续轮询 |

任务执行中收到其他命令会回 `BUSY`。串口日志、AI 置信度和 D/E、F、H 采图记录均开启。采图仍受间隔和单次张数限制，任务日志目录默认保留。

## 3. 新 H 当前流程与通信

> 当前工作区以 21:25 更新前的可用双轴代码为基准。去掉总超时；最后一轮纠偏指令提交后即回双色 `DISC`，坐标取末轮动作前的实测值。预算用完前，后到物料停稳且两轴进入共用容差即回双色终包。下方后续联调补丁描述历史版本。

1. 先看到工位内物料停稳时，记录首件颜色。X 或 Y 超出容差时可发送 `MOVEXY,dx,dy`，继续等另一种颜色的物料停稳。首件最多使用总纠偏次数减一。
2. 首次确认停稳前若发现物料在动、全图可连续确认两种颜色，则按转盘向右运动的假设记录**右侧先到、左侧后到**，并等待判定为后到的颜色在工位范围内停稳。
3. 运动画面暂时凑不齐两色时，继续等待两次停稳。同一色持续出现在画面里只计一次，新 H 要求两种不同颜色。
4. 双色确认时发一次 `COLORS,c1,c2`，它是中间结果。后到物料停稳且两轴达标时回成功终包 `DISC,x,y,dx,c1,c2`。没有任务总超时。最后一轮纠偏指令提交后也回双色 `DISC`，沿用末轮动作前的实测坐标，不等待最后一轮动作完成。预算结束的 `DISC` 不证明已对齐。R 可中断并回 `READY`。

颜色码为红 1、黄 2、蓝 3、绿 4。例如先蓝后红、终点物料中心为 `(320,240)` 时，中间包为 `COLORS,3,1`，成功终包为 `DISC,320,240,0,3,1`。最后的 `3,1` 是先后顺序，终包的 `dx` 是中心 X 相对于画面中心的偏差，和可调 X 目标下的纠偏量是两个不同量。新 H 从 D/E 复用双轴纠偏，不套用其终包语义。旧 H 和 D/E 继续使用末尾带 `ok` 的原终包。

STM32 实验固件可以直接从新终包获得两色。如果此前收到 `COLORS`，终包顺序须一致。`vision h` 发起请求，`vision status` 查看会话，`vision clear` 清除。该实验入口只显示 `MOVE` 像素指令，车辆运动由现有整车控制流程负责。整车固件的自动工位流程仍需按实际固件版本核对 UART 消费契约。

## 4. 配置和重装后复调

板端配置文件是 `/root/yyb_mover_data/h_material.json`。文件可写局部覆盖，省略字段取 `config.py` 默认值。默认模式是旧 H，每次收到 H 时读取一次并固定参数，文件在重启后仍保留。

```json
{
  "mode": true,
  "target_y": 240,
  "max_moves": 0
}
```

`mode: false` 切回旧 H。`max_moves: 0` 用于只观察和采样，此时后到物料停稳即回实测坐标。差分档的默认目标为 `(320,240)`、两轴容差 ±6 px、单轴单次步长上限 12，均为离线初值。停稳使用当前 `config.py` 中的 `PICK_STOP_HOLD_MS` 和 `PICK_STOP_SPEED_PX_S`，再以 H 的中心确认帧数判断。

- 调参台需要已有 Python 3 和可用 SSH。先读取当前板端配置，再改参数并点击保存回读。保存从下一条 H 生效。
- 把车摆到实际目标距离，先用只观察配置收集物料中心 Y。确认目标和运动方向后再逐步恢复步长。D/E/F/旧 H 的临时落点仍使用 `/tmp/plate_bias`。
- 串口日志在 `/root/yyb_mover_serial`，D/E、F、H 采图在 `/root/yyb_mover_data` 的相应目录，新 H 任务目录带 `H-material` 标记。联调时对照首件中心、`MOVE`、颜色顺序和终包的时间。

### 新 H 双轴联调补丁

主动调正发送 `MOVEXY,dx,dy`，采用 D/E 的双轴误差、单轴限幅、移动后等待、重新采样与连续容差确认。新 H 的物料候选沿用 C 的色块定位和 AI 判色，工位内按颜色选择最大候选，用停稳检测和中心稳定判定复核。全图双色仍过滤贴框候选，按右先左后确认。已确认后到颜色后只追踪该颜色，等它在工位内停稳并连续通过 X/Y 容差再回终包。首件最多用总步数上限减一，给终件留至少一轮。

新 H 无总超时。步数用尽后等最后一轮动作停稳再复核。超差或在最后的复核帧内无法确认达标时回 `NONE,H`，达标则回双色 `DISC`；旧 `timeout_ms` 留作配置兼容字段。设 `max_moves: 0` 可只观察并保留停稳坐标回包。调试台可设置 X/Y 各自目标、容差与方向，以及移动等待和最终对齐确认帧数。终包 `dx` 维持原协议定义，即回包 X 相对于画面中心的差，日志的纠偏 `dx` 则相对于可调目标 X。
