# MaixCAM 本地落点调节台

Windows 双击 `launch.cmd` 打开调参台。也可在仓库根目录运行：

```text
python vision-maixcam/tuning_app/server.py
```

## 当前运行基线

页面顶部的“当前程序基线”只读展示本地 `config.py`：图像坐标口径、H 停稳 ROI、HCOLORS/HDISC 方向格式、单件停稳即时回包、`HDISC2` 实验开关、方向兜底、D/E 一轮 MOVEXY 后立即回包策略，以及 J 停稳确认参数。它用于避免页面说明与实际程序版本脱节。

## H 物料中心差分

页面的「H 物料模式」可读取板端值、预览和写入覆盖，写入后会同次回读。也可直接编辑板端 `/root/yyb_mover_data/h_material.json`。没有写出的字段使用板端 `config.py` 默认值。JSON 会保留到设备重启之后，下一条 H 读取新配置，运行中的 H 保留启动时的参数。使用 `"mode": false` 切回旧 H。

在独立差分面板可调整目标 Y、容差、移动增益、符号、单次限幅、最大次数、静稳等待及颜色/中心确认帧数。只观察时可把最大次数置为 0。H 覆盖文件与 D/E/F/旧 H 的临时落点文件分别写入。应用配置不会发送 H 或移动命令。

## OpenCode 日志调查

填写设备地址和 SSH 凭据，在「OpenCode 日志调查」输入问题，例如「最近一次 H 为什么回复 NONE,H」。调参台以只读 SSH 获取近期应用日志和最新串口会话片段。脱敏后的摘录和问题交给本机 OpenCode 当前配置的模型，页面同时展示回答与带行号的摘录。

功能沿用本机 `~/.agents/skills/agent-peer-call/call.py` 登记的 `opencode-dev`。部署到另一台电脑时需要已有同一调用配置和可用的 OpenCode 模型。调查不会修改板端配置或文件。日志摘录有限，仍需对照板端完整记录核实结论。

通过 Tailscale 访问与局域网相同的板子时，如果电脑只信任它的局域网 SSH 主机密钥，填写 Tailscale 地址作为设备地址，并在日志调查的「SSH 主机密钥别名」里填该板子已信任的局域网地址。连接仍会严格校验密钥。OpenCode 超时或模型调用失败时，页面仍展示已取回的日志摘录。

浏览器打开 http://127.0.0.1:8765 。服务仅监听本机，Ctrl+C 退出。可用 `--port 8766` 改端口。

界面支持 H、D、E、F 的 dx/dy 偏移滑杆、数字输入、有效目标示意、默认恢复、配置预览及下载。所有调整首先只改变本地预览；点击“应用全部工位临时配置”才写设备。应用不触发任务或移动。

当前 D/E 单次模式为：产生一轮 `MOVEXY` 后立即返回动作前坐标和终包，不再等待视觉复核，也不使用 8 秒等待上限。终包发出后，空闲服务会在 `6000 ms` 和 `10000 ms` 各补拍一张现场图。此工具不负责安装或部署。

H 有效目标 = 基础目标 - 偏移；D/E/F 有效目标 = (320,240) - 偏移。单位都是 640×480 口径的像素。增加偏移会减小目标坐标；实际车身方向需现场验证。灰圈为基础目标，青色十字为有效目标，图像只是坐标示意。

SSH 操作要求系统已有 `ssh`、设备 root 密钥登录及已确认的 known_hosts。工具以 BatchMode 和 StrictHostKeyChecking=yes 运行，不保存密码、不自动接受主机指纹。可先在终端手动建立连接；如果使用 SSH 别名，也需要该别名允许 root 登录。

也可在页面的可选密码框输入设备密码；此路径使用当前 Python 环境已有的 `paramiko`，不会自动安装。密码不预填，不写文件或日志，只随本机 JSON 请求传递，保留在当前页面内存中，关闭或清空页面后消失。密码方式请填写真实 IP 或域名（不解析 SSH 别名）；依然读取系统 known_hosts 并拒绝未知主机，首次先用终端 SSH 确认指纹。

建议先“读取当前临时值”，再调整一轴 1～2 px，点击应用，等待下一次任务现场验证，重复多轮。页面应用会写入全部十键（包括未展示工位）。“恢复本地默认值”仅恢复当前工位预览，不写设备。“清除临时配置”删除设备 `/tmp/plate_bias`，恢复设备自己的 config 默认值，界面显示的是仓库默认值；二者可能不同。无临时文件时读取也只能显示仓库默认值。

文件写入采用同目录临时文件和原子 rename。配置约 500 ms 缓存；已开始且读过参数的任务不会中途重算。`/tmp` 文件重启失效。满意后应人工固化 config，运行五项视觉自检并按项目流程打包。

验证：`python -m unittest discover -s vision-maixcam/tuning_app -p test_server.py`。未连接真实设备的测试不能证明 SSH、落点或实车精度。
