快速介绍 · YYB 智能搬运视觉端（MaixCAM2）

一句话：MaixCAM2 当视觉上位机，被动回答 STM32 的问题。STM32 发命令，视觉回坐标。
版本：3.0.0 ｜ 设备：MaixCAM2（AX630C）｜ 串口：UART4 / 115200

---

1. 它能干什么

命令场景回什么
A启停区START,<区号>,x,y,w,h（右侧有灰色道路=1 号，没有=2 号）
T,<任务码>任务码TASK,<第一批颜色>,<第二批颜色>
C,<1~4>原料区找指定颜色PICK,颜色,x,y
D / E粗加工区 / 暂存区圆盘DISC,x,y,dx,ok（ok=1 表示环已对中）
F码垛STACK,x,y（不含高度，由 STM32 自己算）
G前方障碍物OBST,x,y,w,h,mm 或 CLEAR
R复位/握手READY
Z结束OK

失败统一回 NONE[,标签]。任务执行中再发命令会收到 BUSY；发 R 会立即中断。

2. 它是怎么"看"的

经典 CV 负责定位（LAB 阈值找色块、霍夫找圆）
AI 负责判色（yolo11n-cls，6 类；置信度不够自动退回阈值）
精度链：坐标反畸变（RMS 0.35px 标定）→ 缩回 640×480 → 9 帧平均
  • AI 模型：/root/models/cls11n.mud（+ 两个 .axmodel）
  • 量化后精度：验证集 99.38%（与 float 完全一致）
  • AI 缺失/报错时自动退回纯阈值，不会导致程序不可用

3. 装到板子上

# ① 让出 UART4（只需一次，然后重启板子）
python3 /root/disable_comm.py --apply
#    或：打开设备上的「Maix Toolbox」→ Disable Maix Comm

# ② 传模型（三个文件放同一个目录）
scp _converted/cls11n.mud _converted/cls11n_npu.axmodel _converted/cls11n_vnpu.axmodel \
    root@<板子IP>:/root/models/

# ③ 装 APP
scp dist/maix-yyb_mover-v3.0.0.zip root@<板子IP>:/root/
app_store_cli install /root/maix-yyb_mover-v3.0.0.zip
⚠️ 关掉 Maix 通信后，MaixVision 的 UART 连接就不能用了，改用网络(TCP)/SSH。

4. 接线

MaixCAM2 A21 (UART4_TX) → STM32 UART 的 RX
MaixCAM2 A22 (UART4_RX) → STM32 UART 的 TX
GND 必须共地，115200 8N1

5. 常用参数（maixcam_app_v2/config.py）

参数默认什么时候改
USE_AITrue模型没装想跑纯 CV 时设 False
AI_MIN_PROB0.60AI 判色太保守/太激进（先开 AI_DEBUG_PROB 看分布）
AI_VETO_OTHERTrueAI 判成 other 时是否丢弃候选
UNDISTORT_ONTrue换镜头/重标后
UNDISTORT_MAX_SHIFT48反畸变"防呆"上限（px）
CENTER_FILTER_N9坐标抖动大就加大，反应慢就减小
ALIGN_ONTrue圆盘是否主动发 MOVE 微调
ALIGN_TOL5环 2 对中容差（px）
STACK_COLOR_VOTEFalseF 是否也做颜色投票
OBST_STABLE_FRAMES5G 的反应速度
TH_RED/TH_YELLOW/TH_BLUE/TH_GREEN样本集统计值换灯光/换场地后跑 tools_analyze_lab.py 重算
ROI_MATERIAL 等起手值现场按机位调整

6. 上板自检（照着打勾）

[ ] 启动日志：DET 640x480 → 640x480 | 去畸变 开 | 多帧平均 9
[ ] 启动日志：[AI] 已加载: /root/models/cls11n.mud (labels=...)
[ ] STM32 发 R → 收到 READY
[ ] A：有路/无路 → 区号 1/2，屏幕上 ratio 数值合理
[ ] C：红黄蓝绿都能命中，日志里 来源=ai / cv
[ ] D/E：会连续发 MOVE 并收敛到 |dx|≤5，ok=1
[ ] F：STACK,x,y（不含高度）
[ ] G：OBST/CLEAR 不来回抖
[ ] 断开相机 → 收到 ERR,camera（可选验证）

7. 常见问题

现象先查什么
串口打不开UART4 是否被 Maix 通信占用（先 Disable Maix Comm）；ls /dev/ttyS4
能开但收不到命令TX/RX 是否交叉；GND；波特率 115200
AI 没生效日志有没有 [AI] 已加载；/root/models/cls11n.mud 是否存在
颜色老判错现场重标 LAB 阈值（TH_*），或调 AI_MIN_PROB
坐标整体偏是否开了去畸变但 STM32 的像素→mm 仍按原始像素标定
圆盘一直不等看 MOVE 方向是否反了（dx>0 期望向右）；或 ALIGN_TOL 太小
启停区老判 2 号看屏幕 ROAD YES/no 和 ratio，调 ROI_ROAD/TH_ROAD
码垛超时确认 STACK_COLOR_VOTE=False；ROI 是否对准
