# 路段连续衔接与原地转向

比赛默认启用连续圆角。车头沿用当前目标航向时，底盘可连续改变移动方向。需要切换车头目标航向时，先确认四轮停稳，再原地转向，然后继续作业或离站。独立避障测试沿用分段路线。比赛开启避障后，已走过的道路可保持车头连续换轴。需换车头航向或驶入需要采样的未知道路时，仍进行对应的停稳和测距交接。工位的回 2 号环可以与收臂并行，下一路段满足连续条件时直接接入。B→A/C 回程原 60 mm 偏移在主段末尾渐变完成。

## 分段对照模式

- 显式设置 CAR_RUN_CORNER_ENABLED=0 时，runimu A/C 采用原路表分段折线路径，起终点 60 mm 侧移按独立线段执行。
- 普通道路进入 `STOP_FORWARD` 时，发送零速并确认四轮新鲜状态、位置和速度。道路交接使用 `CAR_ROUTE_STOP_RPM`（默认 ±2 RPM），航向到位后直接接续下一动作。最终回库停稳仍使用 `CAR_VELOCITY_STOP_RPM`（默认 ±1 RPM）。
- 原料、粗加工和暂存进站先完成道路停车再转头。转头确认到位并收到四轮停稳反馈后进入机构和视觉的到站交接。
- 同向共线道路仍使用原贯通逻辑，例如F→E→D不因直线经过E增加停车。真正改变轴向的B/E等节点、起终点折线以及到站交接会经过分段停车。
- 手动test、工位视觉微调和obstacle退回沿用各自的反馈和交接条件。

## 参数

| 参数 | 分段对照值 | 含义 |
|---|---:|---|
| CAR_RUN_CORNER_ENABLED | 0 | 比赛采用分段停车换向 |
| CAR_ROUTE_NODE_STOP_MS | 0ms | 四轮停稳后直接接续下一动作 |
| CAR_ROUTE_STOP_RPM | 2 RPM | 比赛道路动作交接的四轮反馈阈值 |
| CAR_ROUTE_TURN_HANDOFF_CDEG | 300 | 转向接道路平移时允许带入 3° 余角，单位为 0.01° |
| CAR_VELOCITY_STOP_RPM | 1 RPM | 工位转向到位、最终回库、手动测试及避障停车等场景沿用原阈值 |

比赛仍为前后250RPM，连续同向横移总长≤1200mm用250RPM、更长200RPM。横移150RPM/s、前后240RPM/s、减速200RPM/s以及左28/右35mm每米补偿保留。路表节点、坐标和任务顺序没有重写；取消切角后实际路径按原折线经过节点。
