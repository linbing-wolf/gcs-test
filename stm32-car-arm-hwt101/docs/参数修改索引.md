# 参数修改索引

以当前工作树的配置值为准。参数宏的行尾说明记录用途、单位、适用范围和取值约束。修改编译期参数后重新构建对应目标并下载。串口命令试调只对当前运行生效，标定确认后回填配置。

| 现场问题 | 去哪里找 |
|---|---|
| 前进、后退或左右横移距离不对；侧移时串轴 | [car_config.h](../src/car_config.h) 的「四向距离标定与偏移补偿」。普通左移和右移各有独立系数，工位微调用共用轴系数。 |
| 调车速、加减速和停车停留 | [car_config.h](../src/car_config.h) 的「速度、加减速与停车」。软件斜坡用 RPM/s，驱动器加速度是独立档位。 |
| 调航向、位置 PD 和到位 | [car_config.h](../src/car_config.h) 的「闭环增益与到位」。原地转向、普通行驶分档、行驶固定增益、两类正交位置纠偏、工位驻车保持分别标注。 |
| 调比赛道路交接的停稳轮速和余角 | 在 [car_config.h](../src/car_config.h) 修改 `CAR_ROUTE_STOP_RPM`（默认 2，表示 ±2 RPM）和 `CAR_ROUTE_TURN_HANDOFF_CDEG`（默认 300，表示 3°，单位为 0.01°，0 关闭余角交接），再重新编译烧录。转向接道路平移仍要求四轮反馈、速度指令应答和新 IMU，角速度上限为 2°/s。 |
| 改进站方向、地图停车点、连续过弯 | [car_config.h](../src/car_config.h) 的「道路模式、工位方向与地图」「连续圆角与过弯」。地图与路表联动步骤在文件末尾。 |
| 调粗加工或首次暂存离站补偿 | [car_config.h](../src/car_config.h) 的 CAR_ROUGH_DEPARTURE_EXTRA_MM 用于两批粗加工，CAR_STORAGE_FIRST_DEPARTURE_EXTRA_MM 用于首次暂存，单位均为 mm。进站点由地图参数单独决定。 |
| 调扫码停车点 | [car_config.h](../src/car_config.h) 的 CAR_MAP_SCAN_TOWARD_A_MM 调扫码位置相对 B 沿场边朝 A 的距离。A/C 到内侧行驶线的起步偏移由 CAR_START_INSET_MM 控制，渐变长度由 CAR_START_BLEND_MM 控制，单位均为 mm。改动地图几何后重生成离线路表。 |
| 改原料 J 的左/中/右像素分区，或视觉位移比例和方向 | [station_config.h](../src/station_config.h) 的「原料区 J 像素分区」「视觉纠偏与工位等待」。相机侧、分辨率与串口试调方法见文件末尾。 |
| 调粗加工和暂存的取放落点、环距、第一/二层高度 | [station_config.h](../src/station_config.h) 各工位分组。车载杯取出高度在「车载杯取料与工位模式」。 |
| 调原料抓取、车载杯位、张合爪、收拢和净空 | [arm_config.h](../src/arm_config.h) 的相应姿态、速度、保持与联动分组。手动点动和 PC9 冷启动姿态说明在文件末尾。 |
| 调启动按钮、扫码、IMU 或串口屏 | [car_config.h](../src/car_config.h) 的外设分组和末尾联动说明。 |

## 常用现场顺序

1. **底盘**。实测前、后、左、右四个方向的距离，再调正交补偿或 PD。普通左右横移的系数同时用于比赛、手动单段和超声波避障。单独使用避障固件时重新构建该目标。独立 JY901B 诊断的配置副本需在该工程回填。
2. **工位**。先确认车身停点和观察朝向，再调视觉比例和符号，然后标定环心、各抓点和夹放高度。固定车身时底盘以 2 号环为基准。第二批暂存逐环移车，叠放高度为第一层绝对高度加层高。
3. **机构**。先声明真实姿态再逐轴点动，验证每个环、杯和原料抓点的伸出、下降、释放、抬升与收回。舵机插值时长只决定 PWM 指令衔接，实物跟随、夹持与净空须现场观察。

修改地图内移或道路几何后，先运行 `tools/rebuild-route-table.ps1` 再构建。只调速度、增益、脉冲/mm、工位参数或机构标定时，直接重编即可。底盘、视觉及机构的现有主机测试可检查调参入口和状态机，实车验收还要测距离、夹稳、净空与全程动作。
