# 作业期间航向保持

正式`runimu A/C`发车时，操作者已摆正车身，主控保存开局IMU角度与地图初始朝向的对应关系。原料、粗加工和暂存的两批作业均使用该固定参考，目标由开局角度、工位相对开局的应转角和这段路线已经执行的转向补偿组成。到站、机械臂动作和视觉移车后都不重新取航向零点。比赛中发送 `imu`，额外的 `[route yaw]` 会显示发车角、已累计补偿、当前目标和角差。

原料区 F、粗加工 D 和暂存 H 驻车作业时，四轮低速原地转动保持航向；升降5号、平推7号、云台、载物台、夹爪继续按原状态机运行。保持控制不等待机械臂空闲、不修改抓取姿态或任务顺序、不取消5/7队列、不调用延时。它只纠正车头转偏，不提供前后/左右位置保持。

| 串口命令 | 作用 |
|---|---|
| `loop station on` | 开启各作业区驻车航向保持，默认开启 |
| `loop station off` | 平滑归零并收到四轮ACK、取得零速后的新速度反馈后退出 |
| `loop status` | 查询`encoder`、`gyro`、`station`三个独立开关 |

粗加工 D 和暂存 H 每次进站都以发车参考换算工位目标角，修正量并入本次进站转向。作业中的视觉微调和逐环移车沿用该航向参考。准备向地面松爪时，驻车保持先归零，等四轮停稳再松爪。

驻车航向保持独立于`loop gyro`行驶开关。设置跨普通停止/模式切换保留，复位恢复`CAR_STATION_HOLD_DEFAULT_ON`。只有正式比赛发车已建立参考后自动驻车作业才启用；手动`arm`、独立视觉调试、扫码B点及普通道路行驶不新增保持动作。

参数位于`src/car_config.h`：

| 参数 | 初值 | 含义 |
|---|---:|---|
| `CAR_STATION_HOLD_DEFAULT_ON` | 1 | 上电默认开启 |
| `CAR_STATION_HOLD_KP_X100` | 150 | P=1.5 RPM/度 |
| `CAR_STATION_HOLD_KD_X100` | 30 | D=0.3 RPM/(度/秒) |
| `CAR_STATION_HOLD_MAX_RPM` | 5 | 保持旋转修正上限±5 RPM |
| `CAR_STATION_HOLD_QUIET_CDEG` | 20 | 角差±0.20度 |
| `CAR_STATION_HOLD_RATE_CDEG_S` | 50 | 角速度±0.50度/秒；与角差同时满足时输出0 |
| `CAR_STATION_HOLD_SLEW_RPM_S` | 20 | 转速变化率20 RPM/s；静稳区外整数接口最小非零量为1 RPM |

上述为试调初值，尚无实物稳定性验收。日志`[station hold]`包含开局参考换算后的目标角、当前角差和修正RPM。

保持控制复用机构会话中的四轮接收/查询，独立消费四轮速度ACK；更新周期沿用25ms，只在输出变化时提交四轮速度和同步命令。CAN已有积压超过8帧或阻塞时，让出后台纠偏发送机会，机构与原反馈查询继续推进。视觉移车、固定索引或离站请求到来时，保持先归零、等待四轮ACK及实际停稳，再把四轮控制权交给原执行器；这一交接只等待底盘，机械臂继续运行。子动作完成后保持重新接入，仍使用同一开局参考。

`!`和既有显式全系统停止取消保持并使本轮开局参考失效，不自动重启。反馈缺失、CAN或ACK问题沿用现有告警/等待策略，不新增故障自动停车或机构中止；最后已提交的修正可能保留到恢复。不能以软件并行保证物理上完全不影响夹取，尤其需要实测夹爪接触物料时的扰动。

验证入口为`tools/verify-station-hold.ps1`：两组上电默认配置，A/C真实发车参考采集、四个地图方向和角度跨界、偏到站姿态不重取零点、独立开关、限速/静稳区、CAN拥堵、缺ACK/旧IMU、显式急停，以及两批原料、粗加工和暂存有驻车纠偏时机械臂继续推进、两批 D/H 站内移车受扰后纠偏、地面松爪停稳及离站交接。主机测试及固件构建不代表已经烧录或完成实车验收。
