# 原料 H、HDISC2 与 J 自动抓取

## HDISC2 适配

比赛两批原料均使用 FIXED_3J 流程。H 的有效终包格式为 `HDISC2,arrival,n[,color,x,y...]`。arrival 取 0 或 1，n 取 0～4，颜色码 1～4 且互异，坐标范围为 X=0～639、Y=0～479。arrival 和颜色坐标用于诊断。两种 arrival 以及 n=0 都进入同一个三轮 J 流程。

1. 到原料工位并回观察姿态，发一次 H，等待有效 HDISC2。
2. 执行完 H 之前排队的 MOVE/MOVEXY，并完成四轮停稳交接。
3. 发 J，等待合法的 `MSTATE,1,...`。按本批任务的当前目标色坐标选固定姿态，抓取并放回对应车载杯。
4. 前两件装杯后回观察姿态才发下一次 J。第三件装杯后沿用离站衔接。

BUSY、非法终包和 CRC 错误保留等待。H 收到 `NONE,H` 或 H/J 收到明确 `ERR,...` 时，记录原包、终止工位并发送 R，等待 READY。手动 `vision h` 仍可查看 `HCOLORS` 和旧 `HDISC`，比赛自动 H 要求 `HDISC2`。MaixCAM A1/SCL 接 STM32 PG15，A0/SDA 接 PD7。I²C 地址为 0x42，沿用 32 字节邮箱和 96 字节载荷上限。

左右以机械臂133°垂直朝向原料盘为基准。现有配置名沿用旧名称，但表示固定的物理抓点：

| 固定抓点 | 现有配置前缀 | slide/mm | lift/mm | yaw/° |
|---|---|---:|---:|---:|
| 右侧 | ARM_RAW_PAST | 165 | 90 | 150 |
| 中间 | ARM_RAW_CURRENT（默认引用ARM_PICK） | 7 | 90 | 133 |
| 左侧 | ARM_RAW_NEXT | 165 | 90 | 117 |

比赛根据本轮 J 坐标选择以上姿态。相机画面方向和机械臂左右对应仍需实车核对。

## J停稳门槛

payload为`MSTATE,done,n,color,x,y,state,...`，字段总数严格为`3+4*n`：

- `done`为0/1，`n`为0～4；颜色码为1～4且不得重复，不依赖记录排列顺序。
- 每个state为0运动、1停稳、2证据不足；坐标按有符号16位整数解析。
- `done=0`始终等待，包括`MSTATE,0,0`；不因过程包中所有state恰好为1而提前放行。
- `done=1`必须n>0且全部state=1；错误CRC、错误字段、非法终包不改变等待状态。
- J只报告当前可见物料。合法终包不代表盘中所有不可见物料也已停止；J终包还必须包含下一任务目标色，并且该颜色坐标只命中一个已配置抓取区域。目标缺失、区域外、图像越界或区域重叠时保持等待，不沿用旧H位置。
- 没有自动观察总超时、自动重发或默认到位。无论没有回复还是收到done=0，都保留等待；25秒只提示继续等合法终包。
- J请求须实际被相机取走才能接受本次MSTATE。BUSY、非法终包和CRC错误不能代替合法done=1。

J 在机械臂高位收回且处于 133° 观察角时发送。首件前的 J 等待 H 及底盘纠偏完成，后续 J 等待上一件装杯完成。等待期间不运行下一条转云台/抓取动作，原有独立驻车航向保持继续按已有规则运行。

## 当前图像区域（已合入比赛程序）

HDISC2 和 J 共用同一个图像坐标系。自动抓取用每轮 J 的坐标查区。对应样点为左(136,44)、中(310,315)、右(491,32)。粗分初值见 src/station_config.h。

| 区域 | 固定姿态 |
|---|---|
| X=0～313，Y=0～179 | 左117°／slide165mm |
| X=314～639，Y=0～179 | 右150°／slide165mm |
| X=0～639，Y=180～479 | 中133°／slide7mm |

端点包含，lift保留当前90mm。区域由样点中点推导，是试调范围，不代表覆盖区域内任意坐标都已实测可抓。可在空闲时用`raw region left/middle/right XMIN XMAX YMIN YMAX`逐块调整，复位恢复头文件默认值；持久保存需修改头文件并编译。

三件均以各自的 `[station raw J position]` 记录为准，pose0 右、1 中、2 左。`color`为任务目标，不是抓稳传感器反馈。

## 手动联调与取消

```text
vision h       # 只收新H结果，不自动移车或抓取
vision j       # 只发J、观察MSTATE，不自动移车或抓取
vision status
raw region status  # 查询当前图像区域
raw observe        # J终包无法确定目标位置时，明确重新发J，保留任务和杯位
vision range   # 人工R，取消本地等待并等相机READY
vision clear   # 清会话；未完成H/J会排入R中断相机
!              # 原全系统人工停止；取消H/J并保留R发送
```

`raw observe`只在当前J已完成、但工位仍停留在J等待步骤时接受；不允许覆盖尚未完成的J，不自动定时重发。需要改变观察姿态或区域时用!取消并检查后重测。

成功H/J终包后的正常交接不发送R。人工取消未完成 H/J 或收到本轮明确故障时发送一次 R，急停路径重复取消不丢弃、不重发在途R。R被相机完整读取仍不代表取消完成，必须收到有效READY；READY前的旧业务包不能放行抓取。调用方此时申请的下一条任务会保留，READY后才真正发送，显式再次取消会撤销这条保留任务。J活动时拒绝手动H/J/PICK/D ping覆盖会话。

`vision status`的`[vision cancel] waiting_READY=1 next="..."`表示等待取消确认，不能当作新H/J已在相机端执行。READY必须在R完整交付后收到；启动READY不用于提前放行。取消等待没有自动重发或超时放行。

## 传输和相机配套

外层仍为`AA 55 LEN payload CRC8 0D`，CRC8范围LEN+payload，poly0x07；GPIO I²C地址0x42、32字节邮箱和首字节N=0..31保持。

STM32载荷上限由48扩大到96字节。四颜色正常坐标J报告示例为58字节payload、63字节完整帧，分三次邮箱传输；最大101字节帧可分四次。必须完整组帧、CRC通过后才能推进状态。

比赛配套相机应用需要为 H 回传 HDISC2，并支持每批连续三轮 J。

本次只修改/构建STM32工程，未部署相机、未修改相机持久化参数、未烧录或实车验收。

## 验证入口

- `tools/verify-raw-material.ps1`：两批及 96 组颜色/位置组合，核对 H→J→抓→J→抓→J→抓、每轮目标色坐标和杯位。覆盖三轮各 61 秒不重发等待、ERR 和取消。
- `tools/verify-raw-j-position.ps1`：比赛入口，目标色位置变化、当前样点/边界、缺失/越界/空隙/重叠等待、人工再观察及命令归属。
- `tools/verify-hj-protocol.ps1`：非法字段/CRC/坐标边界、空画面、过程/终包、无应答/连续0不重发、BUSY/实际交付门槛/合法终包及手动R/急停取消。
- `tools/verify-vision-i2c.ps1`：真实软件I²C分支的逐边沿模型，HCOLORS/HDISC、三邮箱J长帧、最大101字节帧、短读及跨会话隔离。
- 固定环位和驻车航向保持专项；必需的heading/arm综合回归及完整ARM编译。两套综合回归既有的自动故障停机断言冲突需单独报告，不能删断言冒充全绿。

用户已指定回退至自动重发之前：当前每个J阶段只发送一次并保留等待，上位机任务调度没有修改。

## 2026-11-24静默J交接适配

后续“第一块后等待J”的接收修复、现场采集要求和尚未实现的双方ACK协议，见[J终包接收诊断与确认协议待办](J终包接收诊断与确认协议待办_20261124.md)。

以`HANDOVER_STM32_H_J_20261124.md`为协议核对依据。相机在无目标、运动中或证据不足时不发过程包，停稳后只发一次`MSTATE,1`；STM32不等待先收到0，也不定时重发J。兼容接收旧过程包但不据此放行。现有96字节payload、跨邮箱组帧、H中间包交错和终包后排空运动FIFO已符合交接，不按文档中的旧仓库48字节描述重复改造。

本轮修复颜色记录额外升序限制，以及取消H/J后缺少R→READY握手的问题。合法HCOLORS/HDISC加入原包日志，HDISC同时记录尚未消费的运动条数；坐标和dx仅记录，不作为额外位移或残差门槛。H预报与终包颜色/方向一致性校验沿用既有契约，交接未给出两者不一致的合法实例，未擅自放宽。

H等待期间同样拒绝`vision ping`额外发送D，避免覆盖相机当前H任务；取消完成前也拒绝ping。该调试入口限制不影响自动工位的正常D/E/F任务。

新增回归先在修改前复现失败，再覆盖无序互异颜色、H/J取消后延迟READY、重复取消/部分R、短读与过早READY、旧终包隔离、60秒静默和跨三片总时长300ms的终包。半帧200ms约束相邻片间隙，测试每片间隙150ms；相机实物分片间隙及物理总线仍待联调。原料区按任务码选色、每次J坐标选固定抓点和三套姿态保持。

完整heading/arm综合脚本仍分别在`verify_entry.c:602`自动故障停机断言、`verify_arm_integration.c:653`载物台并行时序断言处失败。用本轮修改前的vision_link源码与当前其他模块重新构建也在同处失败，未删除或削弱断言。本轮协议专项通过不代表全部综合回归通过，未烧录、未部署相机，也不能证明此前现场等待问题已消除。
