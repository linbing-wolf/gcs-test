# JY901B独立底盘调试程序

横移加速度追加距离实验默认关闭。空闲时发 `imutest extra 1` 启用，`imutest extra 0` 关闭，`imutest extra` 查询开关。仅对 `test l/r` 生效，上电恢复关闭。

开启后每段先采8帧静止加速度做零偏平均。程序将横移方向上的加速度与主轴指令变化作比较，用带泄漏的积分估算沿程缺口。估计缺口超过80mm时按超出部分的1.6倍追加，上限300mm。原目标开始制动、姿态变化超限或数据失效时冻结本段追加量。600ms内无法校零则沿用原距离。日志的 `nominal_mm`、`accel_extra_mm`、`target_mm` 分别是原目标、追加量和实际用于编码器到位判定的目标。

实车对照时可先用相同的距离和速度分别测关闭和开启，记录尺量结果及 `accel_extra_mm`。积分估计会受电机跟随、地面和姿态误差影响，追加值需要实测判断。

## 接线

按用户提供的原理图，U2为原HWT101接口。所示PCB图U2在右，1脚在图下方。

| U2脚号 | STM32侧 | JY901B侧 |
|---|---|---|
| 2 | 5V1 | VCC |
| 3 | PD5 / USART2 TX | RX |
| 4 | PD6 / USART2 RX | TX |
| 5 | GND | GND |

1脚D0和6脚PG7不用连接。默认115200、8N1，JY901B也须为115200并开启标准WIT输出。解析`55 53`姿态、`55 52`三轴角速度、`55 51`三轴加速度/温度、`55 54`三轴磁场和可选`55 59`四元数，各通道独立计时和校验。建议先在厂家上位机确认角度及角速度输出频率50或100Hz，再检查实际数据更新；本程序不自动修改模块波特率、输出频率、校准或磁融合配置。若`imu`显示`rate_samples`不增长，需在模块配置中打开角速度输出；没有新鲜角速度时D项使用角度差分。磁场及四元数也只有模块实际输出合法对应帧才会显示有效，未输出不伪造0值。协议依据：[厂家标准通信协议](https://wit-motion.gitbook.io/witmotion-sdk/wit-standard-protocol/wit-standard-communication-protocol)。

无线调试仍用U6：1脚3.3V、2脚GND、5脚PB0 TX→无线模块RX、6脚PB1 RX←无线模块TX，115200 8N1。

## 机械臂固定方式

**上电前人工确认实际升降135mm、平推0mm，并将机构摆在所确认的收拢姿态。程序不做自动寻零，也不通过反馈证明两轴已经到这个位置。**

| 部件 | 固定目标 | 当前标定PWM |
|---|---:|---:|
| 云台 PA3/TIM2 CH4 | 0° | 1975 μs |
| 夹爪 PA1/TIM2 CH2 | 45° | 826 μs |
| 载物台 PA2/TIM2 CH3 | 20° | 648 μs |
| 平推7、升降5 | 保持人工摆放的当前静止位置 | 只发送使能，不发送位移或回零 |

PWM由TIM2持续输出。云台/夹爪/平台会驱动到该固定PWM对应的位置，因此上电前应摆在对应姿态。两轴保持力取决于真实驱动器与机构，仍需实物确认。诊断中不执行`arm_update()`；`arm ...`动作和`claw ...`全部拒绝。`arm status`只说明固定配置，不代表实测位置。

`!`、`stop`、`s`、`z`保留人工停止：四轮停止，5/7收到停止请求，但不失能、不撤销固定PWM，不自动回零或松爪。之后等待新的人工底盘指令。

## 第一次联调

上电不自动跑车或路线。先发送：

```text
imu
arm status
loop status
```

`imu`应显示`fresh=1`、样本数持续增加、校验错误不持续增长。人工改变朝向时Yaw应随实际变化；左转应增加，跨±180度正常。`roll_cdeg`/`pitch_cdeg`为同一角度帧的倾角，超过`CAR_IMU_MAX_TILT_CDEG`（默认3000=30度）时`tilt_warn`增加，并使D项改用Yaw差分，合法Yaw保持有效；车身明显倾斜应人工检查安装与支撑。`rate_cdeg_s`为原始Z轴角速度（0.01度/秒，逆时针为正），`rate_fresh=1`且`rate_samples`持续增加表示100ms窗口内有角速度帧；控制日志中的同名字段是滤波后的值。`accel_body_mg`为含重力的机体三轴加速度，单位mg，静止不要求三轴全为0。若安装方向相反，在本目录`CAR_IMU_YAW_SIGN`调整（同时作用于角度和角速度）；不能用它补偿传感器侧立或轴向装错。确认真实角度与日志一致后，再开始运动。

从低速短段开始，逐行发送：

```text
test
dist 500
rpm 60
l
```

每次等待`DONE_BY_IMU_ENCODER`和实际停稳，尺量后恢复起点，再单独发送`r`、`f`或`b`。不自动返回，不自动执行下一段。逐步验证后，可设置`dist 2000`、`rpm 200`复测；RPM是上限，实际速度看`left_cmd`/`v_cmd`及四轮反馈。原200RPM日志的大幅摆头并未因更换传感器而被证明解决。

手动单段`f/b/l/r`及定角转向的完成判据已补齐：除了原距离/航向和零速命令ACK，每个轮子都须有严格晚于该次零速命令的新鲜速度反馈，且各自处于`CAR_VELOCITY_STOP_RPM=1`规定的±1RPM范围。仍有4～7RPM或反馈未刷新时保持任务并继续轮询，不能仅因零速命令已发就打印DONE；`!`仍能人工取消。该修复不增加自动故障停机、重启或固定延时，也不改变被本入口禁用的工位行为。日志中的停稳是驱动器反馈证据，仍不替代实物轨迹/打滑测量。

定角转向单独测试：

```text
turn
rpm 60
left90
```

完成后再单独测试`right90`、`left180`、`right180`。返回平移用`test`。

## 纠偏与参数

```text
loop gyro on
loop encoder off
loop forward on
loop status
```

`loop gyro`控制平移航向反馈，`loop encoder`控制普通前进/后退的左右横偏反馈，`loop forward`控制普通左右横移时的前后漂移反馈。手动`test l/r`在gyro+forward均ON时启用下述固定参考系控制；手动`test f/b`在gyro+encoder均ON且`CAR_STRAIGHT_HOLD_ENABLED=1`时启用。关相应正交反馈或gyro则保留原车身轴控制及开关行为，两个正交开关互不替代。编码器距离到位和新鲜IMU/四轮反馈要求一直保留。`loop station`在本程序不可用。固定机构不需要启用机构会话，因此不要发送`arm on`。

`loop forward`默认ON。前后保持P初值0.3RPM/mm、死区2mm、上限8RPM、变化率60RPM/s，参数为`CAR_LATERAL_HOLD_*`（死区复用`CAR_STRAIGHT_HOLD_DEADBAND_MM`）。固定参考系模式新增D初值0.10RPM/(mm/s)，`CAR_LATERAL_HOLD_KD_X100=10`，设0可关闭D；`CAR_LATERAL_HOLD_RATE_FILTER_MS=100`为速度差分的一阶滤波时间常数。D由连续的新共同采样位姿前后误差除以实际时间差得到，不取加速度积分，不在每次主循环反复微分；首份位姿仅建立速度基线。向外移动时加大回拉，已向目标靠近时提前减小回拉，并允许D产生制动方向请求；前馈/P/D总和再经过原8RPM及变化率限制。初值不是实车调参结论。

四轮位置按共同时间插值后投影，避免直接把异步CPOS拼成漂移；扣除原有固定前移补偿后再反馈。固定参考系模式下，8RPM限制的是起步参考系前后位置反馈；它不再被末端主横移速度压成0。角度变换所需的车身前后速度分量可能超过8RPM，两者含义不同；最终四轮仍受原轮速上限及航向优先分配约束。未启用固定参考系模式时保留原主轴速度余量限制，且不加本次D。编码器只能估计轮运动，不能观测没有反映在轮编码器中的地面打滑。

### 固定起步坐标系路径控制

用户针对“途中车头偏了、最后回正但位置留下偏差”授权修复，并随后要求继续统一四方向。当前手动`test f/b/l/r`均可使用；定角转向、工位/双轴/障碍路径及父比赛程序不扩展此逻辑。

- 每段起步定向完成后，固定本段目标航向为参考。轮位移按共同采样时间插值，Yaw保留64份真实角度帧并插值到同一时刻，用相邻航向的中间角旋转本次位移增量，累计`pose_forward_mm/pose_left_mm`。Yaw跨±180度及毫秒计时回卷均按原符号处理。
- 沿程控制使用起步参考系对应主轴位移：l/r使用left，f/b使用forward。主轴和正交速度在同一参考系生成，再换算为当前车身速度，同时沿用原航向PD；两个轴脉冲/mm不同，f/b前向10.00、后向9.98独立保留，速度变换按本段方向换算。
- 末端允许低速正交补位：l/r补前后，f/b补左右；f/b沿程超差也与l/r一样回拉。只有沿程位置在±1mm、相对参考线的正交误差在±2mm、航向满足原±0.8度及角速度判据、四轮速度反馈在±1RPM，才报告完成；最终共同采样位姿及各轮速度反馈均须晚于本次零速命令。门槛只用于平移终点，不阻塞起步定向。
- 当前固定补偿：l/r前移补偿0/0，f/b左右补偿0/0mm/m。2026-11-23用户确认300mm/60RPM距离及方向正常、1000mm时前进右偏10mm/后退左偏20mm；对应日志仍请求-10/+20mm侧移，终点估计为-12/+19mm。因此本次仅取消f/b旧侧偏目标，使直行参考线侧移为0；保留正交位置闭环，距离系数、P/D、制动、限幅和横移参数不变。只修改本诊断，不回写比赛工程。
- 航向P/D、200RPM巡航上限、横移120RPM/s制动及400ms预留、前后保持8RPM上限与60RPM/s变化率保持。f/b沿用200RPM/s制动/200ms预留和左右P=0.5RPM/mm、20RPM上限，新左右D为`CAR_STRAIGHT_HOLD_KD_X100=10`（0.10RPM/(mm/s)，0关闭），差分滤波复用100ms；f/b正交变化率仍沿用150RPM/s。`!`仍立即请求停止并取消，无自动下一段。
- 不外推缺失Yaw，不跨超过250ms的航向缺口重建途中位置。若历史无法覆盖该段轮位移，位姿不再被假装刷新，沿用告警/等待策略保留任务及最后速度命令；需人工`!`，恢复连续采样后重新摆回起点重测。它不是掉线自动停车功能。

新增日志：`path_hold=1`表示启用固定参考系；`pose_valid/pose_age_ms`描述位姿估计时效；`pose_forward_mm/pose_left_mm`为相对起点的前向/向左估计位移；`distance_mm`为主轴位移乘本段行进方向。l/r的`cross_axis=START_FORWARD`，f/b为`START_LEFT`；`cross_mm`是对应正交轴相对含补偿参考线的误差。`cross_rate_mm_s`为该误差的滤波速度，`cross_d_rpm`为未限幅D请求；l/r正值向前，f/b正值向左。`path_forward_cmd/path_left_cmd`为参考系请求，其中正交项包含前馈/P/D、限幅和斜坡，`v_cmd/left_cmd`为变换后的车身请求，`applied_*`仍是已提交四轮指令的反解值。关闭路径保持后`cross_axis=FORWARD/LEFT`恢复车身轴含义，不能把两种误差直接混用。

首次复测用`loop gyro on`、`loop forward on`、`loop encoder on`，以300～500mm/60～120RPM分别测试四方向，每段恢复物理起点，确认正交补位方向后再测2000mm/200RPM。记录实际沿程、正交尺量误差及过程摆头；日志中的最终估计误差小不能证明过程稳定或地面达到同等精度，打滑及传感器航向误差仍会进入里程计。用户最新200RPM日志左移最大角差21.04度、过程估计偏后65mm、最终补回2mm，仅说明补位流程能收敛，不能据此声称高速稳定已经解决。

新日志中`rate_source=GYRO/YAW_DIFF`说明D项来源，`cross_axis=FORWARD/LEFT`说明编码器漂移估计所在车身轴，`cross_mm/cross_rpm`为漂移与纠偏请求。`applied_v/applied_left/applied_turn`是已提交四轮命令的反解值，不是实测车速；`wheel_rpm_raw`仍是驱动器反馈。

运动日志新增加速度观测，与上述控制字段同一行输出，维持原500ms打印周期：

| 字段 | 含义 |
|---|---|
| `acc_fresh` | 最近0x51帧是否有效且不超过250ms；未输出或已过期为0 |
| `acc_age_ms` | 最近0x51帧接收年龄；从未有合法帧时为-1 |
| `acc_mg` | 传感器X,Y,Z机体加速度，含重力，单位mg（1000mg=1g）；从未有合法帧为NA |
| `acc_n` | 本窗口主循环实际处理到的新鲜、不同序号帧数 |
| `acc_mean_mg` | 同一窗口XYZ样本均值，含重力、未减零偏，单位mg；比单个振动峰值更适合看起步/制动趋势 |

安装方向已经300mm/60RPM的`f/r/l`试验核对：用户确认实车分别前进/右移/左移，前进起步主要使X增大，右移使Y减小，左移使Y增大，因此当前输出对应**+X朝车头、+Y朝左、+Z朝上**。这替代此前口述的X左右/Y前后；`imu`状态末尾已修正说明。原始XYZ不交换、不反号，电机方向不变。该结论不等于零偏或磁标定已经完成。

磁场模长是原始LSB幅值的观测，不是标定后的地磁强度，也没有设置未经实测的干扰停机阈值。各通道时间戳独立，不能因为同一日志行就把它们当成严格同步采样；`fresh=1`也不等于完成了磁标定或证明模块当前使用九轴融合。上位机需按实际固件确认并配置输出项；本程序不写模块配置。

### 九轴数据的使用范围

航向P项使用模块输出的Yaw，D项优先使用新鲜`0x52`角速度，超过100ms或明显倾斜时使用Yaw差分。角速度独立于角度序号更新，两种来源共用30ms一阶滤波，避免直接切换造成D项突跳；到位确认仍必须依靠真实的新角度帧。完整保留协议±2000度/秒范围，不再将解析值裁成±300度/秒。轮速饱和时保留转向修正、缩减平移，纠偏不会因全轮统一缩放而被削弱。现有P/D初值及20RPM行驶纠偏限幅保留，需由实车日志重新标定。

加速度、三轴角速度和三轴磁场已完整采集，用于把制动、偏航、晃动和磁场变化放在同一组日志中分析；温度、姿态角和可选四元数也独立记录。加速度没有直接积分进位置闭环；磁力计没有额外叠加一层控制，模块输出Yaw是否使用磁融合取决于传感器自身配置。九轴不等于九个闭环。当前实际组合是航向角/角速度PD、沿行进方向的编码器距离反馈、可切换的正交方向编码器位置反馈。X/Y正向已验证，静止零偏和模块磁标定仍未确认，不据此直接增加加速度/磁场驱动输出。没有新增四轮速度PI；需要先确认驱动器内部控制及真实反馈时延。也没有足够实测依据宣称编码器已达到毫米级地面精度。
