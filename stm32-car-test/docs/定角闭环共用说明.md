# 定角闭环：单次测试与导航共用

更新：2026-10-14。`left90/right90/left180/right180` 和 `runimu A/C` 共用连续IMU速度控制；`tl/tr` 和旧 `run A/C` 保留原位置脉冲模式。当前操作、参数、日志及完成判据以 [连续转向与直行航向闭环](连续转向与直行航向闭环.md) 为准。

## 单独测试

普通命令逐条带换行发送，首次使用30 RPM上限：

```text
!
turn
imu
rpm 30
left90
```

`imu` 应为 `fresh=1`。当前保持 `CAR_IMU_UART_ENABLED=1`。每个定角命令的目标相对受理时真实航向计算；没有新角度会拒绝，不回退到原始脉冲。左右180°保持指定方向并处理±180°跨界。

受理后每个新IMU样本更新角差和角速度，PD连续调整四轮速度，接近目标减速、过冲后回修。完成需角度/角速度稳定及四轮新速度反馈停稳，不使用3600固定位置脉冲，也不等待位置模式到位位。`DONE_BY_IMU` 后才可发下一次定角；不会自动前进或恢复节点确认。`!` 取消任务，不自动续跑。

## 代码入口和职责

单次入口仍在 `src/main_table_nav.c`：

```c
start_heading_turn(+90, turn_rpm);  /* 左转，返回受理状态。 */
start_heading_turn(-90, turn_rpm);  /* 右转，独立调用示例。 */
```

不能同时提交两行。返回1仅表示受理，主循环 `firmware_step()/run_update()` 必须持续推进；最终观察 `RUN_DONE/RUN_FAULT/RUN_STOPPED`。

共享模块 `src/heading_control.h/.c`：

- `heading_control_start()` 保存起始实测航向并建立相对目标。
- `heading_control_update()` 只用新样本累计转角，计算误差、测量角速度及稳定性。
- `heading_control_rpm()` 计算带阻尼和限速的旋转RPM。
- `heading_control_wheels()` 合成前进和旋转分量，沿用四轮安装方向映射。

导航把固定道路方向转换为相对目标，再调用同一核心。转向完成后保留同一个目标供直行纠偏，不以当前有误差的姿态重新建立基准。电机批次ACK、四轮位置/转速/状态轮询、停稳确认、急停和故障处理在入口文件统一实现，不能仅调用纯角度模块就认为电机已执行。

完成后新增0.5/1/2秒只读角度观察，用于核对停后变化；新任务会取消观察，不会自动回修或继续运动。当前电脑及ARM结果见 [地图与后退验证](../evidence/地图起点与后退验证.json)。本轮没有下载或实车验收；此前 [连续闭环验证](../evidence/连续航向闭环验证.json) 和 [共用核心验证](../evidence/定角闭环共用验证.json) 只代表各自旧版本。
