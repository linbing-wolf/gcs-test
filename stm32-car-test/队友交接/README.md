## 三句话结论

1. **偏移的主因不是"控制不稳"，而是"横向不可观测"**：航向环只锁车头角度（且有 0.8° 死区），
   轮式里程计只测轮子转了多少；两者都看不见"车整体横着挪了"。
2. **两个可直接修的系统误差**：`CALIBRATED_PPM_Y` 未按实测修正（前进偏长约 2%）、
   航向死区 0.8°（每米横偏约 14mm）。
3. **提速的前提是先闭环**：90→120 RPM 能省约 8 秒，但打滑会同步放大；
   必须"一次一档、三圈一测"，且同步放大航向修正权限、重标 PPM。
