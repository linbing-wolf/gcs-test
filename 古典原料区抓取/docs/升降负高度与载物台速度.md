# 升降负高度与载物台速度

比赛程序允许升降目标为−20～135mm，最高及收拢位置仍为135mm。0是原坐标零点；`arm lift -5`表示到原0点下方5mm的绝对位置，不是每次再下降5mm。负数支持由原解析器和轴控制计算完成，工位程序的高度字段改为有符号16位，避免负数变成正数。

本次只扩大软件可接受范围，没有改变粗加工/暂存的现用目标高度，也没有修改原料、载物台取放高度、净空、路线或底盘参数。软件下限−20mm不等于已实测机械最低位置。

## 在哪里调

| 用途 | 文件 | 参数 |
|---|---|---|
| 升降允许下限 | `src/arm_config.h` | `ARM_LIFT_MIN_MM=-20` |
| 最高与收拢 | 同上 | `ARM_LIFT_MAX_MM=135`、`ARM_LIFT_HOME_MM=135`，本次不改 |
| 粗加工放料高度 | `src/station_config.h` | `STN_ROUGH_PLACE_LIFT_MM`，当前5 |
| 粗加工抓回高度 | 同上 | `STN_ROUGH_LIFT_MM`，当前5 |
| 暂存第一层放料高度 | 同上 | `STN_STORAGE_LIFT_MM`，当前5 |
| 暂存第二层 | 同上 | 基础高度加`STN_STORAGE_LAYER_LIFT_MM=60`；降低基础高度会同步降低第二层 |
| 载物台转动插值时间 | `src/arm_config.h` | `ARM_SERVO_TIME_MS`由300改为200ms |

在已确认真实姿态、机构会话已就绪时，可先用`arm lift 0`，完成后逐步试`arm lift -2`、`arm lift -5`等，测出工作高度。再将实测绝对高度填入对应工位宏并重编译。三处地面高度互相独立，不需要改最高位置或载物台取放高度。

载物台200ms是目标PWM插值时长，缩短后更快发完目标，舵机本身没有到位反馈。云台100ms、末端保持40ms、夹爪30ms及合爪保持50ms均不改变。实际能否跟上新插值并保持物块稳定仍需实测。

## 验证

`tools/verify-negative-lift.ps1`覆盖手动0→−5→−20、脉冲方向与幅值、−21/136越界拒绝、回135，以及两批粗加工/暂存（含第二批码垛）的负高度。工位使用测试专用−10/−15mm，覆盖默认直接搬运、关闭直接搬运及串行三个配置；正式工位参数未被这些测试值覆盖。另覆盖载物台200ms与云台/夹爪独立计时、并行换盘及人工急停。

原料区、J位置刷新及驻车保持另行回归，完整ARM构建和HEX/AXF载荷一致性单独核对。必需综合回归仍可能触及既有自动故障停机旧断言；不通过修改断言或恢复旧停机策略掩盖该冲突。主机测试和构建不代表实车验收；本次不烧录设备。
