# PC9长短按选择启停区

适用于当前比赛固件。

- 短按：按住不足1000ms后松开，从C出发，执行原`runimu C`路线并返回C。
- 长按：按住至少1000ms后松开，从A出发，执行原`runimu A`路线并返回A。
- 两种操作都在松开并通过30ms消抖后请求启动；按住期间不启用机构或发车，不会先触发C再切换A。
- 按下、松开均使用原30ms消抖。按住时长按两端电平开始稳定的时刻计算，松开消抖不计入按住时长。

接线不变：PC9内部上拉，按钮另一端接GND，按下为低电平。上电已经按住不启动，须松开再重新按。运行中再次操作不重启或切换路线；准备中再次操作不覆盖已选起点。`!`、`s`及原机构停止/关闭取消待启动；持续按住期间被取消后，松开不会再次请求启动。

冷启动前，将平推人工摆在 113 mm、升降摆在 135 mm，保持夹爪和载物台空载，并留出云台、载物台回正空间。车身按原路线要求摆放。平推起始位置由 `src/arm_config.h` 的 `ARM_PC9_START_SLIDE_MM` 设置，代码使用人工摆放作为相对位移基准。

松开按钮并消抖后，程序预检四轮、IMU 和机构反馈。首段平移发令时，平推收回至 0 mm，云台回到 0°，载物台回到 1 号位（20°），夹爪张开至 40°。平推用编码器反馈确认相对位移，三路舵机按目标 PWM 和现有时序交接。若首路走完或需要先绕障转向时初始化仍在进行，程序等它完成再继续。

阈值参数在`src/car_config.h`：`CAR_START_BUTTON_LONG_PRESS_MS=1000u`；消抖参数为`CAR_START_BUTTON_DEBOUNCE_MS=30u`。修改后须重新编译和烧录。

验证命令：`tools/verify-button-start.ps1`。专项覆盖短/长按、999/1000ms边界、抖动、上电按住、计时回绕、人工停止取消、准备中保留起点、行驶中拒绝重启，以及四项初始化随首段起步、延迟平推反馈时的路段交接、并行期间停止、A/C 完整 8 阶段路线。主机模型需要实车验证。
