# 编码器底盘分别合入比赛与避障测试

操作者最终确认：撤销融合/仅模块位移实验，只使用编码器位移，再把当前独立底盘分别合入比赛和避障测试。IMU航向、角速度PD及分速增益保留。没有将两种任务入口相互合并，也没有将诊断固定机械臂/禁用比赛功能的入口复制到比赛。

## 构建入口与范围

| 程序 | Keil入口 | 保留功能 |

| 比赛 | `keil/TableNavigation.uvprojx` | PC9 A/C启动、扫码、原料H/J、机械臂、粗加工/暂存、驻车航向保持 |
| 避障测试 | `diagnostics/ultrasonic-chassis/Ultrasonic_Chassis.uvprojx` | 双超声波、300/550mm阈值、封路/退回、剩余任务规划、独立无线接口；原本禁用的机构/视觉/扫码仍禁用 |
| 独立底盘 | `diagnostics/jy901b-chassis/keil/JY901BChassisTest.uvprojx` | 保持本次撤销后的编码器版本与固定机械臂，不参与父程序任务编排 |

前两个入口原本就共用父目录`src/main_table_nav.c`、`car_config.h`和传感器/航向模块，通过`CHASSIS_OBSTACLE_TEST`区分。此次在共用底盘层合入，再分别全量构建；两套HEX用途不同。

## 合入的底盘行为

- JY901B接原U2 USART2接口，MCU波特率改115200；被动接收，不写模块算法、校准或输出配置。0x52三轴角速度独立时效，Z角速度优先用于D，过期或大倾斜时回到Yaw差分，两种来源均经30ms滤波；0x51/54/59只观测。
- 普通道路及`test f/b/l/r`将共同时间四轮CPOS增量按对应Yaw旋转到本串起步坐标系，再把路径速度换回当前车身。沿程距离和正交位置均来自编码器。没有`loop displacement fused/imu`入口或加速度积分模块。
- 同向道路连续通过节点时，位姿累计不重取起点，但当前路段里程扣除`encoder_offset_mm`，避免F→E→D等串联道路重复计程。换向仍按原分段流程停车、停稳并保留200ms节点停留。
- 前后方向P=0.5RPM/mm、D=0.1RPM/(mm/s)、20RPM上限；横移前后P=0.3、D=0.1、8RPM上限；位置差分用真实共同采样间隔和100ms滤波。普通/手动平移末端允许正交低速补位，沿程±1mm、正交±2mm、原航向条件以及新鲜四轮停稳反馈同时满足才完成。判据不是地面精度承诺。
- 航向分速表按主轴速度斜坡幅值插值，不按`rpm`命令上限选档。前后60/120/200RPM均P1.5/D0.3；横移P1.5/1.8/2.2，D均0.3。这些是当前试调值，不是最优标定。最后10mm保留P2.5/D0.3和60RPM/s转向斜坡；原地转向、视觉/索引、圆角及障碍返回不使用这张分速表。
- 普通/手动平移轮速饱和时保留航向修正，缩减平移；视觉、固定索引、圆角和障碍返回保留原混控分支。手动平移与定角转向必须等待零速命令之后四轮各自新速度进入±1RPM才完成。
- 横移的制动速度曲线和斜坡共用120RPM/s、400ms预留；前后仍为200RPM/s、200ms。起步仍普通前后240、横移150RPM/s。比赛前后250RPM、横移总长≤1200mm上限250RPM/更长200RPM、障碍退回60RPM保持。

视觉MOVE/MOVEY/MOVEXY、站内固定索引、作业目标/顺序、原料J格式/单次发送与区域选点、机械臂参数均未复制诊断版本；父目录相关模块源码哈希与合入前核对。正常航向采样统一使用新的角速度处理，工位与原地转向的参数表保持。

## 当前参数与开关

`src/car_config.h`中：横移10.92、前进10.00、后退9.98脉冲/mm；前后直行左右固定补偿0/0，横移前后固定补偿0/0。之前根据2m实走1940/1970mm讨论的11.26/11.09只是候选，尚未应用，不在本次合入中额外调参。

```text
loop encoder on
loop gyro on
loop forward on
loop status
```

encoder控制前后行驶的正交位置反馈，forward控制横移的前后反馈，gyro控制行驶航向PD。关闭相应反馈按原车身轴分支执行，编码器距离/新鲜反馈/必要定角转向仍保留。比赛的station开关仍独立使用开局参考，避障测试不启用station。

避障测试的裸`loop`仍表示连续测距打印，不改变原用法；`loop status/encoder/gyro/forward`显式命令新增为底盘开关。判障阈值、方向盲区和退回条件未改。其名义动作估时同步横移120RPM/s/400ms，独立1ms参考使用同一参数；A起点E-F封路例的整圈评分由86885变为92996ms，规划器和独立参考相同，不是实车用时。

## 验证与边界

新增`tools/verify-chassis-merge.ps1`验证正式入口四方向2m/200RPM、途中角度扰动、里程与正交收敛、速度上限和非目标作用域，并确认不存在融合/纯模块位移命令。原drive-loops、node-stop、station-hold、station-fixed-ring、raw-j-position、movexy-polarity、vision-settle、no-auto-stop等分别执行。故障仍沿原告警/等待策略，人工`!`停止；不新增自动故障停机。

测试输入同步了明确的新契约：超程注入提供同一时刻的Yaw/CPOS；视觉PD边界通过实测角速度入口提供已稳定样本；手动停稳必须有零速之后的新反馈；横移减速断言改为120RPM/s，固定补偿断言使用当前0/0。原超程、角度、轮速、节点200ms、视觉端点及故障策略断言保留。旧heading自动故障停机、arm-integration载物台时间、negative-lift机构速度、lateral-production连续圆角字段仍有合入前已存在的失败，单列，不删除/放宽。

两套目标分别进行ARM全量构建与AXF/HEX装载字节校验。当前源码哈希、测试、旧失败及两个固件路径见`evidence/encoder-chassis-merge-validation.json`；独立测试撤销证据见其目录`encoder-only-rollback-validation.json`。未烧录、未进行比赛路线或避障实车验收。输出在各自本轮证据目录，不将旧默认OBJ固件冒充当前构建。

本轮比赛构建的链接器调用栈报告为964字节，原1KB栈仅余60字节，尚未包含中断与浮点压栈。共用启动文件统一预留4KB栈；避障目标原本已为4KB。该调整不改变速度或任务时序；静态调用栈报告仍不等于实机栈高水位验收。
