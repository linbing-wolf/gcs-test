# 行驶纠偏开关

适用于当前`CAR_RUN_CORNER_ENABLED=0`分段比赛路线和`test f/b/l/r`，两个反馈开关默认都开启。

作业期间另有独立的`loop station on/off`，默认开启，按正式发车的开局参考保持工位航向；不受`loop gyro`控制。见[作业期间航向保持](作业期间航向保持.md)。

| 命令 | 作用 |
|---|---|
| `loop`或`loop status` | 查询`encoder=ON/OFF gyro=ON/OFF`，不发运动指令 |
| `loop encoder off` / `loop encoder on` | 关闭/开启普通前进、后退的编码器横偏反馈 |
| `loop gyro off` / `loop gyro on` | 关闭/开启前后、左右平移中的IMU航向纠偏，包括平移末端纠角 |

例如只保留陀螺仪纠偏：

```text
loop encoder off
loop gyro on
loop status
```

开关可在空闲或运行中修改，在下一次控制更新生效。编码器横偏修正仍经过原轮速斜坡，关闭时逐步回到固定前馈；重新启用陀螺仪后继续使用该段原航向目标，不把当前偏转角当作新目标。停止、切换模式和再次发车保留所选状态，不写入Flash；复位恢复`src/car_config.h`中的`CAR_ENCODER_DRIFT_DEFAULT_ON`和`CAR_GYRO_HEADING_DEFAULT_ON`（1开、0关）。

固定前后/横移补偿、里程标定、编码器距离完成、比赛250/200RPM分档、节点实际停稳和200ms停留均保留。`encoder off`不会关闭用于距离到位的编码器，也不会删除固定横向补偿；它只控制原本适用于普通前进/后退的横偏反馈，不新增横移、工位微移或MOVEXY的位置纠偏。`gyro off`只取消平移中的航向输出及平移结束的航向稳定门槛；原地定角转向、进站转头及其完成条件仍使用IMU。两项关闭后仍要求新鲜IMU和四轮反馈，沿用现有反馈缺失时的告警/等待策略。

保留旧编译总开关`CAR_STRAIGHT_HOLD_ENABLED`：设0会编译禁用整个直行横向控制通道，串口不能再打开编码器横偏反馈。日常比较请保持该宏为1，用上述运行开关或上电默认宏选择。历史连续圆角控制及独立避障诊断的`loop`测距命令不在本次开关范围内。

验证入口`tools/verify-drive-loops.ps1`：四组上电默认组合，独立串口开关、前后/左右400mm模型、4度航向扰动、运行中重新打开航向反馈、关闭反馈后的左右90度定角转向、比赛A路线和传感器新鲜度要求。主机模型与ARM编译不代表烧录或实车验收；宽回归中的旧故障停机断言冲突应单独报告。
