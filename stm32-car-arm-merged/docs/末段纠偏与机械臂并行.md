# 末段纠偏与机械臂并行（r71）

操作者要求所有相关作业区域的机械臂准备动作与底盘最后修正重叠。r70仅覆盖紧接SS_APPROACH的最后视觉修正，没有覆盖固定环位索引和进站朝向末段；r71补齐这些分支。

| 场景 | 提前执行 | 保留的后续条件 |
| --- | --- | --- |
| 原料区两次进站 | 最后小角度转向修正时，云台转向取料口、按原顺序张开空爪；两轴保持高位收回 | 底盘按原判据完成后发C，仍由PICK确认后执行load1取料 |
| 粗加工区两次进站 | 最后朝向修正时转到观察角 | 底盘完成后发D，按原协议对准 |
| 暂存区两次进站 | 最后朝向修正时转到观察角 | 首次完成底盘定位后发E；第二次按原环位索引后发F |
| 粗加工环位索引后的平台取料、地面抓回 | 最后5mm低速索引与下一SS_APPROACH转向、平推、下降并行 | 后续进杯下降/闭爪仍等索引完成 |
| 首次暂存环位索引后的平台取料 | 同上 | 后续夹取仍等索引完成 |
| D/E/F最后一条MOVE/MOVEY/MOVEXY | 终包已收、FIFO已排空且下一步直接靠近时，末段提前靠近 | 仍等完整修正完成才执行后续夹取 |
| 第二次暂存索引后尚需F定位 | 保持观察姿态，按原流程发F；F最后修正时可提前靠近 | 不在相机仍需观察时提前离开观察姿态 |

参数集中在`src/station_config.h`：`STN_APPROACH_OVERLAP_MM=5`为每轴剩余误差绝对值窗口；`STN_APPROACH_OVERLAP_RPM=6`为已提交指令窗口；`STN_APPROACH_OVERLAP_YAW_CDEG=300`为3度的提前动作航向窗口。进站仅在最终工位朝向修正阶段且每轮指令≤6RPM时准备；索引/视觉仅在每轴剩余≤5mm且前后/横移/转向指令各≤6RPM时提前靠近。

这些窗口只决定是否提前启动。最终距离容差1mm、航向容差0.8度和稳定时间、停车/零指令ACK等完成判据保持。条件暂不满足就继续原顺序，不新增停机条件。普通道路行驶、任务颜色/杯位/环位、速度参数、原机械臂取放坐标和视觉FIFO保持；独立`vision debug`仍无抓放。IMU保持操作者已确认的50Hz、双方230400波特率。

进站期间只推进高位收回、准备云台和张开空爪；底盘完成之前不发C/D/E/F、不进入取料。机构先靠近完而底盘反馈延迟时，也不提前闭爪。底盘一直独占四轮CAN接收队列，升降5/平推7使用独立机构队列。底盘完成后维持已开始的机构会话，交还四轮轮询权；急停与真实驱动/机构故障停止两者。

日志示例：

```text
[station entry overlap] job=1; final heading correction; preparation started; vision/grip wait for chassis
[station entry overlap] chassis aligned; prepared station continues
[station approach overlap] final station move within 5mm/6RPM; approach started; grip waits for chassis completion
[station approach overlap] chassis correction complete; arm approach continues
```

“started”表示动作进入预检，不能单凭此日志认定轴已经移动。`tools/verify-approach-overlap.ps1`通过真实入口、工位、视觉和机构模块运行联合模拟：

- 两条完整A/C路线，六次作业进站均检查PWM实际变化时底盘仍有非零转向指令；不以busy或打印日志代替该证据。
- 粗加工两批的平台取料和地面抓回，以及首次暂存索引，检查实际机构轴指令提交时底盘仍有非零平移；原八项作业与13960mm路线保持。
- 保留D/E/F正负方向、单/双轴视觉末段测试，并要求轴指令与非零平移重叠。
- 中断四轮或IMU反馈，使机械臂先到位：底盘完成前不闭爪；进站准备先完成也不提前请求视觉。恢复反馈后继续。
- 急停、CAN故障、索引期间obstacle和arm stop取消两者；完整工位变体覆盖原标定/高度检查、索引顺序及无并行时的重新采集互锁路径。

本地模拟与ARM构建不是实车验收，未烧录。工位配置0～8通过，配置9仍因原测试文件`push_move_to`编译错误阻塞，未改动该无关测试。使用本次独立生成的HEX，启动版本应为`20261023-merge2-r71`；自动流程实车时序仍待复测。
