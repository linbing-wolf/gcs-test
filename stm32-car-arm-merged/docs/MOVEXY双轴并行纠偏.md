# MOVEXY双轴并行视觉纠偏

对应固件 `20261022-merge2-r58`。粗加工D、首次暂存E、第二次暂存F/STACK，以及独立 `vision debug` 的D/E/F入口，共用本命令和队列。上位机决定偏移数值和何时完成，下位机执行收到的位移；DISC/STACK坐标只作报告，不另算位移。

## 上位机怎么发

UART5仍为115200、8N1；保持既有 `AA 55 LEN payload CRC8 0D` 帧，LEN按实际payload字节数计算，CRC8仍覆盖LEN与payload、poly=0x07/init=0。只新增payload，不改变外层封包。

推荐payload：

```text
MOVEXY,+300,-200
```

也接受以下空格形式（含小写命令名），数值前的加号可省略：

```text
MOVEXY +300 -200
movexy 300 -200
```

这是发给视觉串口的帧内指令；调试口仍先用 `vision debug D` / `vision debug E` / `vision debug F 颜色` 建立相应会话，不能把裸MOVEXY当作调试口的任意移动命令。

| 字段 | 单位与执行方式 | 当前方向 |
|---|---|---|
| dx | 有符号像素，完整幅值换算毫米 | 正值后退，负值前进 |
| dy | 有符号像素，完整幅值换算毫米 | 正值向左，负值向右 |

当前操作者假定1 px=1 mm。因此上例是**后退300 mm与向右200 mm并行**。不把数值只当正负号，不固定每次3 mm，不从当前位置或画面中心重复减一次。两字段均接受−32768～32767的整数。

任一字段0时执行另一轴；两字段都是0时本条不移动，不撤销前面的指令。沿用现有1 mm编码器到位窗口，窗口内的微量目标可能无需输出轮速。

## 并行与完成

一条MOVEXY整体占用一个FIFO元素，队列仍为32条。两轴在同一批四轮速度中叠加，并分别用前后/横移标定系数和编码器投影计算剩余距离；IMU继续保持进站时的车身航向。每轴独立减速，较短轴可以先完成，较长轴继续，直到两轴都完成并停车交接。无需先走完x再启动y。

对角线混控可能让两轮暂时接近零速，因此双轴编码器按车轮指令方向确认反馈极性，静止轮不会被要求完成无意义的方向学习。全部四轮的位置、速度、状态仍按既有CAN轮询取得。双轴期间由实际两轴里程闭环修正，不叠加单轴横移专用的前后开环补偿，避免覆盖收到的dx目标。

旧 `MOVE,dx`、`MOVEY,dy` 保持原有单轴行为，也能与MOVEXY混合排队；它们仍是两条独立动作。要并行，必须将一对偏移放在**同一条MOVEXY**中。下位机不会自行把两条旧指令猜成一对。

收到 `DISC,x,y,dx,1` 或 `STACK,x,y,dx,1` 后停止接收新纠偏，仍执行已经接收的完整队列，等当前双轴运动及互锁交接完成再进入抓放。没有新增视觉合格门槛、R、ACK或自动重发。第二次暂存仍每块一次F，放料后保留纠偏位置，没有额外反向横移或前后撤销。

## 参数在哪里改

所有现有数值保持。新增命令不另设一套增益或速度。

| 文件 | 参数 | 用途 |
|---|---|---|
| [station_config.h](../src/station_config.h) | `STN_VISION_MM_PER_PX_X1000` | 两轴像素到毫米比例×1000；1000表示假定1 px=1 mm，500表示0.5 mm/px |
| 同上 | `STN_ALIGN_MOVE_SIGN` / `STN_ALIGN_Y_MOVE_SIGN` | dx前后方向 / dy左右方向；当前−1 / +1 |
| 同上 | `STN_ROUGH_INDEX_RPM` / `STN_STORAGE_INDEX_RPM` | 相应工位两轴各自的速度上限 |
| [car_config.h](../src/car_config.h) | `CALIBRATED_PPM_Y` / `CALIBRATED_PPM_X` | 前后 / 横移编码器距离标定 |
| 同上 | `CAR_DRIVE_ACCEL_RPM_PER_S` / `CAR_DRIVE_DECEL_RPM_PER_S` | 两轴速度斜坡与制动 |
| 同上 | `CAR_DISTANCE_TOLERANCE_MM` | 沿用的各轴到位窗口，不是视觉偏差门槛 |

## 本地验证边界

已运行现有航向/CAN、机械臂、工位10配置回归及完整70单元ARM构建。新增真实CRC帧到独立四轮惯性/编码器场地模型验证：D/E/F和调试入口、正负/零、300/−200完整幅值、原单轴兼容、配对FIFO边界、提前终包、暂缺反馈、16种反馈极性、不同轮加速度及航向扰动、0.5 mm/px测试比例、急停和bus-off取消。

第二次暂存三块非零MOVEXY验证只有3次并行纠偏和4次既有环位索引，共7段；旧MOVE+MOVEY的10段回归也继续通过。源码测试与构建只证明本地软件行为，不代表已烧录、实车精度、实际节省时间或180秒成绩。上位机工程不在本目录，本次没有修改其发送程序；发送端要使用上述配对payload才能触发并行。
