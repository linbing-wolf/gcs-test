# r105 出弯恢复提速

2026-10-26，针对“车头基本正了后仍加速很慢、像要停下”的反馈修改。r95虽然允许渐进升速，仍只在几何圆弧结束后进入恢复，且继续沿用3度航向比例折速；实际差5度时，路径速度仍可能只剩原参考的3/5。

本次把恢复提前到几何转向剩余5度，实际车头距最终方向小于15度时即可开始。几何弧内仍受原180mm/s参考和300/300RPM/s轮速变化率约束。几何弧结束后，路径及单轮升速率按实际车头偏差渐增：

| 实际车头距最终方向 | 出弯升速率 |
|---|---|
| 接近15度 | 150 RPM/s |
| 10度 | 300 RPM/s |
| 5度以内 | 450 RPM/s |

恢复阶段的航向比例折速门槛使用5度，因此实际5度内不再被原3度门槛压成60%速度。路径修正、旋转纠偏和混控单轮上限继续生效；450是请求上升率，实际还受单轮共同变化率和剩余制动距离约束。

可直接调src/car_config.h的CAR_CORNER_EXIT_ACCEL_RPM_PER_S（当前150）和CAR_CORNER_EXIT_MAX_ACCEL_RPM_PER_S（当前450），最大值须不小于起值。CAR_CORNER_EXIT_ALIGNED_CDEG=500同时定义几何尾段开始范围和实际车头基本回正范围，单位0.01度；CAR_CORNER_EXIT_YAW_CDEG=1500是实际朝向进入恢复的外边界。CAR_CORNER_EXIT_BLEND_ENABLED=0保留不进入恢复的分支。

普通直线起步240、前后250/横移分档、圆弧参考180、停车减速度200及200ms预留保持。只在非退回、非视觉终点且有平移请求时使用出弯专用升速率；整体零速请求仍按原200减速。r104极性/FIFO、视觉/机械臂及离站时序保持。

验证：tools/verify-corner-exit-recovery.ps1记录六种独立轮速模型的实际速度，包含几何尾5度提前恢复、已回正单轮450以及零速200的作用边界。对比同一测试在修改前快照的结果，较慢响应模型出弯最低速度从54.069提高到77.890～80.043mm/s；达到200mm/s从200～201ms缩短至156～160ms。正常响应模型最低速度约160mm/s保持，恢复到200mm/s从51～53ms缩短至45～50ms。

108组增益/轮响应/反馈周期/轮间差异场景通过：最大弧内航向误差14.640度，径向偏差22.038mm；出弯前200mm的实际横向路径偏差最大30.904mm，对照关闭恢复时21.773mm，提速增加了模型偏差，不能把它当作已验证实车精度。A/C各8作业、13760mm的20ms IMU模型均105480ms；与关闭恢复的105975/105585ms属于同参数开关对比，不是实车耗时保证。

视觉末端、MOVEXY极性、普通末端、扫码、提前视觉、并行离站及暂存/180度启动回归通过。verify-heading和verify-arm-integration仍分别卡在旧自动故障停机断言602/159行，未恢复停机，不宣称全部历史回归通过。
