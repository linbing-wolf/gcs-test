# 全程连续过弯（r79）

2026-10-24。版本 `20261024-merge2-r79`，使用原 `runimu A/C`。只生成本地固件，没有烧录或实车验收。

## 实际走法

| 连续行程 | 中间点处理 | 车头 |
|---|---|---|
| A/C→首次B′→E→F | B′、E两个150mm圆角连续通过 | 全段保持手工摆好的−X，横移→前进→反向横移 |
| 等码后的B′→E→F | B′出发，E的150mm圆角连续通过 | 保持−X，前进→横移 |
| 两次F→E→D | 原共线直通，E不停车 | 行驶保持−X，到D按原规则转到+X作业 |
| 两次D→E→H | E的150mm圆角连续通过 | 在弧中+X→+Y，其余直线保持各自方向 |
| 第一次H→E→F | E的150mm圆角连续通过 | 在弧中+Y→−X |
| 最后H→E→B→A | E共线直通；B半径150mm，末尾60mm小弯半径30mm | 保持+Y，横移→后退→横移 |
| 最后H→E→B→C | H→B恢复1770mm，B半径150mm；出弯后600mm前进中平滑侧移60mm，最后280mm纯直行 | 保持+Y，侧移与前进并行，无独立横移收尾 |

正常提前扫码是5段连续路径；A共7个圆弧，C共6个。固定车头模式也采用平滑的相切路径：前后、左右速度在拐点附近连续交接，不停车后重新对准。改变下一作业区朝向时，在最后一个圆弧中完成所需90°转向。

B′是r76的首次扫码位置(2250,1200)，与地图B(2190,1200)不同。r79的回程弯均恢复沿地图B；C在其后向原启停区直线平滑偏移60mm。起点仍是原A/C，原起步60mm仍计入首次B′→E，不改变摆位。正常切角不经过B′/E/B的几何顶点，只在圆弧出口推进对应的逻辑路段；F/D/H及最终A/C仍为原终点。

F/D/H进站最终行程进入50mm近到站窗口后，保持原零指令、航向与反馈条件，把位置残差交给视觉，不反向追补导航停车坐标。窗口是初值，需相机视野验证；视觉MOVE/MOVEXY本身及非作业终点仍保留原位置完成。原料两批各H一次后C,C,C、其他工位动作、视觉MOVE/MOVEXY、机构参数及末段提前准备保持。

## 扫码分支

发车初始化一次并持续接收首个有效任务。第一弧入口为路径进度880mm，入口前已有任务就连续过B′。入口仍无码则不切过扫码位置，继续原1030mm直线到B′；此时仍无码就等待。任务若在最后150mm才到达，也先完成直线，再启动B′→E→F连续路径。不会在弧中临时跳至另一条路线。

返程不再扫码。`station auto off` 同样使用连续过弯，且不要求任务码。

## 控制与参数

- 复用原圆角二维编码器＋IMU闭环、同一时刻四轮CPOS插值和航向PD。修正同时作用于前后、左右、航向，四轮共用RPM上限及变化率限制。
- 圆弧半径取 `min(150mm, 前边长度/2, 后边长度/2)`；入弯提前减速，固定车头参考上限250mm/s，转动车头参考上限150mm/s；短弧按半径平方根缩放。各弧再按四轮所需变化率计算可跟随速度，预留20%给修正；因此参考上限不等于实际弧速。
- 位置与航向PD参数未加大，单轮仍限300RPM；道路/连续路径加速240RPM/s，制动120RPM/s，过零先减速后加速，三轴共同比例推进。工位微调沿用本地150RPM/s。转头插值改为两端角速度为零的三次曲线，峰值从平均角速度的1.875倍降为1.5倍。最后5mm允许原机构准备，夹取仍等待底盘交接及后续视觉指令完成。
- 连续路径不再叠加旧单轴横移的经验前移量；旧配置保留给分段执行器。没有新增外部位置传感器，无法观测轮子不相应转动的真实侧滑，也不能消除离开上一工位前已有的场地偏差。
- 修复启动航向历史时间：保留IMU真实接收时间，拒收倒序/重复时间记录，避免低频IMU造成错误插值；支持角度±180°和毫秒计时回绕。

没有新增偏差阈值停机。沿用r74不因15°偏航或500mm二维估计越界取消连续路径；反馈等待、实际驱动故障、编码器无响应和 `!` 急停保持。`obstacle` 在机构准备前触发，确认停稳后沿本次连续路径退回其起点，再停等；原工位/重叠作业内处理保持。

将 `CAR_RUN_CORNER_ENABLED` 改为0并重新编译，会使用r76的分段执行器（也关闭D→E→H圆角）。`CAR_RUN_OMNI_ENABLED=0` 保留旧模式，均有主机回归。

## 验证边界

当前行为以[C回程侧移与视觉交接](C回程侧移与视觉交接.md)为准。当前证据及固件哈希见 `../evidence/current-validation.json` 的 `allRouteCorners`。专项按独立地图圆心检查A的7个弯、C的6个弯、两种车头策略、弯中实际非零平移、两种起点及8个作业顺序；另测扫码提前/延后/缺失、反馈恢复、急停/故障、各连续路径退回以及低频航向和时间回绕。

ARM全量构建、包核对及机构/CAN等主机回归分别记录。工位配置0～8通过；配置9仍是已有 `push_move_to` 测试夹具编译错误，未作为通过。主机模型不含真实摩擦、打滑、供电或扫码视野，不能代替实测耗时和稳定性。
