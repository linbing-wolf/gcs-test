# 横移距离速度分档

2026-10-25，版本`20261025-merge2-r93`。按操作者最终确认，只对横移分档，前进/后退不分距离。

## 直接调整参数

以下四项集中在`src/car_config.h`开头，直接修改后重新编译、烧录即可，无需重新生成地图：

| 参数 | 当前值 | 含义 |
|---|---:|---|
| `CAR_LATERAL_SHORT_MM` | 1200 | 短横移的最大连续同向长度，mm；等于分界仍算短档 |
| `CAR_LATERAL_SHORT_RPM` | 250 | 短横移速度上限，RPM |
| `CAR_LATERAL_LONG_RPM` | 200 | 长横移速度上限，RPM |
| `CAR_RUN_RPM` | 250 | 前进、后退上限，RPM；不分距离 |

`CAR_LATERAL_MAX_RPM`、`CAR_TRANSLATION_MAX_RPM`及`CAR_WHEEL_MAX_RPM`由速度配置自动推导，不必再手工同步另一处总上限。转向上限`CAR_TURN_CLOSED_LOOP_RPM`独立设置，本轮保留源码已有的300；本轮前左移补偿已调为30、右移10mm每米，减速度200RPM/s，这些也保留。

## 连续路段与实际输出

- A/C→B当前为短横移，选250上限；起步60mm平滑偏移及原路线保持。
- F→E→D共线横移810+810=1620mm，整个直线串选200。通过E后不会因剩余810mm变短而升档。
- H→E→B共线横移780+990=1770mm，选200；其后的B→A/C若为车身前进/后退，则用250。
- 连续路径按规划车头及名义直线方向识别前后/横移，合并相邻共线道路计长，不用位置误差或航向噪声切档。圆角原有mm/s参考及变化率约束保持。
- 普通分段、test横移、连续路径及位置模式都应用相应限速，混控后的最终单轮也不得突破当前档位。人工导航的RPM请求仍可调低；`rpm 0`继续采用道路表速度。
- 上限不是保证达到的速度。短路的加速、制动、角速度及拐弯限制可能使实际指令峰值低于250；没有为达到上限修改既有加减速。

本轮继续使用r91的横移经验前移和回补方式，没有恢复r92新增的横移前后位置闭环；工位原60RPM微调、机构参数、地图、视觉和故障策略保持。

## 验证边界

`tools/verify-lateral-speed-tiers.ps1`覆盖连续过弯开/关、1200/1201边界、左右横移、前进/后退两种长度、较低请求、500组三轴混控、位置模式、F→E→D通过E及临近终点档位保持、A/C发车及H→B→启停区的方向切换。模型中的短横移指令峰值可能不到250，但所选上限必须正确。

当前证据见`evidence/current-validation.json`。主机检查、固件构建和包哈希核对均不代表实车不超调，200/250分档的实车表现尚待验证；旧自动停机断言的失败单独记录，不宣称完整回归通过。
