# 横移航向阻尼（r67，2026-10-23）

用户反馈暂存区到B点连续左移780+990=1770mm时车头明显左右摆动。现场日志记录航向误差窗口从-3.04°到+2.11°；其中角差-0.39°时角速度为-26.5°/秒。当前日志未包含固件版本，不能仅凭这些日志确认当时烧录的源码版本或实际四轮指令。

## 改动

普通左右横移在仍有横移速度指令时，复用已有的 `heading_control_drive_rpm`。它按角差与角速度共同给出修正，允许车头经过目标方向前施加阻尼。旧分支使用原地转向函数，在±0.8°内直接输出零修正，超出后有最低5RPM修正；行驶分支仅在角差和角速度同时满足静稳条件时归零。

没有调整任何控制参数、速度或加减速参数。沿用已有行驶参数：Kp=1.2 RPM/度，Kd=0.3 RPM/(度/秒)，静稳窗口±0.2°且±0.5°/秒，最小修正1RPM，最大修正20RPM，并保留原有随平移速度限幅。

横移指令归零后继续使用原停车对齐函数；原地转向、终点距离反修、完成条件、CAN反馈、急停和互锁保持。没有新增停机条件。本次不增加横移过程中前后位置的反馈控制，也不能检测编码器无法观测的地面滑移。

## 日志

横移的 `[control]` 现在也输出 `t_ms`、`v_ref/v_cmd`、`left_ref/left_cmd`、`turn_ref/turn_cmd`、`control_dt_ms`、`wheel_cmd_rpm`、`wheel_rpm_raw` 和 `speed_age_max_ms`。原有 `yaw_win` 保留。

- 速度和修正量单位均为RPM。`left_ref` 是横移斜坡前目标，`left_cmd` 是本次提交批次的横移分量；左正右负。
- `v_ref/v_cmd` 是前进分量，横移时主要反映已有经验补偿；并非横移速度。
- `turn_ref` 是混合前航向控制结果，`turn_cmd` 是经过平移速度约束的旋转分量。四轮统一限幅还可能缩小分量，因此分析实际四轮命令应看 `wheel_cmd_rpm`。
- `wheel_rpm_raw` 保留驱动器原始符号，反馈时效参考 `speed_age_max_ms`；命令不等于实际轮速。
