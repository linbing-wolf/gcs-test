# 无障碍全向路线（r72）

按操作者要求，默认全场无障碍。每条道路都保持当前车头，用已有地图坐标到车身坐标变换，直接输出前进、后退、左横移或右横移。首次走的路也可后退或横移，已走道路记录不再决定能否这样执行。

`src/car_config.h`的`CAR_RUN_OMNI_ENABLED=1`启用此策略。原首次/已走道路开关仅在该值为0时生效，作为旧策略兼容分支保留。`completed_roads`仍只在实际反馈完成整条道路时记录，不伪造已走状态。

例如B点扫码完成时车头朝地图-X，之后E→F的地图-Y位移直接换算为右横移。到原料区时已有正确作业朝向，无额外道路转向；机械臂准备仍与进站完成确认并行。到其他工位如果需要让车右侧朝向作业区，仍按原工位配置转向。

以下行为保留：

- 两条A/C路线的地图几何、节点、距离和八项作业顺序，正常全程13960mm。
- B点扫码朝向，原料/粗加工/暂存的作业朝向及到位判据。
- IMU航向PD、编码器距离闭环、横移/前后速度限制和末端控制。
- 视觉FIFO、机械臂姿态/速度与r71进站和索引末段并行；原料PICK及各区视觉确认。
- `!`急停和现有真实故障处理。无障碍是假定场地条件，未改动手动`obstacle`停止/回退命令。

当前自动流程中，首次原料区朝向与B扫码朝向相同，因此这次进站没有非零转向，后续五次工位转向仍覆盖机械臂PWM与底盘转向重叠。索引、视觉末段提前靠近保持。

`tools/verify-omni-route.ps1`同时运行生产模式和仅测试的旧策略变体：7680组真实有向道路分段/四种车头/历史记录/起点和作业组合，用独立场地坐标重建核对位移、距离与车头不变；再跑A/C底盘和完整自动作业。底盘模型中两条路线的转向段从10次降至6次，均到达原工位坐标，距离不变。这是软件模型结果，不是实车耗时或定位精度保证。

航向/CAN、机构、工位0～8配置、机械臂末段并行、MOVEXY、直行横向修正及扫码回归继续验证。工位配置9仍因原`verify_station_compaction.c`中的`push_move_to`编译错误阻塞，未改动该无关测试。

本次固件单独生成，启动版本为`20261023-merge2-r72`。未连接硬件或烧录，新增首次道路横移/后退的实际跑偏和路线精度仍需实车复测；IMU保持50Hz及双方230400波特率。
