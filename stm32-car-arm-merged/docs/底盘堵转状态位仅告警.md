# 底盘堵转状态位仅告警

2026-10-25，版本 `20261025-merge2-r86`。按操作者要求，取消STM32收到底盘驱动器堵转标志后立即终止整车任务的行为。此改动只调整状态位处理，未解决此前进站超程、轮间减速不同步或驱动器报告堵转的原因。

底盘CAN地址1～4的状态位 `stalled=1`（bit2，数值4）改为只告警；启用状态下的 `flags_dec=5/7` 允许继续行驶、四轮互锁和工位移车。保留完整原始flags，不伪造健康状态，也不自动清除驱动器标志。出现和清除时分别记录：

```text
[wheel stall] addr=3 flags_dec=5; reported; log only; driver protection unchanged
[wheel stall] addr=3 flags_dec=1; cleared
```

持续相同状态不重复刷屏。四轮未使能和驱动器保护状态仍拒绝运行/停机，故障文字改为 `motor disabled or protected` 或 `wheel disabled/protected`。全局 `!`、CAN故障、反馈等待、编码器实际无位移/方向异常、航向及机构姿态互锁保持。驱动器自身堵转保护参数没有修改，驱动器仍可能自行停车；实际无位移也仍可触发STM32现有故障处理。

本轮保持r85地图、原料/暂存内移、粗加工新增80mm、60mm发车偏移、减速240及机构/视觉配方原样。

专项入口 `tools/verify-wheel-stall-log.ps1` 覆盖四轮原始状态保留及告警去重、真实行驶、A/C自动圆角、四轮互锁/工位移车，以及未使能、保护、急停、冻结编码器继续触发停止。项目要求的heading和机构回归已运行；结果、源码哈希及本轮ARM构建证据见 `evidence/current-validation.json`。完整heading回归仍存在修改前的1670mm模型距离超差，不能将专项通过等同整套回归通过。未烧录、未实车验证。
