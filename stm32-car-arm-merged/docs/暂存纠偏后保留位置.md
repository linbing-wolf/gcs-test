# 暂存纠偏后保留位置

当前版本：`20261022-merge2-r56`。

第二次暂存区每块物料放好后，保留上位机MOVE/MOVEY执行后的车身位置。删除原来先反向横移、再反向前后移动的自动撤销步骤，以及仅供该步骤使用的累计位移和执行状态。

后续仍按原任务顺序索引到下一环位，发送该物块颜色对应的一次F并执行上位机的新MOVE/MOVEY；最后原有回逻辑2号位和离站动作保持。没有把反向撤销移到其他阶段，也没有添加新的补偿移动。

150/300 mm索引从当前位置出发，因此已执行的视觉偏移会保留下来。逻辑上回到2号位，不等于物理上已恢复到原来的导航停车坐标；下一次F可继续按上位机纠偏，最终离站时残留偏移对返程落点的影响需要实车确认。

第一次暂存E、粗加工D、第二次暂存每块F的次数、FIFO顺序、像素换算、抓放参数、110 mm上升净空和离站回正/转弯并行保持。
