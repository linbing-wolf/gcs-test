# 作业节拍优化（r30）

当前版本：20261020-merge2-r30。本次仅调整动作并行、原地转向后段速度和B点扫码接收窗口；不改任务颜色/靶位顺序、放料高度、索引距离、视觉协议或地图。

## 云台和载物台并行

原料区装完一块后，原来已经通过YAW|PLATFORM在同一步回转/换杯，本次保留。粗加工与暂存区选择杯位时改为同一步转动载物台、云台到256°；粗加工抓回放上车时同样并行。两区结束时平台回1号、云台回0°也合并。

合并动作仍在lift135/slide0时执行，共用当前配置600ms插值。两路插值与双轴有效反馈完成后，才伸出/下降。夹爪状态不改变；手动arm platform命令仍沿用原接口。新增内部arm_platform_with_yaw，不在串口新增命令。轴速2500、插值600ms是用户已有本地修改，未还原为旧的3000/700。

电脑模型对比同一次换盘+转向：原串行1303ms，并行652ms。该数值包括模拟预检开销，不代表真实舵机已到位；舵机和夹持都没有位置传感器。

## 到B即接收扫码

扫码模块本来就是连续模式，接收窗口此前限制在转完后进入RUN_STATION。现在首次B点到达后（edge1/job0）转向期间就能锁定首个有效任务。码分片、无效码和重复码仍按原解析器处理；后续不同有效码不会覆盖首码。到B前、回程B、停机后和闲置扫码只显示，不重装任务。未扫到时仍转到扫码方向，在B持续等待；手动预置任务仍支持。

当前扫码朝向和B→E出站朝向都是-X。扫码先到时，仍完成出站所需航向确认，再直接接下一段，省掉进入扫码工位后重新获取机构互锁和等码的流程；不把途中扫码当作底盘航向已到位，也不带错误朝向直走。
