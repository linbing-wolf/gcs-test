# 抓取直转与底盘平移并行

原实现版本：`20261022-merge2-r57`；r60已修正出杯下降时序，见[出杯下降时序修复](出杯下降时序修复.md)。本次开始时，操作者已把 `ARM_CLEARANCE_MM` 改成105 mm，沿用该值；修改前源码在 `evidence/direct-transfer-before-20261022T090751446186Z`。

## 自动抓放的动作衔接

原来夹住物块后，先升到135 mm、平推收回0 mm并完成旋转，再伸出到下一取放姿态。这会产生“缩一下，再停一下”的中间动作。

现在原料区 `arm load1`、粗加工和两批暂存的自动搬运改为：

1. 在原标定位置夹住物块，最终合爪PWM后仍保持120 ms。
2. 抬至当前105 mm离杯净空；已处于该高度时不发重复位移。此处不先收回0 mm，也不先绕到135 mm。
3. 直接转向下一取放角，平推和升降同时到下一姿态的最终参数。r60车载杯到地面先启动平推35→55 mm与云台256→126.5°，经过 `ARM_CUP_EXIT_DESCENT_DELAY_MS`（默认100 ms）后即下降到5 mm或第二层65 mm并预选下一杯，不等待转向结束；地面回杯为平推55→35 mm、云台126.5→256°、lift到110 mm。
4. 等实际轴位置/到位反馈及舵机指令完成，再松爪或进入下一次夹取。搬运中夹爪保持原状态。

原料口55/105/131°、车载杯35/110/256°、从杯取料100 mm、粗加工地面55/5/126.5°、暂存5/65 mm等取放参数不变。手动pick/home/place/cycle/load3标定动作表保持。

## 底盘何时与旋转并行

- 当前物块已经放好、准备移往下一环位时：实际升降135 mm、平推0 mm到达后，不必等剩余云台/载物台旋转结束，便开始原150/300 mm环位移动。
- 作业结束离站时：同样在实际135/0收拢后，末尾回车头、载物台回位与下一段转弯、前进、后退或横移并行。
- 向当前固定放置目标搬运物块期间，底盘仍保持已对准的位置；下一段移车不提前到本次抓放完成之前。

工位持续跟踪原航向的稳定状态，离站不重复累计同一段稳定时间；仍重新取得四轮反馈。工位旋转与索引交接时，只复用原有300 ms窗口内的状态/速度，四轮编码器位置重新读取后才建立里程基线。真实偏航、不新鲜反馈仍走原有等待/纠偏流程。没有提高底盘或机构的速度数值。

四轮接收队列仍由底盘独占，机构5/7号反馈独立。急停、CAN总线故障和障碍处理仍同时取消底盘与机构动作。

## 可自行修改的参数

| 文件 | 参数 | 当前值与含义 |
|---|---|---|
| `src/arm_config.h` | `ARM_DIRECT_TRANSFER_ENABLED` | 1：离杯后直接到下一取放姿态；0：恢复先高位收回的搬运路径 |
| `src/arm_config.h` | `ARM_LIFT_PARALLEL_ENABLED` | 1：启用升降联动；直接搬运也需要它为1 |
| `src/arm_config.h` | `ARM_CLEARANCE_MM` | 105 mm：操作者当前净空设置，影响离杯后开始搬运的高度 |
| `src/car_config.h` | `CAR_ARM_TRANSLATION_OVERLAP_ENABLED` | 1：剩余旋转与后续底盘平移并行；0：平移等待旋转完成 |

这些参数后面均有中文行尾注释。升降/平推4000 RPM、机构加速度220、云台180+40 ms、载物台400 ms、夹爪50 ms及合爪保持120 ms均保持。完整参数入口见 [参数修改索引](参数修改索引.md)。r56删除的暂存纠偏反向撤销继续保持删除。
