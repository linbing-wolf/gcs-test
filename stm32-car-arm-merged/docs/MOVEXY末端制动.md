# MOVEXY末端制动（r69，2026-10-23）

用户复测r68的F2 `MOVEXY,-75,-44`，反馈抖动减轻但仍存在。该指令换算为前后75mm、横移-44mm；日志中前后里程到77mm后出现 `v_ref=-3`，随后回到75mm，横移最终-43mm，均满足原有两轴1mm完成窗口。该次指令与上一次18/11mm不同，不能据换向计数直接量化r68改善比例。

## 本次定位和修改

原双轴速度先按剩余距离和制动模型计算，再把不足3RPM的速度抬到3RPM。只剩2mm时，现有制动模型给出的上限约为前后1.807RPM、横移1.919RPM，但最终指令仍为3RPM。这个最低速度覆盖了末端减速结果，与现场过冲后反修的现象相符；它并不能证明所有实车抖动都来自这一处。

r69仅把 `run_vector_target` 使用的最低速度改为独立参数 `CAR_MOVEXY_MIN_RPM=1`。这样最后2～3mm可以继续减速到1RPM，超程反修也可以用1RPM完成。剩余6mm及以上的速度计算保持；普通路线和单轴MOVE/MOVEY的3RPM下限不变。

保留原两轴目标、比例增益、制动和加减速模型、±1mm完成窗口、停车判据、急停与互锁。r68不足1RPM航向修正抑制及 `wheel_rev` 诊断保留。不增加积分或停机条件。保留用户设置的双方230400，模块50Hz仍由用户配置。

## 验证和限制

专项在修改前重现2mm剩余距离下3RPM覆盖制动结果，修改后两轴四种符号均为1RPM；检查0/1mm停止窗口、2/3mm低速、超程反向及6mm以上速度。模拟覆盖F2的75/44mm与18/11mm四方向、原MOVEXY几何、编码器极性、队列、取消和急停。r68的微小航向换向重放仍通过。

当前源码、回归、ARM构建和固件以 `evidence/current-validation.json` 为准。工位视觉配置9仍有继承的 `push_move_to` 测试编译错误，配置0～8通过。

本次没有烧录或实车验收。最后几毫米会更缓，1RPM的实际跟随能力及抖动改善程度需要实车确认。复测时保持F2初始偏差与上次一致，优先复测 `MOVEXY,-75,-44`，比较过程最大超程、反向请求、`wheel_rev` 和实际抖动；无需通过放宽到位窗口获得表面改善。
