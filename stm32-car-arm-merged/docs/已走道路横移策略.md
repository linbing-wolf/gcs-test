# 已走道路横移策略

r45将左右横移接入全程runimu的已走道路策略，沿用本轮completed_roads完成记录。整条道路所有几何段完成、抵达下一节点后才置位，正反方向共享道路编号。部分通行、停止或中断不提前记作完整道路；新一轮清空历史。

## 动作选择

| 道路与目标方向 | 动作 |
| --- | --- |
| 已完整走过，目标在当前车头前方 | 前进，保持车头 |
| 已完整走过，目标在后方 | 后退，保持车头 |
| 已完整走过，目标在左侧 | 左移，保持车头 |
| 已完整走过，目标在右侧 | 右移，保持车头 |
| 首次或尚未完整走过 | 原有道路朝向策略 |
| 到达原料、粗加工或暂存作业点 | 仍完成原工位朝向后再作业 |

新参数CAR_RUN_REVISIT_LATERAL_ENABLED=1。原CAR_RUN_REVERSE_ENABLED继续控制已走路的后退；r44发车横移及最终H→E→B→A/C固定车头策略保持。道路表、地图坐标、各段距离和全程13960mm不变，IMU仍维持当前航向。

run_resolve_leg同时供实际动作和run_next_straight预看使用，预看只改变局部完成记录，不提前改写真实历史。同轴、同向、同航向且不需作业的相邻段仍可连续通过；需要换平移轴、到站作业或首次道路转向时按原流程停车。首次F→E采用横移，但首次E→D尚未完整通行，因此在E转入原道路航向；该次E不再连续通过。第二次F→E→D以及最终H→E→B仍连续经过E。

速度配置保持r44：横移与前后行驶上限均3000RPM，采用原120RPM/s加减速与制动计算；工位微调/索引请求仍60RPM，抓放角度、高度、D/E/F次数和视觉方向均未修改。已有道路记录不代表地面绝对定位，横移打滑和横向经验补偿仍需实测。
