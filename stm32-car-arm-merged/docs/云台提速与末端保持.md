# 云台提速与末端保持（r52试调）

操作者确认夹爪为270°，机械臂底座云台为360°位置型，能停在指定角度。保留现有云台脉宽/角度标定，未改成连续旋转的转速控制。供电电压尚未提供。

| 参数 | r51原值 | r52 |
| --- | --- | --- |
| 云台插值时间 | 250 ms | 180 ms |
| 最终云台PWM提交后保持 | 0 ms | 40 ms |
| 夹爪插值 | 50 ms | 50 ms |
| 最终合爪PWM提交后保持 | 120 ms | 120 ms |
| 载物台插值 | 400 ms | 400 ms |
| 底盘软件加速度 | 150 RPM/s | 150 RPM/s |

原值、源码及默认输出哈希记录在 `evidence/yaw-fast-r52-context.json`。本次只调整云台时序。

转动仍使用原五次平滑曲线，命令曲线在起点和终点的速度、加速度均为零，插值范围不越过起止目标。到达目标后，从最终PWM实际提交时开始保持40 ms，期间继续处理反馈与急停；不使用阻塞延时，不触发额外故障停机。重复同一云台角度不附加保持。云台与载物台并行时，保持时间与平台转动重叠，步骤仍等待最慢通道和原有轴反馈。

单独云台步骤名义时序由250 ms变为180+40=220 ms；20 ms PWM更新和反馈预检会影响实际软件耗时。这是目标指令计时，不是物理到位测量。180 ms插值比250 ms更快，也会提高命令曲线的峰值速度和加速度；40 ms保持只能提供稳定时间，不能保证负载下无抖动或实际已到位。若实车跟不上，继续压缩时间不会提高物理转速，需要按实际转动录像或角度反馈重新标定。

[厂家DS3218规格书](https://www.dsservo.com/d_file/DS3218%20datasheet.pdf)列出的是180°/270°规格。本次用户确认的云台为360°位置型，因此没有直接套用该表的额定转速，也没有更改电源电压或舵机PWM频率。

机构、航向/反馈、工位视觉三套回归以及完整70单元ARM构建通过。新增检查覆盖双向单调插值、最终PWM后保持40 ms、重复角度跳过保持及计时回绕；原有合爪保持、两批抓放、离站并行、D/E/F、独立视觉调试与急停回归继续执行。未烧录或做实车稳定性、到位和全程时间验收。
