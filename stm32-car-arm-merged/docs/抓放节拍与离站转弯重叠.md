# 抓放节拍与离站转弯重叠

r46处理每个抓放小动作间的重复等待、机构提速和离站回正与转弯重叠。原抓放坐标、动作先后、载物台选杯、视觉方向与协议以及r45路线策略保持。

## 停顿来源及处理

原begin_step每次都清空两轴反馈，再依次读取5/7号的位置、转速和状态。即使上一动作刚刚确认完成，或本步只转舵机，也要重新等待一轮。现在仅复用上一动作实际完成且仍在原500ms有效期内的反馈；首次动作、反馈过期、arm pose重新声明或停止恢复仍重新采集。

实际移动的轴在提交新目标前清除本轴的完成采样，必须收到新的位置和到位数据才完成；不动轴继续使用仍有效的实际反馈。电脑夹具中新动作可在1ms提交，过期/重新声明场景仍重采，冻结新目标位置时不会因为旧arrived状态而虚假完成。

不变的云台、载物台或夹爪角度不再执行空插值。实际改变的角度仍需要运动时间，参数如下：

| 参数 | 修改前 | 当前 |
| --- | --- | --- |
| 升降目标速度 | 2500 RPM | 4000 RPM |
| 平推目标速度 | 2500 RPM | 4000 RPM |
| 机构两轴加速度档位 | 200 | 255 |
| 云台/载物台插值 | 600 ms | 400 ms |
| 夹爪插值 | 200 ms | 150 ms |
| 底盘加速度档位 | 200 | 200 |

对应arm_config.h的ARM_LIFT_RPM、ARM_SLIDE_RPM、ARM_AXIS_ACCEL、ARM_SERVO_TIME_MS、ARM_CLAW_TIME_MS。驱动接口为16位RPM、8位加速度，本地Emm_V5.c注释标注位置模式速度0～5000RPM、加速度0～255。目标速度不是实测速度，短行程能否达到目标及夹持可靠性需实车验证。

不能直接把真实插值全部置零：舵机没有到位传感器，发出最终PWM不等于已经转完或夹牢。升降到位后收回、夹紧后抬升、转向到杯位后再伸出/下降仍按原路径执行；并行这些线性动作会改变已经使用的抓放轨迹。本次不通过虚构完成来省时间。

## 提前转弯的范围

仅原料最后一块load1 last末步，或粗加工/暂存最后回slot1、yaw0的步骤可提前交接。必须已经实际完成lift135、slide0，剩余只有云台/载物台回正插值；升降和平推运动中不提前交接。

此时主循环继续更新5/7独立队列和舵机PWM，底盘独占1～4号队列，提前做离站四轮新反馈预检和需要的原地转向。转弯期间四轮只发旋转混控，前后/左右平移等待回正结束后放行。若r45路线选择直接横移、无需转弯，仍可将离站预检与回正重叠。日志区分grips done、parking finished和translation released，不把舵机PWM估时称为实测到位。

停止、CAN故障或显式obstacle同时取消两边，清除重叠状态并保持最后PWM，不自动重启。新增工位接口station_departure_ready及机构接口arm_departure_rotation_active只描述这一末尾阶段，不能用于其他抓放步骤。

## 验证

六套主机回归通过，工位含10种配置、A/C整轮自动抓放与六次离站重叠。专项测试制造需要实际离站90°转弯的路段，证明云台/平台仍在插值时车轮已旋转；同时断言未回正时不存在前后或横移指令。急停、bus-off和obstacle均停止两边并保持PWM。反馈复用覆盖新目标冻结、过期重采和人工重新声明；4000RPM及255档位由实际命令参数校验。70编译单元ARM构建通过，ELF/HEX装载字节及r46版本串一致。

26组同条件电脑节拍对比，以最后实际完成回正为结束：每次原料作业减少4064ms，粗加工减少8268～8319ms，暂存减少4578～4629ms；索引顺序、次数和距离不变。夹具将5/7位置命令立即反馈到目标，未建模电机惯量/加速度和真实UART成本，因此这里只量化软件等待及插值变化，不代表真实电机提速收益或实车耗时。
