# 自动故障停机移除

2026-10-25，版本 `20261025-merge2-r88`。操作者明确选择“删除所有自动故障停机，只保留!手动急停”。本说明取代早期文档中故障会自动停车或取消机构动作的描述。

| 情况 | 当前软件行为 |
| --- | --- |
| 编码器超程、极性冲突、轮子无位移、偏航/转向方向异常 | 不触发故障停车；按原控制继续或告警 |
| D进站超程、障碍退回距离超差 | 删除专用故障停车分支；原距离闭环可反向修正，不再用故障中止 |
| 轮子未使能、保护位、CAN总线/发送故障 | 告警；不取消队列、不主动停轮、不清除任务 |
| IMU/四轮反馈过期或不完整 | 继续查询，保留最后已提交指令及斜坡状态，不自动发零速；收到有效数据后继续计算 |
| 串口接收队列/行缓冲溢出 | 丢弃损坏输入并告警，不触发全系统急停；缓冲已满时`!`仍具有优先级 |
| 机构CAN异常、工位错误、四轮互锁异常 | 不自动调用`arm_stop`、`nav_stop`，不因错误取消正在执行的机构动作 |
| 手动位置/导航命令提交失败或无路可走 | 报告未解决的失败状态，不自动发停车包，不把未提交/未到位当作完成 |

`!`全系统手动急停、原有明确人工停止命令、上电初始化和正常任务到位停车保留。数据帧格式、数组边界、合法参数及真实到位条件保留；没有有效下一步时等待处理。`NAV_FAULT`、`MOTION_FAULT`或工位错误状态仍可用于报告未解决条件，它们不再直接停止其他正在执行的动作。

D制动预留200ms、减速度240、原料/暂存新增50mm、发车60mm偏移及撤回粗加工新增80mm补偿均保持本轮之前的设置。机构动作配方、地图坐标和视觉协议没有扩大修改。

验证入口为 `tools/verify-no-auto-stop.ps1`。分段/连续两种编译模式注入状态异常、无位移、失效IMU、失联轮子、bus-off、串口及CAN接收溢出、CAN发送失败，核对不产生故障停车包或任务取消，再验证`!`以及缓冲溢出时`!`仍会请求全系统停止。另验证实际机构插值不中断、工位拒绝不会停止已运行机构、位置/导航提交失败不发停车包和正常到位停车。

`tools/verify-rough-braking.ps1`保留首次峰值检查。更慢响应或注入位置误差的情况会按原闭环回补，不代表没有越过禁入区。旧heading、arm、发车和堵转测试中要求“异常后自动停止”的断言与本轮策略冲突，当前仍报告失败；不能把整套旧回归视为通过。完整结果、源码哈希及Keil产物见 `evidence/current-validation.json`。

软件现已没有这些自动停机保护：异常或反馈丢失时，电机可能持续最后指令；不具备禁区安全保证。驱动器/芯片自身保护仍可能使电机停止，通信失效时软件`!`停止命令也不一定送达。未烧录、未实车验证。
