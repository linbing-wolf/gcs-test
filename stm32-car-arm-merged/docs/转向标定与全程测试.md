# 脉冲转向标定与转向后直行

2026-10-14更新：沿用操作者当前开启的IMU接收，日志已有新角度。left90/right90/left180/right180采用IMU闭环，现采用边测角边调速的连续转向，详见 [连续转向与直行航向闭环](连续转向与直行航向闭环.md) 和 [定角闭环共用说明](定角闭环共用说明.md)。本文的tl/tr和第4节run A/C仍用于原始脉冲测试及旧全程。旋转保留原四轮方向映射；驱动器完成脉冲不等于车身达到指定角度。

## 1. 下载后先测旋转方向

在地面标记车身中心和初始车头方向。使用实际调试串口、115200 8N1、文本发送、末尾换行，关闭循环发送。每条单独发送：

```text
turn
info
pulses 200
tl
```

turn 是转向标定模式，默认30 RPM。tl 只执行一次每轮200脉冲，不代表左转90度。等车自然停稳，发送 !，测实际角度并检查中心漂移。重新摆回起点后发送 tr，检查相反方向。估时只显示 OBSERVE，不宣告角度到位。

如果 tl 实际右转，将 src/car_config.h 中 CAR_TURN_CCW_DIR 从1改成0，重新编译下载并验证方向。这个方向位来自原底盘映射，左右转名称必须在实车核实后使用。

## 2. 分别标定左右转90度

用 pulses 数值 改下一次脉冲数，范围1～20000。先小角度测量，逐步接近90度。不要循环发送；重复试验前停稳并重新对齐起点。计算：

新脉冲数 = 本次脉冲数 × 90 ÷ 实测角度

分别记录左右转脉冲和实测角度，每个方向至少重复验证3次。与全程转向保持相同30 RPM；改转速后重新验证。rpm 在 turn 模式只改转向测试速度，不改全程编译配置。

## 3. 临时填值并验证90/180度

停稳后，在 turn 模式输入 ccw90 实测左转90度脉冲数 和 cw90 实测右转90度脉冲数。参数填整数，不能把中文说明一起发送。这两条只设置RAM，不驱动车辆、不写Flash。

验证旧脉冲标定时，设置 pulses 为对应90度脉冲数，再发送 tl/tr；旧全程的右转180度需另用两倍右转90度脉冲、tr实测。left90/right90/left180/right180已改成独立IMU闭环，不再用于验证单次固定脉冲的角度。

info 显示 ccw90、cw90。设某项为0可清除对应值并禁止旧 run A/C；不禁止具备有效IMU反馈的定角或 runimu 命令。复位会恢复 car_config.h 的默认值。确认后将两项写入 CAR_TURN_CCW_90_PULSES、CAR_TURN_CW_90_PULSES，重新编译下载即可长期沿用。

## 4. 跑全程

两侧转角参数都非0才允许启动。以实际A或C模型起点摆车，初始车头朝+Y；不要从上次FAULT停车处直接重发全程。发送 run A 或 run C。

路线保留原无障碍固定作业顺序，中心轨迹理论总长15040 mm。改变方向时先旋转，再沿车头前进，无左右横移、无倒车；连续同向段不重复转向。最终返回原启停区后恢复+Y。18个直行段加16次旋转，共34个动作，A/C相同；旧全程转向30 RPM，直行现为90 RPM。

旋转和直行各自等待四轮位置命令ACK及主动读取的到位反馈，然后才执行下一动作。没有扫码、机械动作或站内延时。工位朝向沿当前行驶方向，未来执行作业时再指定朝向。! 请求停车，不自动恢复路线。

heading_est 是按已完成指令推算的朝向：0=+Y、1=-X、2=-Y、3=+X。physical_pose=unconfirmed 表示没有真实定位。DONE_BY_MOTOR也不能证明真实回到起点或车头对齐。无IMU时需要记录连续转弯的累计角度和位置误差；旋转时车身占用空间也需现场核对。

原 test 四方向标定和 nav/go 人工导航仍保留为历史平移接口。本轮改动针对 turn 和 run A/C，人工 heading 命令不会使车身旋转。

## 5. 尺寸与尚未解决的问题

操作者指定沿用 1A整车第三版装配A.SLDASM。已只读提取四个轮子实体极值并转换到装配坐标，用轮体宽度中面核对轮心：轴距190 mm，轮距约215.964 mm。证据见 ../evidence/chassis-history/第三版底盘尺寸.json。理论90度轮行程=(轴距+轮距)×pi/4，乘当前10.36脉冲/mm，得到约3303脉冲。

先用200脉冲验证方向，随后可以用 pulses 3303、tl/tr 测量90度初值，仍需按实际角度分别校准左右。info 中 model90_initial 是几何计算值，不是已标定的 ccw90/cw90。默认两侧已标定值仍为0，全程不会直接采用模型估算值。模型只读读取成功，未保存或修改原模型。

此前实车全程在第二段因4号电机到位位缺失超时，这个问题尚未定位。转向方案不会自动解决它，仍保留四轮到位检查；出现同类FAULT时记录ack/ready及车辆行为。
