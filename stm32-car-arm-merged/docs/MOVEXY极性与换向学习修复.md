# r104 MOVEXY极性与换向学习修复

2026-10-26，修复一个可以复现的方向学习错误：旧代码用动作起点至今的累计CPOS位移，与最新轮速指令配对。命令已反向、反馈仍包含旧方向位移时，可将正确极性学成相反值；位置回补随后可能变为正反馈。现有实车摘录不足以证明这就是该次故障的唯一原因。

本次只修改main_table_nav.c一个生产文件，保持当前速度/加减速、两轴目标幅值和符号、1mm位置窗口、r100末段控制、视觉FIFO/终包及机械臂/离站行为。

- 将单轴行程归一符号与轮子物理极性分开。正常单轴运动通过原两份实际位移确认后，缓存CPOS相对逻辑轮速的极性。本轮道路及工位子动作交接保留缓存，MOVEXY直接使用，不再每次重新猜。没有填入未经测量的四轮正负值，也不写入非易失存储。
- 冷启动未知轮在提交指令时登记方向变化。反向后先等新速度反馈实际过零/变向，再用此后的CPOS建立局部学习原点。学习区间与整段位置原点分开，确认仍需至少2mm和两份不同时间、同向增长的位置。后续换向不改变已确认的物理极性。
- 四轮串行CPOS先按前后采样插值到共同时间，再逆混控，避免异步采样被解释为虚假双轴偏差。
- 接近对角线时，某轮可能几乎不动。冷启动三轮极性已知时，按既有混控矩阵w1-w2+w3-w4=0完成三轮可观测逆解；不能将未知轮按零位移处理，也不把推导值写成第四轮的极性标定。四轮确认后恢复完整四轮逆解。这沿用轮式里程计的运动几何假设，不能代替外部地面定位或纠正打滑。

首次确认会打印一次：

    [encoder polarity] addr=... source=straight/vector cpos=起点,前一位置,当前位置 command_sign=... polarity=...

诊断输出沿用轻量数字输出，避免运动深调用链内使用printf。保存异常前的这些行及四轮原始CPOS，可以继续排查反馈突跳或执行方向异常。
