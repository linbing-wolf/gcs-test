# 直行航向与起停优化及过程诊断（20261018-diag1）

> 当前版本已更新为20261018-route1，继续保留下述诊断字段。连续直行、`obstacle`退回和当前速度配置见 [连续直行与障碍退回](连续直行与障碍退回.md)；下文是此前控制/诊断版本说明，不是本轮新增行为。

## 本轮新增：打印间隔内的偏航峰值

2026-10-18完整 `runimu C` 日志中，两次E→H已打印的行驶角差绝对值最大为0.40°和0.47°，操作者仍报告E点转向后向H行驶时明显偏移。这些每约500ms的快照不能排除间隔内短时偏航，也不能证明地面轨迹正确。

本轮仅补过程观测：在每次主循环处理到新的IMU序号后，统计平移期间的角差最小值、最大值和对应里程、样本时间。前进、后退、左移、右移均启用；原地转向不混入平移窗口。原控制参数、速度、路线、互锁和停车判据保持不变。

保留原日志字段和约500ms定期输出，末尾追加紧凑字段，避免把打印频率提高到控制频率。新几何段建立编码器基线时清零；段末若还有未打印样本，会在 `[control segment done]` 前补一条 `[control]`，该条可能不足500ms。

```text
... error_cdeg=5 ... yaw_win=24,-210,54,182401,77,210,182750
```

`yaw_win`固定为7个逗号分隔整数，依次为：

| 序号 | 含义 |
|---|---|
| 1 | 本窗口处理到的不同IMU样本数；同一序号不重复计数 |
| 2、3、4 | 最小 `error_cdeg`、发生时的编码器 `distance_mm`、IMU样本的系统毫秒时间 |
| 5、6、7 | 最大 `error_cdeg`、发生时的编码器 `distance_mm`、IMU样本的系统毫秒时间 |

角差单位仍为0.01°，负数表示相对目标偏左，正数表示偏右。上例仅说明格式：即使当前只有0.05°误差，窗口内也曾左偏2.10°、右偏0.77°；示例不是新的实车测量。相同极值保留第一次发生的位置和时间，不把未出现过的0计入范围。

**里程是处理该角度时最近一次编码器计算值，不是与IMU同步采样的地面坐标。** 时间为32位系统毫秒计时，可能回绕。统计仅覆盖软件实际处理到的样本；主循环被串口输出阻塞时，ISR中被更新覆盖的中间角度仍无法恢复。若整个窗口的角差都很小而现场偏移明显，仍需对照地面基准，区分IMU测量/基准偏差和横向位移。

现场仍使用 `runimu C`（或对应起点的 `runimu A`），命令不变。复测时从启动版本行开始复制，保留E→H之前的转向、沿途所有含 `yaw_win` 的行、段末和H点转向。当前固件没有由代理烧录、没有上传GitHub；构建和测试见 [当前验证](../evidence/current-validation.json)。

以下保留20261017-r1的控制实现说明；当前诊断版沿用这些参数。

## 现场问题与本次改动

操作者提供的D→E、E→H和H→E日志都显示：停稳对齐误差约0.2°，前进80多毫米后先左偏约2.5°，减速时又右偏约2～3°，最终角度重新收敛。问题发生在行驶过程中，不限于E→H。日志没有四轮实际转速，不能据此指定某个电机或认定机械因素已排除。

本次在本文件夹修改共用的前进/后退控制：

1. **行驶航向PD单独计算。** 沿用1.20 RPM/度、0.30 RPM/(度/秒)的增益初值；在小角差但仍有角速度时保留阻尼，允许越过目标角之前给出制动方向的纠偏。行驶最小修正降至1RPM，不沿用原地转向的3RPM规则。
2. **前进/后退速度指令渐变。** 上升和正常下降各120RPM/秒；从0到90RPM至少750ms。减速目标结合剩余距离、减速度和100ms延迟预留，提前限制速度。正常控制短暂停顿最多吸收50ms斜坡，避免等待后一次大跳变。急停和故障仍直接停车，绕过斜坡。
3. **补充指令和反馈日志。** 保留原 `[control]` 字段，前进/后退时追加时间、速度目标、最后提交的速度、纠偏目标、实际提交纠偏、控制间隔、四轮指令及四轮原始转速。

原地转向、车头停止后的对齐和四轮停稳判据沿用原逻辑；闭环横移、机械机构互锁和动作、A/C地图与路线保持原行为。正常前进速度归零后，切回原停车对齐控制，避免用行驶阻尼环持续做低速修正而无法结束。

## 日志怎么读

前进/后退的 `[control] phase=2/3`会追加下列字段；原地转向phase=0不追加这组字段。下面仅说明格式，不是新的现场测量：

```text
... t_ms=12345 v_ref=90 v_cmd=36 turn_ref=-2 turn_cmd=-2 control_dt_ms=25 wheel_cmd_rpm=-38,34,34,-38 wheel_rpm_raw=... speed_age_max_ms=60
```

| 字段 | 单位和含义 |
|---|---|
| `t_ms` | 本次日志输出时的系统毫秒时间 |
| `v_ref` | 剩余距离/制动计算得到的前进速度目标，RPM；正前进、负后退 |
| `v_cmd` | 经过斜坡后最后提交给四轮合成的车身前进速度，RPM；不是实测车速 |
| `turn_ref` | 当前航向控制计算的旋转修正，RPM；正为左转、负为右转 |
| `turn_cmd` | 经过“不让平移轮反转”的限幅后，最后实际提交的旋转修正，RPM；不是车体角速度 |
| `control_dt_ms` | 最近两次可提交控制计算的实际间隔；25ms是目标周期，串口输出和ACK等待会增加间隔 |
| `wheel_cmd_rpm` | 地址1、2、3、4最后提交的有符号电机速度；正数对应命令 `dir=1`，负数对应 `dir=0` |
| `wheel_rpm_raw` | 地址1、2、3、4驱动器 `S_VEL` 回包解码出的原始有符号转速，RPM |
| `speed_age_max_ms` | 四轮转速中最旧一项的年龄；四项是轮询结果，不是同时采样 |

**`wheel_rpm_raw`符号来自驱动器协议，不能默认与 `wheel_cmd_rpm` 的正负号一致。** 先用已确认的电机方向核对符号关系，再判断正反向；比较各轮速度幅值和起停时差时可先看绝对值。ACK表示收到命令，不能代替实际转速。

`turn_ref`、角差等为当前状态计算，`v_cmd/turn_cmd/wheel_cmd_rpm`为最后提交批次；它们可能相差一个控制周期。原有 `error_cdeg` 仍为0.01度；按当前配置，负值表示IMU角度相对目标偏左，正值表示偏右。

日志仍每500ms输出，不为了增加日志量缩短默认周期。USART3文本输出会占用主循环时间，`control_dt_ms`和`speed_age_max_ms`可帮助判断实际延迟。仿真专项已加入115200 8N1约87μs/字符的输出耗时模型，模型不能覆盖真实中断和CAN时序的全部情况。

## 参数位置

均在 `src/car_config.h`，修改后重新编译、下载。以下是待实车验证的初值，不是已经测得的最优参数。

| 参数 | 当前值 |
|---|---:|
| `CAR_DRIVE_HEADING_KP_X100` | 120，1.20RPM/度 |
| `CAR_DRIVE_HEADING_KD_X100` | 30，0.30RPM/(度/秒) |
| `CAR_DRIVE_HEADING_QUIET_CDEG` | 20，±0.20° |
| `CAR_DRIVE_HEADING_QUIET_RATE_CDEG_S` | 50，±0.50°/秒 |
| `CAR_DRIVE_HEADING_MIN_RPM` | 1RPM |
| `CAR_DRIVE_ACCEL_RPM_PER_S` / `CAR_DRIVE_DECEL_RPM_PER_S` | 各120RPM/秒 |
| `CAR_DRIVE_BRAKE_LOOKAHEAD_MS` | 100ms，制动计算延迟预留 |
| `CAR_DRIVE_SLEW_MAX_DT_MS` | 50ms，单次斜坡更新最多吸收的时间 |

原地转向仍使用 `CAR_HEADING_*` 的原参数。实际前进中旋转修正仍有20RPM上限，并受当前平移速度限制，避免为纠偏把某些轮子反转。这里的速度上限仍由 `CAR_RUN_RPM=90`控制；串口 `rpm 30`不会把 `runimu`的全程直行上限改为30。

## 已做验证与实车待确认

已完成：IMU开启/关闭两组完整回归、直行专项、机械机构/底盘互锁专项、68编译单元ARM完整构建、AXF/HEX装载数据一致性和包内依赖/哈希检查。具体结果与源码哈希见 [当前验证](../evidence/current-validation.json)，模型前后对照见 [对照记录](../evidence/drive-heading-comparison.json)。

同一四轮响应差异模型、同一测试程序中：旧版E↔H最大偏航约3.8～3.9°，新版约0.6～0.8°，包含串口输出耗时开/关两种情况。模型参数没有由真实电机辨识；不得把这些数值当成新版本的实车误差。标准整圈模型用时A由148373变为148553ms，C由148298变为149228ms；这两组标准计时不含真实UART成本，不能据此保证比赛总时间。

现场对比应保持地面、负载、起始车身基准和初始朝向一致，重复记录D→E、E→H、H→E：起步偏航峰值、减速反向偏航、沿道路的真实侧偏、最后停靠位置及整圈耗时。日志重点看角差/角速度、`v_ref/v_cmd`、`turn_cmd`与各轮实际转速幅值。

仍有限制：轮子编码器不直接测量地面侧滑，IMU没有场地绝对航向校正，已有位置偏移不会因最后转正而自动消失。停车判据保留原合同，之前诊断出的前进小幅超程仍可能被接受，不把距离参数±1mm宣称为实车精度。本轮实车改善幅度、制动距离和载物表现仍待现场验证。
