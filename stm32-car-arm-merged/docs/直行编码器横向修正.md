# 直行编码器横向修正

对应源码版本 `20261023-merge2-r64`。普通 `runimu` 前进、后退增加横向位移反馈，补偿四轮运动不一致造成且能反映在编码器中的侧移。实车增益、误差和稳定速度上限尚未标定。

## 观测与动作

四轮方向均经原有两份新位置反馈确认后，将本直行串的编码器增量恢复为车身方向，再按麦轮逆变换提取左右位移。左偏为正，输出向右补偿；右偏则相反，后退不反转这套车身左右定义。沿用前后距离、航向PD、方向学习和反馈有效期，不根据轮速回包推算位置。

CAN四轮CPOS是依次采样的。每轮保留相邻两份采样，在四轮共同覆盖的时间插值后再投影，避免将采样时差误当侧移；无共同时间、方向未确认或反馈过期时不产生新的有效横向观测。正常控制使用仍在有效期内的最近观测，反馈不完整时沿用原停车等待/恢复流程。

横向控制为带死区、限幅和速度变化率限制的比例修正。主轴低速时进一步缩小补偿，保留四轮原行驶方向；需要横向补偿时，为横移和航向分量预留单轮300 RPM以内的余量。前后距离仍由既有计算决定，主轴停车即停止横向输出，不新增到站后的单独横移或横向到位门槛。

同方向连续直线通过中间节点时保留编码器起点和横向误差；新段重新取得静止基线后清零。横移、工位移车（含MOVE/MOVEY/MOVEXY）、原地转向及主动obstacle停车/退回不启用本修正。机械臂、视觉协议、路线表和原工位动作保持。

## 参数与日志

参数集中在 `src/car_config.h`：

| 参数 | 初值 | 含义 |
|---|---|---|
| `CAR_STRAIGHT_HOLD_ENABLED` | 1 | 普通前进/后退启用，0关闭 |
| `CAR_STRAIGHT_HOLD_KP_X100` | 50 | 死区外每毫米0.50 RPM；须实车标定 |
| `CAR_STRAIGHT_HOLD_DEADBAND_MM` | 2 | 编码器估计横向死区，mm |
| `CAR_STRAIGHT_HOLD_MAX_RPM` | 20 | 最大横向修正RPM，低速另有限制 |
| `CAR_WHEEL_MAX_RPM` | 300 | 既有单轮混控上限，集中命名后供余量计算复用 |

`[control]` 增加 `cross_mm`（左正右负）、`cross_rpm`（向左正、向右负）和 `cross_valid`（是否曾取得有效观测）。`cross_valid=1`不单独代表反馈仍新鲜，控制还检查样本时间和既有四轮新鲜度。

## 验证与边界

`tools/verify-straight-hold.ps1`对开关0/1分别编译和运行。独立四轮模型覆盖前进/后退、两侧速度偏差、16种编码器极性、错时采样、毫秒回绕、高速混控余量、急停、CAN bus-off及反馈丢失/恢复；另用只移动模型车身而不改变轮子反馈的侧滑证明这种误差仍不可观测。

此功能估计的是车身左右分量，不是结合IMU旋转积分的场地二维定位，也不保证全局路线位置。轮子空转、真实侧滑、轮径/安装误差和较大航向变化仍会造成估计误差；不依靠本功能检测所有打滑。需要实测地面位置时，应使用视觉或其他独立位置参照。

本地回归和ARM构建的当前状态以 `evidence/current-validation.json` 为准；电脑模型结果不代表烧录、实车精度或比赛验收。
