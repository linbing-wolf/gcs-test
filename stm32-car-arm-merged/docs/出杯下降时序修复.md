# 出杯下降延时

历史版本 `20261022-merge2-r60`。r61已按最新要求改为110 mm起转并继续升到135 mm，到顶后再计下降延时；当前以[出杯升降与旋转联动](出杯升降与旋转联动.md)为准。以下为r60记录。

粗加工及两次暂存从车载杯取物：合爪并保持原120 ms，抬至当前105 mm后启动云台转向与平推。**从首次转向PWM写入开始计时，达到配置延时后就提交下降指令并开始载物台预选下一杯**；云台和平推继续运行。默认100 ms时，下降发生在转向结束之前。

在 [arm_config.h](../src/arm_config.h) 修改：

```c
#define ARM_CUP_EXIT_DESCENT_DELAY_MS 100u /* 单位ms；0=立即并行，不等待转向结束。 */
```

数值越大，下降/换杯越晚；越小越早。修改后重新编译下载。此参数不改变抓取100 mm、净空105 mm、粗加工/首批暂存放料5 mm、第二批放料65 mm，也不改变速度、合爪保持或原料装车/回杯动作。

延时使用毫秒状态机，主循环继续处理串口、底盘、反馈和急停，不调用阻塞delay。载物台从延时到期后独立插值，不能沿用云台已走过的时间而突然跳到目标。零延时保留立即并行模式。

按要求只运行0/100/250 ms出杯专项（每种覆盖粗加工、首次暂存、第二次暂存各3杯）、基础航向/CAN与机械臂检查和完整ARM构建，没有重跑工位10配置/全路线。检查包含：抓稳保持、升到105、平推与旋转启动、延时前无下降/无换杯、延时后下降到5/65、默认100 ms不等转向结束及最终姿态。未烧录实车；实际避让与防掉落效果仍须按实物调整延时。
