# 独立视觉纠偏调试（r49）

操作者确认的需求：不用运行完整路线，实际执行上位机`MOVE/MOVEY`纠偏；完成后不抓放、不接下一段路线。

## 串口指令

调试串口仍为USART3、115200、回车结束。

| 指令 | 行为 |
|---|---|
| `vision debug` | 默认按粗加工D测试一次视觉纠偏 |
| `vision debug D` | 粗加工D |
| `vision debug E` | 暂存圆盘E |
| `vision debug F 1` | F码垛识别颜色1；颜色可选1～4 |
| `vision debug status` | 查看调试是否运行及现有视觉会话、队列、最近回包 |
| `vision debug off` | 中途退出，按现有全局停车流程取消；已经结束则只提示inactive |
| `!` | 保持原有全局急停 |

调试需要人工把车放到相应视觉区域，不会自动开到工位，也不要求二维码或任务码。`station auto on/off`原设置保持；一次只运行一个视觉任务，运行中不接受第二次D/E/F或抓放命令。

## 进入前的现有机构声明

沿用原有`arm on`互锁、已知机构/载物台姿态和新鲜IMU条件。升降应在135mm高位、平推在0mm收回位置。已经按正常作业流程声明过且保持高位收回时，直接发`vision debug`即可。

尚未声明时，在确认实际机构位置后，按现有方式操作：

```text
arm on
```

等待`[arm interlock acquired: ...]`。若实际姿态确为平推0、升降135、云台0、夹爪45、载物台1号20°，再声明：

```text
arm pose 0 135 0 45
arm platform pose 20
vision debug
```

姿态声明不是自动归位，数值必须与实际位置对应。调试入口不会自动伸出/下降，也不打开或闭合夹爪，不旋转载物台。它只把已经高位收回的云台转到所选工位观察角（当前126.5°），完成该动作后再请求视觉。

## 一次调试的流程

1. 转到所选工位观察角，发送一次D、E或F,颜色。
2. 复用自动作业的视觉收包、FIFO和编码器/IMU移车，不引入另一套纠偏算法。当前仍按操作者假设1px=1mm；MOVE正后退、负前进；MOVEY正左移、负右移。
3. 每条离散位移按收到顺序执行，0不覆盖旧指令；不重乘视觉增益，不重算坐标差或增设图像合格门槛，不自动重发，不发送R/READY/运动ACK。
4. D/E等DISC、F等STACK终包；执行完已收队列、当前移车和原有停车/互锁交接后打印：

```text
[vision debug done] commanded moves complete; hold position/yaw; no grip, return or route
```

5. 保持纠偏后的车位和观察角，退出本次会话。没有夹取、放置、150/300mm索引、F放后基准恢复或自动离站动作。可以直接再次发调试指令进行下一次测试。

一次成功结束不会清除已存任务码，也不会改变`station auto`设置。若之后要恢复完整路线，先按原流程收臂回正（`arm home`），并把车放回所选起点后再启动。

## 中途退出

`vision debug off`在调试运行中与现有全局停车语义一致：停止车和机构、取消待执行视觉位移以及积压CAN动作，停止云台插值并保持最后PWM；原有姿态有效性会被清除，重新测试需要按原方式检查并声明姿态。任务码也按现有显式全局停止规则失效。已经成功结束后再发off，不会额外停止机构或清除已知姿态。

中途退出不会给视觉板发送R；视觉板上的本次任务可能仍运行，待其结束后再开始下一次测试。退出或急停后的迟到MOVE/终包不能重新启动下位机动作。正在跑正常路线时，`vision debug off`仅提示调试未运行；全局停车仍用`!`。

## 验证范围

主机联合测试覆盖默认/D、E、F四种颜色；无二维码和任务码、带预存任务码、自动作业开/关；观察角准备、四条双轴纠偏、提前终包、完整幅值和顺序；成功后两秒内无抓放、轴运动、换盘、索引、回程和路线衔接；任务与原自动作业开关保留。另测等待、转云台、移车期间的off/急停，迟到指令、重复请求、非法参数、姿态/IMU未准备、已有运动及bus-off。

保留当前目录已有的机构加速度220、夹爪插值50ms，本次不修改这些参数，也不修改扫码代码、CAN发送队列或视觉协议。六套回归、工位10配置和完整ARM构建结果以`evidence/current-validation.json`与`evidence/vision-debug-r49-verification.json`为准；未烧录、未连接实车或视觉板。像素比例、方向、机械臂/相机安装和实际对准效果仍需实测。
