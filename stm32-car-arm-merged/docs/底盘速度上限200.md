# 底盘速度上限200

2026-10-25，版本`20261025-merge2-r91`。操作者在150/250RPM横移对照后，要求将底盘RPM上限统一为200。本次只实施速度上限调整，不引入此前讨论的四轮协调斜坡修改。

## 调整范围

- `CAR_WHEEL_MAX_RPM`：300→200，约束IMU闭环平移、转向、连续路径及组合混控的最终单轮速度指令。
- `CAR_RUN_RPM`及`CAR_LATERAL_MAX_RPM`共用上述上限：原前后/横移请求3000→200。
- `CAR_TURN_CLOSED_LOOP_RPM`共用上述上限：自动原地转向请求1000→200。
- test、turn、人工导航的`rpm`输入范围20～300→20～200；201及250等超范围输入拒绝，保留原设置；人工导航`rpm 0`仍使用道路表速度。
- 位置模式及导航模块已有RPM范围检查使用同一上限，避免通过其他入口提交超过200的底盘指令。
- 原有60RPM工位微调/索引、60RPM障碍返回、30RPM手动转向初值及其他较低值保持。mm/s、RPM/s和驱动器加速度档位不按RPM数值替换。

## 保留参数及限制

通用及D制动预留均200ms，道路减速度240RPM/s；地图及离线路表、原料和暂存流程、升降/平推机构速度、回补方式及软件故障策略保持。旧自动停机断言仍与当前策略冲突，不能称完整回归通过。

`tools/verify-chassis-rpm-limit.ps1`检查三个串口模式边界、125组三轴混控、位置模式前后、200RPM左右横移、正反180度转向及A/C自动发车；验证软件输出上限，不证明实车速度不会超调。构建与验证记录以`evidence/current-validation.json`为准。

200RPM尚未烧录或实车验证，不能据150RPM表现改善便认定200RPM已解决横移后窜。
