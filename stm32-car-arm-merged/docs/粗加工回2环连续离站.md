# 粗加工回2环连续离站（r81）

2026-10-24。用户选择“仍经过2环，但不停顿，直接衔接下一段道路”。本次仅改变两次粗加工的最后一块抓回及离站衔接；原料、暂存第一批和第二批F/STACK作业不扩大修改。

## 新时序

最后一块地面夹紧并完成合爪保持 → 实际升降通过既有110mm起转净空 → 底盘读取新的四轮位置并开始离站，机械臂继续放回原杯位 → 机械臂直接收回到0度，载物台回1号 → 底盘连续经过2环附近并接入D→E→H。

最后放回载物台后不再转126.5度观察角。回2环不再是一个要停车确认的工位子动作，期间不发视觉请求。最后抓取环为2时回程前缀为0，直接走道路；为1或3时，将原150mm前进／后退作为同一连续路径的第一段。

延续现有圆角规划：150mm短段将半径自动限制为75mm，因此经过2环附近、不会精确穿过其几何中心。路径的场地原点按最后抓取环的位置偏移换算；后续暂存区目标仍是原地图H点，不通过复位模拟位置掩盖误差。原150mm属工位索引，本次虽并入道路执行，仍不重复计入名义13960mm道路里程。

## 保留的完成条件

- 夹爪及合爪保持先完成；升降位置实际达到原110mm条件后才允许离站，不用估时替代位置。软件仍无夹持传感器。
- 底盘和5/7号机构分别消费原有CAN队列；离站使用新反馈建立位置基线。车载放回、收臂、平台回1仍完整执行，真实故障与显式停止仍同时取消两边。
- 原反馈延迟等待保留；没有增加超程、角度或时限阈值停机。外部输入obstacle时，因为整条前缀路径的起点不是地图D点，沿用工位停止策略，不自动倒回最后抓取环后声称已到D。
- `CAR_ARM_TRANSLATION_OVERLAP_ENABLED`、`CAR_RUN_CORNER_ENABLED`、`CAR_RUN_OMNI_ENABLED`任一为0，保留原串行或工位并行的回2环停车编排。`STN_ROUGH_THROUGH_ENABLED`是三个已有开关的派生条件，不是独立调参项。

## 本次验证

`tools/verify-ring2-through.ps1`覆盖A/C、两次粗加工及全部6种环号排列，共24组；独立模型确认150/0/−150mm前缀、2环附近非零轮速、最后车载松爪发生在行驶中、直接回0度、原H点终点及一次D视觉。另测109mm未到净空、缺失升降反馈、110mm放行、底盘反馈暂停/恢复、急停/总线故障/obstacle/arm stop取消两边。
