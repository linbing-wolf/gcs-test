# 机械臂高位并行（r50）

本次优化原料区、粗加工区和两次暂存区的自动抓放。使用现有机械臂执行器的一步多机构能力，减少先转向、再平推、再张开空爪的串行等待。

| 场景 | r50动作 |
| --- | --- |
| 原料区接近物块 | 在135 mm高位同时转到131°、平推到55 mm、张开空爪；整个动作完成后下降到105 mm、合爪 |
| 原料区放到车载平台 | 合爪后先升到135 mm、收回平推；同时转到256°并平推到35 mm，完成后下降到110 mm、松爪 |
| 粗加工/暂存区从平台取料 | 在135 mm高位同时选杯、转到256°、平推到35 mm、张开空爪；全部完成后下降到100 mm、合爪 |
| 粗加工/暂存区向地面放料或抓回 | 在135 mm高位同时转到126.5°并平推到55 mm；全部完成后下降到原有取放高度，再松爪或合爪 |
| 粗加工抓回后放到平台 | 在135 mm高位同时选杯、转到256°并平推到35 mm，夹爪保持闭合；全部完成后下降到110 mm、松爪 |

粗加工及第一批暂存的地面取放仍为lift=5 mm，第二批暂存码垛仍为65 mm。升降和平推仍为4000 RPM、机构加速度220、云台/载物台插值400 ms、夹爪插值50 ms。本次不修改这些参数。

升降离开物块或杯壁、随后收回平推的先后顺序保留。没有实测杯壁净空，直接把低位上升与水平回收合并，会改变物块离杯路径。高位并行步骤的下降由原有位置反馈及舵机完整插值完成后衔接，没有增加固定等待。

云台与平推并行意味着在135 mm高位边转边伸；实车仍需核对这段扫过空间。本地测试不能证明无碰撞、夹持成功或实际节省的秒数。

底盘、路线、工位索引、二维码、视觉D/E/F与MOVE/MOVEY协议保持原有逻辑。第二次暂存仍逐块发送F。离站末尾纯云台/载物台回正步骤保留，继续与底盘离站转弯重叠。独立vision debug没有抓放动作。

验证记录见 `evidence/arm-parallel-r50-verification.json` 和 `evidence/current-validation.json`。前后各26个相同工位模拟场景的耗时对比见 `evidence/arm-parallel-r50-benchmark/comparison.json`；该模型立即返回轴目标位置，不包含实际机构加减速和物理串口成本，不能据此推算实车450秒会缩短多少。
