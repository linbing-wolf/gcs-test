# 串口命令速查与故障处理

核对日期：2026-10-23。适用于本目录当前源码，启动版本标识为 `20261022-merge2-r63`。完整准备流程、接线、互锁和视觉协议见[合并与串口操作](合并与串口操作.md)。

## 发送规则

- 电脑连接调试串口 USART3：PB10 TX、PB11 RX、GND共地，3.3V逻辑。
- 串口助手：**115200、8数据位、无校验、1停止位、无流控、文本/ASCII发送**；关闭循环发送。
- 普通命令以 LF 或 CRLF 结束；**`!` 无需换行，全系统停止**。
- 命令区分大小写；表中的 `P/Z/Y/C/N/DEG` 是参数占位符，需要替换为数字。`1/2/3` 表示选一个数字，不发送斜杠。
- 平推、升降使用整数毫米；机构角度可带一位小数，均为绝对目标坐标。例如 `arm lift 130` 是到130mm，不是上升130mm。
- 运动指令逐条发送，等完成并检查实际机构后再发下一条。`[accepted]` 只表示接受指令。

## 1. 查询与停止

| 指令 | 作用 |
|---|---|
| `help` | 板端帮助 |
| `info` | 底盘模式、导航和路线状态 |
| `feedback` | 四轮反馈及故障诊断 |
| `imu` | 航向、采样和数据新鲜度 |
| `arm status` / `arm` / `claw status` | 机构姿态、步骤、PWM、杯位和互锁状态 |
| `station` | 自动开关、工位步骤、两批任务及视觉比例 |
| `vision status` / `vision` | UART5视觉状态、最近payload及移车队列 |
| `!` | 无需换行，全系统停止并取消本轮作业 |
| `s` / `z` / `S` / `Z` | 需要换行，全系统停止 |
| `arm stop` | 手动时停止机构、保留底盘独占；启用自动工位的路线/工位中取消整个作业并停车 |

停止保留最后舵机PWM和步进使能，机构位置基准失效；舵机仍可能趋向最后目标。重新动作前按实际姿态恢复声明，详见详细文档。

## 2. 夹爪、升降、平推和云台

普通机构动作需要 `arm on` 会话有效、已声明实际姿态且5/7号轴反馈满足条件。

| 指令 | 作用 / 范围 |
|---|---|
| `arm on` | 申请独占底盘，发停车并获取四轮新状态/速度反馈，满足互锁后启用5/7；首次启用时舵机PWM仍关闭 |
| `arm pose P Z Y C` | 声明实际平推mm、升降mm、云台°、夹爪°；不移动两轴或清编码器，但立即写云台/夹爪PWM |
| `claw open` / `arm open` | 张爪45° |
| `claw close` / `arm close` | 合爪15° |
| `claw angle N` | 指定夹爪角度0～270°；例如 `claw angle 30` |
| `arm slide N` | 平推0～187mm，0为收回；187为理论上限，未全行程实测 |
| `arm lift N` | 升降0～135mm，135为最高位 |
| `arm yaw N` | 云台−94.5～265.5°；例如 `arm yaw 126.5` |
| `arm move P Z Y` | 同一步提交平推、升降和云台目标；不改变夹爪 |
| `arm home` | 升135 → 平推收回0 → 云台回0°；保持夹爪，不改变平台杯位 |
| `arm off` | 收拢后退出独占，关闭夹爪/云台/平台PWM；5/7保持使能，夹爪可能失去保持力 |

`arm pose` 是人工声明，**不是自动回零**。不要把目标位置当作已经到达的位置来声明。

## 3. 载物台和抓放序列

| 指令 | 作用 / 条件 |
|---|---|
| `arm platform pose DEG` | 声明平台实际角度0～270°，立即写平台PWM |
| `arm platform 1` | 1号杯20° |
| `arm platform 2` | 2号杯139° |
| `arm platform 3` | 3号杯256° |
| `arm pick` | 从平推0/升降135/云台0开始，按原料抓取姿态夹一块，最后保持夹住 |
| `arm place` | 将手中物块放到当前杯位；须已声明平台角度，不自动换杯 |
| `arm cycle` | 收拢 → 夹取 → 放平台；过程会开爪 |
| `arm load1` | 装一块到当前杯位，再切下一杯，末尾保持131°取料预备角 |
| `arm load1 last` | 装一块后回车头0°，平台并行切下一杯；自动原料第三块使用 |
| `arm load3` / `@` | 连装三块，最后收拢并回1号杯位；手动不等待视觉 |

手动 `arm platform N` 要求已声明平台角度，且平推0、升降135、云台0°。平台1号杯位和地面1号环位不是同一个概念。

兼容别名：

| 指令 | 等效指令 / 含义 |
|---|---|
| `arm load 1` | `arm load1` |
| `arm load 3` / `arm cycle3` | `arm load3` |
| `arm pick red` / `arm pick green` / `arm pick blue` | 都等效 `arm pick`，不按颜色选择物块 |

## 4. 整圈路线与任务码

| 指令 | 作用 / 条件 |
|---|---|
| `runimu A` / `runimu C` | 从实际A/C起点启动整圈；自动作业默认开启 |
| `station auto on` | 闲置时启用自动到站作业，上电默认on |
| `station auto off` | 闲置时关闭到站作业，只跑底盘；启动前须退出机构会话 |
| `task 134+123+314+231` | 完整两批任务：第一批颜色+第一批粗加工环位+第二批颜色+第二批粗加工环位 |
| `task 123` | 第一批颜色简码，仅供单批调试，不能完整执行第二批 |
| `obstacle` | runimu道路行驶期间停车，按已记录运动退回上一已记录节点并停等；不自动重规划 |

自动作业须保留有效机构会话，机构已声明并收拢，平台为1号位。行驶/作业中不能更改自动开关；首个B点等任务时可补输入任务码。工位、环位移车或离站重叠期间发送 `obstacle` 会故障停车，不倒退。

任务码也可连写12位，或省略 `task ` 前缀。颜色1红、2黄、3蓝、4绿；每批三色不重复，两批颜色集合相同；两组环位均为123的排列。任务在一整轮两批作业内复用，整轮结束、全局停止或故障取消后清空。

## 5. 底盘单段测试

先收拢机构并 `arm off`，再切换模式。`rpm` 修改当前测试/人工导航模式的速度，不修改runimu固定配置。

| 模式 / 指令 | 作用 |
|---|---|
| `test` | 进入车身方向单段测试 |
| `dist 60` | 设置一段60mm；范围50～2000mm |
| `rpm 30` | test/turn速度范围20～300RPM |
| `f` / `b` | 前进 / 后退一段；位置模式估时不代表实际到达 |
| `l` / `r` | 左 / 右横移一段，IMU航向+编码器距离闭环 |
| `turn` | 进入IMU定角转向测试 |
| `left90` / `right90` | 左 / 右转90° |
| `left180` / `right180` | 左 / 右转180° |

当前横移上限与runimu行驶请求上限共用配置，不再是旧文档中的60RPM限制；手动 `rpm` 的输入范围仍为20～300。转向、横移需要新鲜IMU。

## 6. 人工节点导航

先 `nav`，再按真实节点和朝向声明；整圈入口仍为 `runimu A/C`。

| 指令 | 作用 |
|---|---|
| `nav` | 停止当前流程，切到人工查表导航；需要重新确认位置 |
| `pose A` | 确认实际节点，范围A～I |
| `heading N` | 地图朝向：0=+Y向下，1=−X向左，2=−Y向上，3=+X向右 |
| `go H` | 导航到目标节点，范围A～I |
| `rpm N` | 人工导航20～300RPM；`rpm 0` 使用道路表速度 |
| `confirm` | 当前段等待人工确认时，确认真实运动已完成 |
| `node B` | 确认实际已到节点，范围A～I |
| `obstacle` | 报告当前导航段障碍 |
| `return A` | 确认实际已退回节点，范围A～I |
| `block N` / `unblock N` | 标记 / 解除道路阻断，编号0～11 |
| `progress N` | 上报已测量的当前段进度，整数毫米 |

人工确认不会测量实物，不能用来跳过未完成运动。切换模式会停止并使原导航位置确认失效。

## 7. 视觉请求与独立纠偏

| 指令 | 作用 |
|---|---|
| `vision ping` | 仅向视觉端发送D；不启动车辆纠偏 |
| `vision range` | 仅向视觉端发送R；不自动改变机构/底盘坐标 |
| `vision pick N` | 手动请求颜色1～4，等待PICK；不自动夹取 |
| `vision clear` | 取消视觉请求，保留统计计数 |
| `vision debug` / `vision debug D` | 执行一次独立粗加工视觉纠偏 |
| `vision debug E` | 执行一次独立暂存圆盘纠偏 |
| `vision debug F N` | 执行指定颜色的独立叠放识别纠偏，N为1～4 |
| `vision debug status` | 查询独立纠偏及视觉链路状态 |
| `vision debug off` | 调试运行中按全局停止取消；调试未运行时仅提示inactive |

**`vision debug` 会移动车辆**，但不抓放、不做环位索引、不继续路线。需要人工把车放到对应区域，先建立机构会话，声明机构/平台姿态，平推收回0、升降135mm且IMU新鲜。详细步骤见[独立视觉纠偏调试](独立视觉纠偏调试.md)。

当前D/E/F使用同一视觉位移FIFO，支持MOVE/MOVEY/MOVEXY；MOVEXY两轴并行。MOVE正后退、负前进，MOVEY正左、负右；比例当前假定1px=1mm，尚非实测标定。这些payload从UART5二进制帧接收，不能直接当作电脑调试口文本命令。

## 9. 云台全行程诊断

| 指令 | 作用 |
|---|---|
| `arm yawtest init N` | 声明并直接输出云台起始脉宽，500～2500μs |
| `arm yawtest N` | 0～360测试刻度，单次8秒插值；不是普通云台逻辑角 |

测试刻度0→2500μs→逻辑−94.5°；94.5→1975μs→逻辑0°；360→500μs→逻辑265.5°。`arm yawtest 0` 不是回初始位。要求机构互锁有效，不依赖5/7轴反馈；保持夹爪/平台PWM，测试后位置基准失效。

## 10. 完成反馈与常见问题

| 输出 / 状态 | 含义或处理 |
|---|---|
| `[accepted]` | 命令接受，不等于运动完成 |
| `DONE_BY_IMU` / `DONE_BY_IMU_ENCODER` | 软件闭环完成，仍需核对真实朝向/位置 |
| `estimate elapsed` / `NOT arrival` | 只是估时，不能认定到达 |
| `[arm step complete: ...]` | 单步完成，序列可能继续 |
| `[arm done: ...]` | 两轴反馈和舵机指令时序完成，没有夹持/舵机角度传感器 |
| `[vision debug done] ...` | 已收纠偏动作执行结束，保持当前位置/观察角 |
| `[arm interlock] state=` | 0无会话、1等反馈、2独占有效、3故障锁定 |
| `[arm] state=` | 0空闲、1预检、2提交命令、3运动、4停止/故障、5云台诊断 |
| `referenced=0` | 对应机构/平台姿态基准无效，需要按实际位置重新声明 |

| 提示 / 现象 | 当前处理 |
|---|---|
| 串口无回复 | 检查交叉接线、共地、115200、换行及芯片是否运行；发送回显不代表收到回复 |
| `session pending/already on` | 会话已建立或仍在等反馈；查询 `arm status`，不要连续重发 |
| `arm session owns motion` | 手动底盘被机构锁定；收拢并 `arm off` 后再测试；自动作业按详细文档准备 |
| `route/station owns motion` / `route/station owns request` | 路线/工位占用中，手动动作或视觉请求被拒绝 |
| `chassis active` | 底盘仍有活动流程，先停止并检查 |
| `four-wheel confirmation delayed` / `arm interlock feedback stale` | 告警并继续查询；检查四轮地址、供电和CAN反馈，不表示已取消或完成 |
| `wheel disabled/stalled/protected` / `CAN transmit/bus fault` | 硬故障停止；检查后重建互锁及实际姿态 |
| `arm on and four-wheel stop confirmation required` | 需要有效机构会话，先 `arm on` 并等待互锁成功 |
| `actual pose unknown` | 按实物重新 `arm pose P Z Y C`，不能伪造已到位 |
| `busy; use ! or arm stop` | 上一动作未结束，等待完成或停止 |
| `feedback reply timeout` / `action deadline exceeded` / `position ACK missing` | 当前是告警并等反馈/位置，不代表动作完成；保留完整日志诊断 |
| `[arm axis warning]` | 5/7号轴状态异常仅记录；不自动清保护，也不虚构到位 |
| `declare actual platform angle` | 按真实平台角度声明 `arm platform pose DEG` |
| `platform requires declared angle and arm home pose` | 声明平台角度并完成收拢后再切杯 |
| `park with arm home` | 未满足退出姿态，不能释放底盘 |
| `PICK delayed` / `alignment reply delayed` / `STACK reply delayed` | 视觉等待告警，保留本次请求；不会据此自动抓放 |

当前四轮轮速幅值及非零持续时间只记录，不沿用旧稿±5/±15RPM停机规则；5/7号轴的失能/堵转/保护状态也仅记录。四轮硬故障、CAN硬故障、机构位置命令被拒绝、超行程等仍需分别处理。完整判据与恢复步骤见[合并与串口操作](合并与串口操作.md)。

已移除的旧命令：`run A/C`、`tl/tr`、`pulses N`、`ccw90 N`、`cw90 N`。定角转向使用 `turn` 后的 `left90/right90/left180/right180`。
