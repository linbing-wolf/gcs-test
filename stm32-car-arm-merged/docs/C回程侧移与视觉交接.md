# C回程侧移、道路超程与视觉交接（r79）

2026-10-24，`20261024-merge2-r79`。操作者报告整轮约250秒，限时180秒，包含扫码和视觉等待。本版没有实车验收，也不代表追回约70秒或保证180秒完成。

## C回程

H→E→B恢复原1770mm逻辑横移，E→B仍990mm，B弯的地图参考恢复x=2190。原60mm侧移改在B→C的前、中段同步完成：B弯出口(2190,1350)后，前600mm前进行程按五次曲线从0侧移到60mm，两端侧移速度和加速度均为零；随后280mm只直行到原C(2250,2230)。车头仍保持+Y，末尾没有独立横移段。

参数 `CAR_C_RETURN_BLEND_MM=600`。二维编码器/IMU跟踪两轴，C终点仍需位置窗口、原航向及零指令/反馈条件。直行参数保留道路240RPM/s、工位150RPM/s、制动120RPM/s，固定车头弧段参考250mm/s、转头弧段上限150mm/s及轮速变化率规划保持。独立侧移分量在接近最终x目标前预制动，为另一轴留出变化率余量，避免前进加速挤掉侧移制动。

连续路径的s在侧移段按前进方向毫米计，真实斜向轮迹略长；逻辑总距离仍按前进1030+侧移60计入，整圈13960mm不变。A路线几何、人工导航地图及离线路表不修改。关闭连续路径或全向模式时，C回到原分段路径，包括最后独立60mm；默认两项均为1。

## 长道路超程

- 固定车头连续路径：四轮CPOS先按共同历史时刻积分，再用同一数据估计的速度给控制参考补偿采样年龄，预测范围不超过既有100ms预留。历史位置本身不改写；C等非作业终点仍检查实际采样位置，不以预测宣布到位。
- 普通全向道路：用新鲜四轮速度及CPOS平均年龄，在减速参考中提前扣除这段延迟行程；编码器到位判据不外推。工位微调、测试平移和障碍退回不使用该道路补偿。
- 同步转动车头的弧段继续沿用共同采样时刻的原转向前馈，本次不重新调其控制参数。

这些改动针对已观测的运动与控制滞后；编码器不可见的轮胎侧滑、离开H前已有的地图坐标偏差仍不能自行测出。相对位置控制及主机模型没有车身轮廓/场地绝对边界约束，不能由“规划未越线”推断实车必不压边界。

## 作业区末端由视觉接手

只有自动F/D/H进站最后一段、导航行程已到达且残差在 `CAR_ROUTE_VISUAL_WINDOW_MM=50` 初始窗口内，才取消反向追补原停车坐标。明显偏离路径时仍继续导航纠偏，不提前跳过中途道路。停车指令、航向和新鲜反馈仍按原规则完成，然后执行原料H、粗加工D或暂存E/F等既有视觉流程。

50mm是工程初值，尚不是实测相机视野或地面精度。`[route arrival]`记录残差；未收到原视觉成功条件仍等待，不因进入窗口就抓取。视觉每条MOVE/MOVEXY、环位索引、扫码B和最终C等非作业终点继续按原编码器位置条件执行；没有删除全程位置闭环。进站最后5mm的机构准备保留；导航残差已交视觉且仍在50mm窗口内时，也允许原低速、航向和高位收回条件下开始观察准备。全部六次进站均检查准备先于底盘交接；取消末端倒回后，不再要求每次观察PWM都赶在车辆仍运动时发生，原视觉/夹取及工位索引靠近并行条件保持。

没有新增阈值停机、任务取消或真实轮速幅值互锁。原急停、驱动器故障、反馈等待与恢复政策保持。

## 实车计时

每次正常 `runimu A/C` 开始独立统计，作业序号变化时输出 `[run timing] stage job=...`，完成、停止或故障后输出 `[run timing] total`：

| 字段 | 互斥计时范围 |
|---|---|
| `road_ms` | 道路执行，包括起步预检、转向和反馈等待；重叠机构时间不重复累计 |
| `scan_wait_ms` | B点停车等本轮任务，不包括行驶中并行扫码 |
| `station_move_ms` | 工位MOVE/MOVEXY及环位索引子动作 |
| `arm_ms` | 工位机构busy，其间视觉即使也在等待也不重复累计 |
| `vision_wait_ms` | 非机构busy、非工位移车时等待视觉应答 |
| `other_ms` | 工位其他交接/反馈等待 |
| `total_ms` | 上述互斥时间之和 |

旧benchmark日志的 `chassis_ms` 为主循环采样tick计数，未计入循环内的模拟CAN延时，不能与本版 `road_ms` 直接相比；整轮 `total_s` 则可在相同模型下比较。本版分类直接累计毫秒时钟差。

这是程序状态对应的实际墙钟时间，不是实体机械动作完成传感。阶段名称及并行动作优先级见表，不能把每个子系统busy持续时间再相加。计时只打印阶段边界，不消费CAN/视觉数据或推进任务。

## 验证与本地调值

当前结果见 `../evidence/current-validation.json`。专项覆盖C侧移单调性/末段纯直行、独立轮速积分的B附近外侧峰值和C终点、编码器极性/轮速不一致、实际20mm超程交视觉而不倒回、视觉子动作/非作业终点边界及计时归类。原圆弧15°/35mm运动跟踪模型预算保持；自动工位最终导航坐标改按50mm交接窗口检查，不能再称该导航终点满足1mm。

执行期间本地机构配置另有调值：出杯延时300→200ms、云台150→100ms、夹爪插值50→30ms、合爪保持120→50ms。本版保留它们，未将其作为本次修改；当前回归和固件均使用这组配置。机构状态测试按完整六类反馈轮询周期取样，不再假定旧云台时长。当前参数的真实夹持、净空和舵机跟随仍需实车验证。

前后耗时比较使用相同的当前机构参数；相较本次改动前模型整圈变化很小，不能推算实测能省约70秒。模型不包含实际视觉等待分布和地面打滑，应使用下一轮的阶段/总计日志定位250秒的主要耗时。

工位联合套件配置0～8与各专项分别记录；配置9的既有 `push_move_to` 测试夹具编译错误仍未作为通过。只生成本地固件，未烧录。
