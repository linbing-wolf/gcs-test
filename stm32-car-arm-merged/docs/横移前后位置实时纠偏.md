# 横移前后位置实时纠偏

2026-10-25，版本`20261025-merge2-r92`。按操作者要求，在普通左右横移中加入前后位置实时纠偏，复用原前进/后退的横向位置保持模块。

## 行为与参数

四轮位置反馈先插值到共同时间，再逆混控提取前后轮行程，使用前后系数`CALIBRATED_PPM_Y`换算毫米。以本次连续直行串开始时的编码器位置为零，前偏时输出后向速度，后偏时输出前向速度；F→E→D通过E时不重置这个参考。IMU仍独立维持航向。

位置纠偏开启时，普通横移不再叠加左20/右8mm每米的固定前移前馈；这些配置保留给关闭位置纠偏及其他原执行路径。两套控制不同时推动车身。

| 参数 | 当前值 |
|---|---|
| `CAR_STRAIGHT_HOLD_ENABLED` | 1，前后行驶和普通横移共用开关 |
| `CAR_STRAIGHT_HOLD_KP_X100` | 50，即0.5RPM/mm，沿用原值 |
| `CAR_STRAIGHT_HOLD_DEADBAND_MM` | 2mm，沿用原值 |
| `CAR_STRAIGHT_HOLD_MAX_RPM` | 20RPM，低速时进一步收窄，沿用原值 |
| 最终单轮指令上限 | 200RPM，主横移为纠偏及纠角保留轮速余量 |
| 减速度 / 制动预留 | 240RPM/s / 200ms，保持 |

纠偏只在主横移仍有速度时与其同时执行；主轴归零，前后纠偏也归零，不新增到站后的前后回位动作或停车等待。没有修改主轴到位判据、故障策略、地图、机构参数和任务编排。工位、MOVEXY、连续路径及obstacle使用各自既有控制，不叠加本模块。

## 日志

普通横移的`[control]`新增：

```text
cross_axis=forward cross_mm=12 cross_rpm=-5 cross_valid=1
```

表示编码器估计前偏12mm，位置模块输出后向修正。`cross_rpm`不是最终单轮转速；单轮看`wheel_cmd_rpm`。这是轮行程估计，不是视觉或地面绝对坐标，不能把2mm死区称为实车定位精度。

## 验证与限制

`tools/verify-lateral-hold.ps1`比较开关0/1：每种配置覆盖64种左右横移/前后偏差/编码器极性组合，并重跑原64种前进后退轮间偏差和共同时间采样检查。开关关闭保留原经验前移路径；开启时，横移轮间偏差模型的最坏末端前后偏移由132.076mm降至12.300mm，过程中最大21.235mm。新横移回归预算为末端15mm、过程25mm；主轴停下后不追补，因此不承诺终点收敛至2mm。

模型中可由编码器观测的±30mm前后位移得到纠正，终点约±4.4mm；只改变地面位置、不改变编码器的±30mm滑移仍然留存。该结果明确表明本模块不能检测全部空滑、滚轮侧滑或偏航引起的地面累计误差。

200RPM输入与输出专项、D制动和首次暂存离站兼容检查、自动故障停机移除专项及Keil构建记录见`evidence/current-validation.json`。旧heading/arm套件仍在要求自动停机的断言处失败，不能称完整回归通过。未烧录、未实车验证，也未宣称已查明驱动器高速失配的物理根因。
