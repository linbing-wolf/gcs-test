# 出弯渐进加速（r95）

同步转头圆弧完成后，实际车头仍可能有残余偏角。出弯直线允许边修正航向边温和升速，不等待航向误差变成零。

| 实际车头距最终方向的偏差 | 沿路径升速率 |
|---|---|
| 接近15度 | 从90 RPM/s起逐渐恢复 |
| 10度 | 约165 RPM/s |
| 5度以内 | 恢复原道路240 RPM/s |

参数集中在 `src/car_config.h`：`CAR_CORNER_EXIT_YAW_CDEG=1500`、`CAR_CORNER_EXIT_ALIGNED_CDEG=500`、`CAR_CORNER_EXIT_ACCEL_RPM_PER_S=90`。角度单位为0.01度，升速率是等效电机RPM/s。`CAR_CORNER_EXIT_BLEND_ENABLED=0`恢复r94出弯行为，改后重新编译下载。

只对转头圆弧之后的出弯直线生效，不在弧内提前突破原规划限速。按实际航向残差线性增加路径参考升速率，位置修正及转向反馈沿用原能力；单轮混控斜坡继续最终约束输出。实际轮速和路径加速度不由软件参考保证。

原3度航向误差比例限速保留；圆弧参考180mm/s、150mm半径规划157.7mm/s、弧内轮速变化率300/300RPM/s，以及停车减速度200RPM/s、200ms制动预留、横移分档、地图、工位与急停策略保持。

`tools/verify-corner-exit.ps1`对比r94与r95，检查5～15度偏差时路径参考确实上升、加速度渐增、≤5度恢复原加速度，以及减速/弧内/退回/视觉终点范围。每组包含108种独立车辆模型场景和A/C各8项作业的完整路线。最终配置的全程模型耗时与r94相同，不能据此宣称实车减少等待或提高全程速度；此版验证的是更渐进的出弯衔接。

早期尝试在弧尾直接放宽航向速度上限，完整路线模型出现新增偏差，未纳入最终固件。当前保留原上限，实车效果仍需复测。没有烧录或实车验收。
