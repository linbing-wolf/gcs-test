# 第二次暂存并行移位与离站（r96）

第二次暂存放下物块后，机械臂开始连续抬升并收回；实际升降反馈达到既有125mm离物净空，即可启动下一环固定索引，不等完整升到135mm最高位或机构动作全部结束。仍沿用现有净空及新鲜反馈判据，没有降低门槛。

第一、二块放下后，下一环150mm或300mm的固定距离移动与继续抬升、收回并行。下一次F定位等待固定移位及机构收拢完成；F/STACK终包及其MOVE/MOVEY/MOVEXY纠偏完成后，才进入该块平台取料和65mm叠放。每批仍有3次F，平台取料100mm、层高60mm、夹爪/升降/平推参数均保持。

最后一块放下后，机械臂按原净空抬升收回并直接回0度；从最后环到2环的固定距离作为离站道路前缀，连续衔接H→E→B→A/C。行驶与机构归位并行，不在2环额外停车，不新增E/F或其他视觉等待。上位机已发送的位置纠偏继续保留，不在放料后自动反向抵消。

`STN_STORAGE_SECOND_THROUGH_ENABLED`复用原机构并行、全向及连续过弯三个开关。关闭机构并行时保留串行编排；只关闭全向或过弯时，作业内仍可并行索引，但回2环采用原停车路径。首次暂存、原料、粗加工、道路几何、速度分档、r95出弯及故障/人工急停策略保持。

验证入口为 `tools/verify-storage-second-parallel.ps1`：每种开关组合检查72种A/C、G2环序及G3颜色序组合，另外检查124mm等待、125mm未到顶时底盘有运动指令、升降反馈缺失等待、人工`!`、F等待期间禁止夹取、正/负/零视觉修正保留。独立场地坐标仍按实际最后环检查离站交接；只调整测试中交接时点的期望坐标，不放宽误差预算。

测试与Keil构建不代表实车验收；现有125mm净空是否适合实际叠放物块、机械臂及场地，仍需上车核验。
