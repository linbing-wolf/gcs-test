## 当前常用值及怎么改

### 机械臂位置与联动

`lift` 是绝对高度：**0最低，135最高**；`lift=5` 表示去高度5 mm，不是下降5 mm。`slide=0` 表示完全收回。

| 参数 | 当前值 | 调整含义 |
|---|---:|---|
| `ARM_CLEARANCE_MM` | 110 mm | 操作者确认的离杯净空；调高会更晚开始收回/转向，调低须重新确认杯壁和物块净空 |
| `ARM_LIFT_PARALLEL_ENABLED` | 1 | 1启用升降联动：右侧直达取放高度、上升到净空后收回；0恢复顺序升降 |
| `ARM_STATION_PRESELECT_ENABLED` | 1 | 1提前选择下一杯，0在下一次取放接近时选杯；不改变物块所属杯位 |
| `ARM_LIFT_RPM` / `ARM_SLIDE_RPM` | 4000 / 4000 RPM | 增大目标转速；实际速度仍受驱动器、供电和负载影响 |
| `ARM_AXIS_ACCEL` | 220 | 驱动器协议档位0～255，不能当作RPM/s，也不能仅凭数值断定实际加速度 |
| 原料区 `ARM_PICK_*` | 55 / 105 / 131° | 平推/升降/云台，控制原料口抓取 |
| 车载杯 `ARM_PLACE_*` | 35 / 110 / 256° | 放回车上的位置；从车上取出另用100 mm |
| `STN_ROUGH_PLATFORM_TAKE_LIFT_MM` | 100 mm | 粗加工、第一次暂存、第二次暂存从车载杯取物共用 |
| 粗加工放下 / 抓回 | 55 / 5 / 126.5° | 两个lift参数分别控制松爪和抓回，可以独立修改 |
| 暂存第一层 / 第二层lift | 5 / 65 mm | 第二层由 `STN_STORAGE_LIFT_MM + STN_STORAGE_LAYER_LIFT_MM` 得出，当前5+60 |

当前净空高度按操作者修改为110 mm，用于夹取后上升时启动收回、转向和选杯，升降仍连续到135 mm。**转向车右侧（原料口131°、粗加工/暂存126.5°）下降时没有这个中间点，直接下降到原抓放高度，与平推/云台并行。** 车载杯位256°仍先到净空高度再进入杯内100 mm，放回杯的110 mm与当前净空相同，会去掉重复目标。净空采用升降轴实际位置反馈；改变机构或物块尺寸后需重新确认。

### 舵机时间

| 参数 | 当前值 | 调整含义 |
|---|---:|---|
| `ARM_YAW_TIME_MS` | 180 ms | 云台平滑指令插值时长；减小更快发完目标，不代表实测已转到 |
| `ARM_YAW_SETTLE_MS` | 40 ms | 最终云台目标PWM提交后保持，再进入下一步 |
| `ARM_SERVO_TIME_MS` | 400 ms | 载物台插值时长；与云台独立计时 |
| `ARM_CLAW_TIME_MS` | 50 ms | 夹爪开合插值时长 |
| `ARM_CLAW_CLOSE_HOLD_MS` | 120 ms | **最终合爪PWM写入后**抓稳再上升；不能靠加速云台来缩短这一段 |
| `ARM_CLAW_OPEN_DEG` / `ARM_CLAW_CLOSE_DEG` | 45° / 15° | 控制开口与夹持位置，不是速度 |

`ARM_*PULSES_PER_MM`、编码器计数、方向符号、舵机零点/补偿和最小最大角是硬件标定项；不要通过改这些值给机构提速。

### 工位、视觉和底盘

- 两区相邻环150 mm，1↔3自动一次300 mm；索引/视觉微调请求上限均60 RPM。方向约定前1、中2、后3。
- `STN_VISION_MM_PER_PX_X1000=1000` 表示当前假定1 px=1 mm，500则为1 px=0.5 mm；这不是实测标定。上位机每条MOVE/MOVEY按完整有符号数执行；不从DISC/STACK坐标另算一遍位移。
- 当前MOVE正值后退、MOVEY正值向左；方向改对应SIGN，位移比例改换算参数。本次没有改视觉行为。
- 底盘软件加速150 RPM/s、减速120 RPM/s；`CAR_MOTION_ACCELERATION=200` 是另一个驱动器档位。
- **`CAR_RUN_RPM=3000` 是请求值，实际还经过 [heading_control.c](../src/heading_control.c) 的 `heading_control_translate_wheels` 单轮300 RPM限幅。** 单改3000不会绕过这个限制；300不是本次新增或提高的数值。
- `CAR_DISTANCE_TOLERANCE_MM=1` 控制到位窗口；`CAR_DISTANCE_OVERRUN_MM=500` 仅放宽超程停机边界，不能消除实际过冲。转向稳定时间、查询周期等在 `car_config.h`，它们不是机械臂动作间的固定停顿。
- 修改地图内移量或道路几何后，需要先运行 `tools/rebuild-route-table.ps1` 重生成离线路表，再编译。仅改机构参数不需要重生成路线。

第二次暂存放料后的自动反向撤销已在r56删除，不设启用开关；车身保留MOVE/MOVEY后的实际位置。后续150/300 mm索引继续从当前位置出发，详见[暂存纠偏后保留位置](暂存纠偏后保留位置.md)。

## 不在常用配置头里的接口项

| 位置 | 用途 |
|---|---|
| [vision_link.c](../src/vision_link.c) | UART5初始化115200；帧缓存、查询告警时间、MOVE/MOVEY队列。改通信约定要同时核对上位机 |
| [main_table_nav.c](../src/main_table_nav.c) 的 `scanner_init` / `scanner_update` | 扫码配置指令和CRLF解析状态机；不是机械臂速度参数 |
| [hmi_status.c](../src/hmi_status.c) 的 `hmi_init` | USART6/PC6发送、9600波特率；需与屏工程一致 |
| [arm_control.c](../src/arm_control.c) 的 `build_load_one` | 原料区自动单块动作顺序；日常调位置和时间优先改 `arm_config.h` |
| [station_job.c](../src/station_job.c) 的 `build_rough` / `build_storage` | 粗加工和两批暂存动作顺序；日常调位置优先改 `station_config.h` |

## 修改后的验证

保持每次修改范围清楚，先改一个类别。运动参数/动作修改后运行 `tools/verify-heading.ps1`、`tools/verify-arm-integration.ps1`、`tools/verify-station-vision.ps1`，再完整ARM编译。电脑回归证明指令顺序、坐标和反馈状态机；实际夹稳、碰撞净空、定位精度和全程耗时仍要实车确认。
