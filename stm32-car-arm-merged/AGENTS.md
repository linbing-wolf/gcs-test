# 底盘与机械机构合并工程

- 本目录是独立合并工程，唯一入口为 `keil/TableNavigation.uvprojx`。保持 `../stm32-car-test`、`../stm32-arm-test` 和 `../gcs-test` 原样。
- 底盘使用本地当前runimu控制；merged2仅合入机械机构、任务码、UART5视觉与到站作业。操作者已确认默认接入自动到站作业；`station auto off`仅跑底盘。未标定的粗加工/暂存/平台取料表必须拒绝执行，不能用占位数值放行。
- 自动行驶要求机械臂已声明，行驶与工位互斥地消费四轮CAN队列。进站最后一段车头及路径参考均匹配作业区朝向后，可保持高位收回并提前转观察角；视觉与地面取放仍等待到站。粗加工及暂存第一批按操作者要求，在地面取放完成且实际升降通过既有离物净空后，下一固定环位索引与车载取放/回转并行，不必等完整收臂；下一地面取放必须汇合底盘到位，原5mm低速靠近仍可提前。第二批暂存的逐物块F/STACK流程保留。高位收回后剩余云台/载物台回正仍可与离站转弯、前后/横移并行；离站须重新采集四轮反馈，机构5/7仍用独立接收队列。不导入独立测试程序的全部main或电脑端烧录脚本。
- `!`始终是全系统急停请求，不得复用为夹取。机构使用 `arm ...` / `claw ...` 文本命令。
- r97按操作者要求将CAN_ABOM设为ENABLE，线路满足bxCAN总线恢复条件后自动退出Bus-Off；保留原自动重发和发送队列策略，不新增自动故障停机、清队列或任务重启。恢复后积压帧可能继续发送；固件编译/队列主机测试不代表总线故障已消除或实车恢复已验收。
- r98仅调整普通道路/独立平移的末端控制：四轮方向确认后，末段无连续后续路段时，横移最低请求可降至1RPM；最后10mm锁定同一末端航向PD，保留当前转向增益、取消10RPM最低修正、按60RPM/s衔接上一次实际提交的转向输出。小幅回拉时不再按平移速度压制转向，避免到位/回拉切换造成输出跳变。原1mm/0.8度/稳定时间判据保留；工位索引、视觉微调、obstacle、连续圆角及正常90/180度转向不使用此末端控制。不恢复自动故障停机，也不增加横移前后位置保持。
- r99按操作者要求取消首次B缺码停等，包括连续路径缺码时截短圆角到B的分支；扫码从发车横移持续至B→E直行、E→F及首次F到站。首个合法码锁定两批任务，后续扫码不覆盖；返程B不再初始化。若到首次F仍无码，只保持该任务未完成并继续接码，不编排取料；扫码或手输任务到齐后从F继续原流程。保留扫码配置/CR解析、r98停车、运动参数、视觉和机械臂；!仍取消并清任务，闲置与返程晚到码不能重建任务。
- r100按操作者要求将r98末端平滑扩展到视觉MOVE/MOVEY/MOVEXY：仅station_chassis_xy_start成功启动的视觉子动作置标记，固定150/300mm索引不置标记；单轴剩余距离或双轴最大剩余距离≤10mm后锁定末端控制，使用原视觉行驶PD增益120/30和60RPM/s变化率，不再随平移归零切到定角最低RPM。保留0.8度窗内亚1RPM静噪、窗外1RPM慢纠偏及原1mm到位判据；视觉单轴末段最低1RPM，双轴原末段1RPM保持。正常转向、道路、固定索引、视觉指令幅值/符号/FIFO/终包规则、机械臂时序和故障策略保持。此项取代r98中排除视觉微调的范围；不恢复自动故障停机。
- r101按操作者要求，将自动H/D/E/F及H后首次C请求前移到进站/固定索引/最后视觉位移的末段位置窗口（沿用10mm），观察姿态就绪即可发送，不等待下位机航向稳定、四轮停稳或互锁交接完成；上位机自行判稳。一次仍只有一个视觉会话，H终包已到且旧位移FIFO全部交底盘后才允许预发C，并保留H完成依据及提前C回包；F预发跨过INDEX_WAIT/串行CHASSIS但不提前消费后续动作。纠偏与取放仍按原底盘汇合和机构顺序执行；C第二/三块原本不等底盘，保留上一块作业依赖。替代前文视觉等待进站/索引停稳的发送限制，不改串口协议、速度、地图、r100末端、净空及自动故障策略。
- r102按操作者要求，原料区末块放回平台并完成松爪后，收臂（升降/平推及回正）可与离站同时进行；粗加工最后抓回必须在原杯放好并完成松爪之后才放行离站，再并行收臂，替代r81“实际110mm即带物离站”。暂存两批保留原实际125mm离地净空，达到后不等135mm/收回/回正即可并行离站。所有平台放置路径在双轴实际到位、云台最终PWM完成后接松爪，不额外等待云台40ms保持；地面动作、夹紧保持、升顶后200ms下降预留及现有调参保持。直线尽头随后需工位转向/视觉时，F/H进入原10mm末段、D满足原1mm编码器窗口后直接切转向，不先等一次零速/航向稳定；转向陀螺仪闭环、视觉发送/执行交接及非视觉/独立平移终点保持。此项替代前文相应离站放行和转向前停车时序，不恢复自动故障停机。
- r103按操作者现场反馈进一步前移：暂存两批最后一块松爪完成后即放行离站，不再以125mm抬升作为底盘离站门槛；机械臂内部原125mm后转向/平推顺序及中途环位索引的125mm门槛保持。工位离站重新取得四轮新鲜位置/速度/状态后，同向且航向在原窗口内即可起步，不重复零速/航向稳定保持；编码器基准必须取本次离站交接后的采样。粗加工180度进站转向从剩余10mm开始，仍拒绝D方向超出原1mm窗口的超程交接；转向前不发零速停等，陀螺仪闭环和视觉FIFO/执行交接保持。测试须记录首个非零底盘指令时云台未回零，以及真正纯转向批次的时刻，不能仅用arm_busy证明云台并行。此项替代r102中最后暂存125mm离站门槛和D转向必须进1mm的限制；粗加工最后一块仍先回原杯、松爪再离站。
- r104修复MOVEXY极性学习：区分车身距离归一符号与CPOS相对逻辑轮速的物理极性。正常单轴两份真实位移确认后缓存物理极性，本轮道路/工位子动作交接保留；MOVEXY直接使用缓存，不再每次重新猜。冷启动未知轮在指令提交时登记换向，等待新速度反馈过零/变向，并用该时刻之后的新CPOS学习区间确认；整段逆解原点保持，不能将旧方向累计位移配新方向。四轮CPOS先插值到共同时间再逆混控；冷启动三轮极性已知时，用既有混控矩阵的零空间关系完成三轮可观测逆解，不伪造第四轮极性标定。一次性输出确认依据；不硬填硬件符号、不放宽到位窗口、不改速度/加减速/目标/协议/机械臂/离站，不恢复自动停机。主机换向复现及极性组合通过不能代替实车排除CPOS突跳/线路/打滑。
