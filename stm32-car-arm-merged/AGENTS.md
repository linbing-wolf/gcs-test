# 底盘与机械机构合并工程

- 本目录是独立合并工程，唯一入口为 `keil/TableNavigation.uvprojx`。保持 `../stm32-car-test`、`../stm32-arm-test` 和 `../gcs-test` 原样。
- 底盘使用本地当前runimu控制；merged2仅合入机械机构、任务码、UART5视觉与到站作业。操作者已确认默认接入自动到站作业；`station auto off`仅跑底盘。未标定的粗加工/暂存/平台取料表必须拒绝执行，不能用占位数值放行。
- 自动行驶要求机械臂已声明，行驶与工位互斥地消费四轮CAN队列。进站最后一段车头及路径参考均匹配作业区朝向后，可保持高位收回并提前转观察角；视觉与地面取放仍等待到站。粗加工及暂存第一批按操作者要求，在地面取放完成且实际升降通过既有离物净空后，下一固定环位索引与车载取放/回转并行，不必等完整收臂；下一地面取放必须汇合底盘到位，原5mm低速靠近仍可提前。第二批暂存的逐物块F/STACK流程保留。高位收回后剩余云台/载物台回正仍可与离站转弯、前后/横移并行；离站须重新采集四轮反馈，机构5/7仍用独立接收队列。不导入独立测试程序的全部main或电脑端烧录脚本。
- `!`始终是全系统急停请求，不得复用为夹取。机构使用 `arm ...` / `claw ...` 文本命令。
- 操作者2026-10-25明确要求移除所有自动故障停机：异常仅告警，不自动发零速/Stop_Now、取消队列或中止正在执行的机构动作；`!`及原有显式人工停止、正常到位停车保留。无有效反馈/参数时保留未完成状态等待，不伪造到位；不得擅自恢复自动停机保护。驱动器自身硬件保护不由本策略控制。
- 粗加工最后一块抓回后，通过原110mm实际离物净空即可衔接道路，与放回载物台及直接回0度并行，不再回右侧观察角；回2环作为离站路径前缀，经现有圆角连续接入D→E，不在2环停车或请求视觉。只有工位并行、全向和连续过弯都启用时使用；关闭任一开关保留原索引停车路径。暂存及原料区末尾流程不扩大修改。此前缀起点是最后抓取环，外部obstacle在整条此前缀路径中沿用工位停止策略，不误报已回地图D点。
- 首次暂存最后一块松爪后，按原实际离物净空收回并直接回0度；固定回2环作为离站前缀连续接H→E→F，不在2环停车或增加视觉。沿用同一组三个并行/全向/过弯开关，关闭任一保留原索引路径。第二次暂存逐物块F/STACK和末尾流程保持；此项取代上一条“暂存末尾不扩大”的首次暂存限制。地图以当前配置为准：暂存新增50mm已撤回，粗加工原50mm保留。
- 底盘CAN地址1～4，升降5，平推7；PA1夹爪、PA2载物台、PA3云台使用TIM2，底盘毫秒计时使用TIM5。机构不发送广播同步命令。
- 当前参数来源和操作见 `docs/合并与串口操作.md`；当前验证以 `evidence/current-validation.json` 的源码哈希和结果为准。
- `docs`中其他文档和 `evidence/chassis-history` 属于继承的底盘资料，不能当成本合并版本的实车验收。
- 修改运动、CAN或互锁时运行 `tools/verify-heading.ps1`、`tools/verify-arm-integration.ps1`，并完整ARM构建；本地测试不代表烧录或真实动作已通过。
